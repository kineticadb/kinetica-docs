<a id="sql-show-file-cache"></a>


Lists the names of the database's
[file caches](/content/config#config-main-file-cache).  File caches can be shown by
any user.

```sql title="SHOW FILE CACHE Syntax"
SHOW FILE < CACHES | CACHE [<cache name>] >
```

Specify a `<cache name>` to show only that file cache; the only file cache is
`external_files`.  Cache names are case-sensitive and must be given in
lowercase.

To see the settings of the file caches, use [DESCRIBE FILE CACHE](/content/sql/system_properties/describe-file-cache); to see the
entries held in each file cache and the usage statistics of the caches, query
the [ki_file_cache_entries](/content/catalogs/kinetica#ki-file-cache-entries) and [ki_file_cache_stats](/content/catalogs/kinetica#ki-file-cache-stats)
catalog tables.


## Response


The response to `SHOW FILE CACHE` is a single-column result set,
`CACHE_NAME`, with one row per file cache.
