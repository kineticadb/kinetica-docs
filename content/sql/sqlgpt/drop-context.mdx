---
title: DROP CONTEXT
---

<a id="sql-gpt-drop-context"></a>


Removes an existing [SQL-GPT context](/content/sql/sqlgpt/create-context#sql-gpt-create-context).

```sql title="DROP CONTEXT Syntax"
DROP CONTEXT [<schema name>.]<context name>
```


## Examples


To remove the `example.atc_ctx` *SQL-GPT context*:

{/* Source: /examples/sql/sql-gpt/syntax.kisql (lines 22) */}
```sql DROP CONTEXT Example
DROP CONTEXT example.atc_ctx
```
