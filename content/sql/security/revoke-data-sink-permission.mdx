---
title: REVOKE Data Sink Permission
---

<a id="sql-security-priv-mgmt-dsink-revoke"></a>


[Permissions](/content/security/sec_concepts#security-concepts-permissions-datasink) on
[data sinks](/content/sql/ddl/create-data-sink#sql-create-data-sink)
that have been [granted](/content/sql/security/grant-data-sink-permission#sql-security-priv-mgmt-dsink-grant)
directly to
[users](/content/security/sec_concepts#security-concepts-users) or
[roles](/content/security/sec_concepts#security-concepts-roles) can be revoked.

```sql title="REVOKE Data Sink Permission Syntax"
REVOKE <CONNECT | ADMIN> [PRIVILEGES]
ON <ALL DATA SINKS [IN [SCHEMA] <schema reference>] | DATA SINK <data sink reference>>
FROM <user name | role name>
```

```sql title="REVOKE Create Data Sink Permission Syntax"
REVOKE CREATE [PRIVILEGES] ON DATA SINKS
[IN [SCHEMA] <schema reference>]
FROM <user name | role name>
```


## Examples


To revoke connect access on the *data sink* named **kin_dsink**
from the **auser** *user*:

{/* Source: /examples/sql/data_sink/data_sink.kisql (lines 92) */}
```sql REVOKE Data Sink Use Permission Example
REVOKE CONNECT ON DATA SINK kin_dsink FROM auser
```

To revoke administrative access on the *data sink* named **kin_dsink_http** from
the **auser** *user*:

{/* Source: /examples/sql/data_sink/data_sink.kisql (lines 118) */}
```sql REVOKE Data Sink Administrative Permission Example
REVOKE ADMIN ON DATA SINK kin_dsink_http FROM auser
```
