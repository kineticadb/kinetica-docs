---
title: ALTER ROLE
---

A [role](/content/security/sec_concepts#security-concepts-roles) can have its associated
[resource group](/content/rm/concepts#rm-concepts-resource-groups) modified.

```sql title="ALTER ROLE Syntax"
ALTER ROLE <role name>
SET RESOURCE GROUP [=] <group name | DEFAULT>
```


## Examples


To assign the **memory_over_execution** *resource group* to the **analyst**
role:

{/* Source: /examples/sql/security/user_role.kisql (lines 68-69) */}
```sql ALTER ROLE Example
ALTER ROLE analyst
SET RESOURCE GROUP memory_over_execution
```

To unassign the *resource group* from the **analyst** role:

{/* Source: /examples/sql/security/user_role.kisql (lines 72-73) */}
```sql ALTER ROLE Removing Resource Group Example
ALTER ROLE analyst
SET RESOURCE GROUP DEFAULT
```
