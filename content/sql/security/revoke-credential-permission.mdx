---
title: REVOKE Credential Permission
---

<a id="sql-security-priv-mgmt-cred-revoke"></a>


[Permissions](/content/security/sec_concepts#security-concepts-permissions-credential) on
[credentials](/content/sql/ddl/create-credential#sql-create-credential)
that have been [granted](/content/sql/security/grant-credential-permission#sql-security-priv-mgmt-cred-grant)
directly to
[users](/content/security/sec_concepts#security-concepts-users) or
[roles](/content/security/sec_concepts#security-concepts-roles) can be revoked.

```sql title="REVOKE Credential Permission Syntax"
REVOKE <READ | ADMIN> [PRIVILEGES]
ON <ALL CREDENTIALS [IN [SCHEMA] <schema reference>] | CREDENTIAL <credential reference>>
FROM <user name | role name>
```

```sql title="REVOKE Create Credential Permission Syntax"
REVOKE CREATE [PRIVILEGES] ON CREDENTIALS
[IN [SCHEMA] <schema reference>]
FROM <user name | role name>
```


## Examples


To revoke read access on the *credential* named
**auser_azure_active_dir_creds** from the **auser** *user*:

{/* Source: /examples/sql/credential/credential.kisql (lines 76) */}
```sql REVOKE Credential Use Permission Example
REVOKE READ ON CREDENTIAL auser_azure_active_dir_creds FROM auser
```

To revoke administrative access on the *credential* from the **auser** *user*:

{/* Source: /examples/sql/credential/credential.kisql (lines 82) */}
```sql REVOKE Credential Administrative Permission Example
REVOKE ADMIN ON CREDENTIAL auser_azure_active_dir_creds FROM auser
```
