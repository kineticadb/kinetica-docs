---
title: REVOKE Function (UDF/UDTF) Permission
---

<a id="sql-security-priv-mgmt-udf-revoke"></a>


Permissions relating to
[UDFs/UDTFs](/content/security/sec_concepts#security-concepts-permissions-function) and
[Python UDF function environments](/content/udf/python/writing#udf-python-func-env)
that have been [granted](/content/sql/security/grant-function-udf-udtf-permission#sql-security-priv-mgmt-udf-grant)
directly to
[users](/content/security/sec_concepts#security-concepts-users) or
[roles](/content/security/sec_concepts#security-concepts-roles) can be revoked.

```sql title="REVOKE Function (UDF/UDTF) Permission Syntax"
REVOKE <EXECUTE | ADMIN> [PRIVILEGES]
ON <ALL FUNCTIONS | FUNCTION < <function name> | * >>
FROM <user name | role name>
```

```sql title="REVOKE Create Function (UDF/UDTF) Permission Syntax"
REVOKE CREATE FUNCTION [PRIVILEGES]
FROM <user name | role name>
```


## Examples


To revoke execute on the **udf_sos_py_proc** *UDF* from **udf_user**:

{/* Source: /examples/sql/udf/udf.kisql (lines 211) */}
```sql REVOKE Function Execute Permission Example
REVOKE EXECUTE ON FUNCTION UDF_SOS_PY_PROC FROM udf_user
```

To revoke administrative access on every existing & future *UDF*, as well as the
ability to manage *function environments*, from **udf_user**:

{/* Source: /examples/sql/udf/udf_env_perm.kisql (lines 39) */}
```sql REVOKE Function Administrative Permission Example
REVOKE ADMIN ON FUNCTION * FROM udf_user
```
