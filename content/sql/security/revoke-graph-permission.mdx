---
title: REVOKE Graph Permission
---

<a id="sql-security-priv-mgmt-graph-revoke"></a>


[Permissions](/content/security/sec_concepts#security-concepts-permissions-graph) on
[graphs](/content/sql/graph#sql-graph) that have been
[granted](/content/sql/security/grant-graph-permission#sql-security-priv-mgmt-graph-grant)
directly to
[users](/content/security/sec_concepts#security-concepts-users) or
[roles](/content/security/sec_concepts#security-concepts-roles) can be revoked.

```sql title="REVOKE Graph Permission Syntax"
REVOKE <READ | WRITE | ADMIN> [PRIVILEGES]
ON <ALL GRAPHS [IN [SCHEMA] <schema reference>] | GRAPH <graph reference>>
FROM <user name | role name>
```

```sql title="REVOKE Create Graph Permission Syntax"
REVOKE CREATE [PRIVILEGES] ON GRAPHS
[IN [SCHEMA] <schema reference>]
FROM <user name | role name>
```


## Examples


To revoke query, match, solve, & show access on the *graph* named
**big_cities_graph** from **geo_user**:

{/* Source: /examples/sql/graph/graph.kisql (lines 372) */}
```sql REVOKE Graph Permission Example
REVOKE READ ON GRAPH big_cities_graph FROM geo_user
```
