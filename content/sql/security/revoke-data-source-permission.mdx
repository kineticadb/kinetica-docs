---
title: REVOKE Data Source Permission
---

<a id="sql-security-priv-mgmt-ds-revoke"></a>


[Permissions](/content/security/sec_concepts#security-concepts-permissions-datasource) on
[data sources](/content/sql/ddl/create-data-source#sql-create-data-source)
that have been [granted](/content/sql/security/grant-data-source-permission#sql-security-priv-mgmt-ds-grant)
directly to
[users](/content/security/sec_concepts#security-concepts-users) or
[roles](/content/security/sec_concepts#security-concepts-roles) can be revoked.

```sql title="REVOKE Data Source Permission Syntax"
REVOKE <CONNECT | ADMIN> [PRIVILEGES]
ON <ALL DATA SOURCES [IN [SCHEMA] <schema reference>] | DATA SOURCE <data source reference>>
FROM <user name | role name>
```

```sql title="REVOKE Create Data Source Permission Syntax"
REVOKE CREATE [PRIVILEGES] ON DATA SOURCES
[IN [SCHEMA] <schema reference>]
FROM <user name | role name>
```


## Examples


To revoke connect access on the *data source* named **kin_ds** from
the **auser** *user*:

{/* Source: /examples/sql/data_source/data_source.kisql (lines 83) */}
```sql REVOKE Data Source Use Permission Example
REVOKE CONNECT ON DATA SOURCE kin_ds FROM auser
```

To revoke administrative access on the *data source* named **kin_ds_anon** from
the **auser** *user*:

{/* Source: /examples/sql/data_source/data_source.kisql (lines 116) */}
```sql REVOKE Data Source Administrative Permission Example
REVOKE ADMIN ON DATA SOURCE kin_ds_anon FROM auser
```
