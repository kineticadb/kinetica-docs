---
title: REVOKE Directory Permission
---

<a id="sql-security-priv-mgmt-dir-revoke"></a>


[Permissions](/content/security/sec_concepts#security-concepts-permissions-kifs) on
[KiFS directories](/content/sql/kifs/create-directory#sql-kifs-create-dir)
that have been [granted](/content/sql/security/grant-directory-permission#sql-security-priv-mgmt-dir-grant)
directly to
[users](/content/security/sec_concepts#security-concepts-users) or
[roles](/content/security/sec_concepts#security-concepts-roles) can be revoked.

```sql title="REVOKE Directory Permission Syntax"
REVOKE <READ | WRITE> [PRIVILEGES]
ON <ALL DIRECTORIES | DIRECTORY < <directory name> | * >>
FROM <user name | role name>
```

```sql title="REVOKE Create Directory Permission Syntax"
REVOKE CREATE DIRECTORY [PRIVILEGES]
FROM <user name | role name>
```


## Examples


To revoke read access on a *directory* named **kdata** from the
**kuser** *user*:

{/* Source: /examples/sql/kifs.kisql (lines 184) */}
```sql REVOKE Directory Read Permission Example
REVOKE READ ON DIRECTORY 'kdata' FROM kuser
```

To revoke write access on a *directory* named **kdata** from the **kuser** *user*:

{/* Source: /examples/sql/kifs.kisql (lines 190) */}
```sql REVOKE Directory Write Permission Example
REVOKE WRITE ON DIRECTORY 'kdata' FROM kuser
```
