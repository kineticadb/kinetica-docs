---
title: REVOKE Stream Permission
---

<a id="sql-security-priv-mgmt-stream-revoke"></a>


[Permissions](/content/security/sec_concepts#security-concepts-permissions-monitor) on
[streams](/content/sql/ddl/create-stream#sql-create-stream)
that have been [granted](/content/sql/security/grant-stream-permission#sql-security-priv-mgmt-stream-grant)
directly to
[users](/content/security/sec_concepts#security-concepts-users) or
[roles](/content/security/sec_concepts#security-concepts-roles) can be revoked.

```sql title="REVOKE Stream Permission Syntax"
REVOKE ADMIN [PRIVILEGES]
ON <ALL STREAMS [IN [SCHEMA] <schema reference>] | STREAM <stream reference>>
FROM <user name | role name>
```

```sql title="REVOKE Create Stream Permission Syntax"
REVOKE CREATE [PRIVILEGES] ON STREAMS
[IN [SCHEMA] <schema reference>]
FROM <user name | role name>
```


## Examples


To revoke administrative access on the *stream* named
**kin_stream** from the **auser** *user*:

{/* Source: /examples/sql/stream/stream.kisql (lines 75) */}
```sql REVOKE Stream Administrative Permission Example
REVOKE ADMIN ON STREAM example.kin_stream FROM auser
```
