---
title: SHOW CATALOG
---

<a id="sql-show-catalog"></a>


Outputs the DDL statement required to reconstruct the given
[catalog](/content/sql/ddl/create-catalog#sql-create-catalog).

```sql title="SHOW CATALOG Syntax"
SHOW CATALOG <catalog name>
```


<Info>
The response to `SHOW CATALOG` is a single-column result set with
the DDL statement as the value in the `DDL` column.
</Info>


## Parameters


<AccordionGroup>

<Accordion title="&lt;catalog name&gt;" id="<catalog-name>" defaultOpen>

Name of the existing *catalog* for which the DDL will be output.

</Accordion>

</AccordionGroup>


## Examples


To output the DDL for a *catalog*:

{/* Source: /examples/sql/datalake/datalake.kisql (lines 159) */}
```sql SHOW CATALOG Example
SHOW CATALOG iceberg_rest_cat
```
