---
title: DROP STATISTICS
---

<a id="sql-drop-statistics"></a>


Removes the statistics collected on a column of a *table* by
[COLLECT STATISTICS](/content/sql/ddl/collect-statistics).  Queries against the *table* are then planned without
statistics for that column.

Dropping statistics requires read
[permission](/content/security/sec_concepts#security-concepts-permissions) on the column; a user
whose access to the *table* is limited to certain
[rows](/content/sql/security/grant-table-permission#sql-security-priv-mgmt-row-grant) or
[columns](/content/sql/security/grant-table-permission#sql-security-priv-mgmt-col-grant) can drop the
statistics of any column they can read.

```sql title="DROP STATISTICS Syntax"
DROP STATISTICS [ON] [TABLE] [<schema name>.]<table name> COLUMN <column name>
```


## Parameters


<AccordionGroup>

<Accordion title="&lt;schema name&gt;" id="<schema-name>" defaultOpen>

Name of the *schema* containing the *table* whose statistics will be dropped

</Accordion>

<Accordion title="&lt;table name&gt;" id="<table-name>" defaultOpen>

Name of the *table* whose statistics will be dropped

</Accordion>

<Accordion title="&lt;column name&gt;" id="<column-name>" defaultOpen>

Name of the column whose statistics will be dropped; only one column can be given per statement

</Accordion>

</AccordionGroup>


## Examples


To drop the statistics on a column of a *table*:

{/* Source: /examples/sql/table/statistics.kisql (lines 50) */}
```sql DROP STATISTICS Example
DROP STATISTICS ON TABLE example.stats_employee COLUMN salary
```
