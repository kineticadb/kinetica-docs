<a id="sql-system-properties"></a>

*Kinetica* provides a SQL interface for system administration: managing
[system properties](/content/config), which control everything from
GPUs, hostnames, storage, graph server, and more; verifying that the database
is in a consistent state; and managing the database's file caches.
