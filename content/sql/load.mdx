<a id="sql-load-file"></a>

Data is loaded into *Kinetica* from files held in a data source, on the
*Kinetica* file system (KiFS), or on the local file system. Use **LOAD INTO** to
create or populate a table from source files, optionally subscribing to the
source so new data is ingested as it arrives, or **INSERT INTO ... SELECT ...
FROM FILE** to query files directly and insert the result into an existing
table.
