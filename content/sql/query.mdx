title: Queries (SQL)
---

Queries retrieve and combine data from *Kinetica* tables with the **SELECT**
statement. The features and functions below cover joins, aggregation, grouping
and windowing, set operations, common table expressions, subqueries, and the
full library of scalar and aggregate functions available in query expressions.
