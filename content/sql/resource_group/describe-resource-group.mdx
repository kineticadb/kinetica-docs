---
title: DESCRIBE RESOURCE GROUP
---

<a id="sql-rg-desc"></a>


The configuration of any *resource group* can be shown, in tabular form.  The
configuration for all *resource groups* in the system can also be shown with a
single command.

```sql title="SHOW RESOURCE GROUP Syntax"
SHOW RESOURCE GROUP < <resource group name> | ALL >
```


## Examples


To show the configuration of the **memory_and_execution**
*resource group*:

{/* Source: /examples/sql/resource_group.kisql (lines 102) */}
```sql DESCRIBE RESOURCE GROUP Example
DESCRIBE RESOURCE GROUP memory_and_execution
```

To show the configuration of all *resource groups*:

{/* Source: /examples/sql/resource_group.kisql (lines 114) */}
```sql DESCRIBE RESOURCE GROUP (All Groups) Example
DESCRIBE RESOURCE GROUP ALL
```
