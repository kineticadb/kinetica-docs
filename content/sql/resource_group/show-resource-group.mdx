---
title: SHOW RESOURCE GROUP
---

<a id="sql-rg-show"></a>


The DDL statement required to reconstruct any *resource group* can be shown. The
DDL for all *resource groups* in the system can also be shown with a single
command.

```sql title="SHOW RESOURCE GROUP Syntax"
SHOW RESOURCE GROUP < <resource group name> | ALL >
```


## Examples


To show the DDL of the **memory_and_execution** *resource group*:

{/* Source: /examples/sql/resource_group.kisql (lines 99) */}
```sql SHOW RESOURCE GROUP Example
SHOW RESOURCE GROUP memory_and_execution
```

To show the DDL of all *resource groups*:

{/* Source: /examples/sql/resource_group.kisql (lines 111) */}
```sql SHOW RESOURCE GROUP (All Groups) Example
SHOW RESOURCE GROUP ALL
```
