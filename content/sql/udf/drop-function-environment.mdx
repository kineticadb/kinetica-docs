---
title: DROP FUNCTION ENVIRONMENT
---

<a id="sql-drop-function-environment"></a>


Removes an existing
[Python UDF/UDTF environment](/content/sql/udf/create-function-environment#sql-create-function-environment).

```sql title="DROP FUNCTION ENVIRONMENT Syntax"
DROP FUNCTION ENVIRONMENT <environment name>
```


## Parameters


<AccordionGroup>

<Accordion title="&lt;environment name&gt;" id="<environment-name>" defaultOpen>

Name of the UDF environment to remove

</Accordion>

</AccordionGroup>


## Examples


To remove the Python UDF environment `udfe_st`:

{/* Source: /examples/sql/udf/udf_env.kisql (lines 227) */}
```sql DROP FUNCTION ENVIRONMENT Example
DROP FUNCTION ENVIRONMENT udfe_st
```
