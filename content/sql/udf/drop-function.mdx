---
title: DROP FUNCTION
---

<a id="sql-drop-function"></a>


Removes an existing [UDF/UDTF](/content/sql/udf#sql-udf).

```sql title="DROP FUNCTION Syntax"
DROP FUNCTION <function name>
```


## Parameters


<AccordionGroup>

<Accordion title="&lt;function name&gt;" id="<function-name>" defaultOpen>

Name of the UDF to remove

</Accordion>

</AccordionGroup>


## Examples


To drop the `UDF_SOS_PY_PROC` UDF:

{/* Source: /examples/sql/udf/udf.kisql (lines 235) */}
```sql DROP FUNCTION Example
DROP FUNCTION UDF_SOS_PY_PROC
```
