---
title: Using Tableau with Kinetica
---

*Tableau* connects to *Kinetica* using its built-in *PostgreSQL* connector, over
the [PostgreSQL Wire Protocol](/content/connectors/psql_wire_protocol); no
additional driver is needed.


<Info>
To visualize maps from Kinetica-hosted datasets, see
[Kinetica Geospatial Visualization for Tableau](/content/bi/tableau/kin_geo_viz_tableau).
</Info>

To view your *Kinetica* data from *Tableau*:

1. In *Tableau*, under **Connect**, select
   **To a Server --&gt; PostgreSQL**
2. Enter the connection details:

   * **Server**:  host name of the *Kinetica* head node
   * **Port**:  `5432`
   * **Database**:  `postgres`
   * **Authentication**:  **Username and Password**
   * **Username** & **Password**:  credentials of
     the *Kinetica* user to connect as

3. Click **Sign In**
4. Select the schema containing the data you want to view
5. Select the *table* containing the data you want to view


    ![images/tableSelection.jpg](/content/bi/tableau/images/tableSelection.jpg)

6. From a sheet, configure the fields as needed.  In this example, the "x" field
   is set as longitude and the "y" field is set as latitude.


    ![images/setColumnType.jpg](/content/bi/tableau/images/setColumnType.jpg)

7. Add the fields you want to view and the type of display


    ![images/map.jpg](/content/bi/tableau/images/map.jpg)


<Info>
When connecting this way:
* *Geometry* columns cannot be read directly.  To use one, connect with
  **Custom SQL** and convert it to WKT text with
  [ST_ASTEXT](/content/sql/query/geospatial-geometry-functions#sql-geo-functions), or use numeric longitude &
  latitude columns, as in the steps above.
* In earlier releases, *Kinetica* did not report foreign keys to
  *Tableau*, so relationships between *tables* were not detected
  automatically; define them in the *Tableau* data source as needed.
</Info>


<Tip>
*Tableau* can also connect to *Kinetica* through the *Kinetica* JDBC
driver, using *Tableau's* **Other Databases (JDBC)** connector.
Download the [JDBC JAR from GitHub](https://github.com/kineticadb/kinetica-client-jdbc)
and follow the
[Tableau connection guide](https://help.tableau.com/current/pro/desktop/en-us/examples_otherdatabases_jdbc.htm).
</Tip>
