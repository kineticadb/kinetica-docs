<h3 className="tsd-anchor-link" id="command"><code className="tsd-tag">Optional</code><span>command</span></h3>
<div className="tsd-signature"><span className="tsd-kind-property">command</span><span className="tsd-signature-symbol">?:</span> <span className="tsd-signature-type">string</span></div>
<div className="tsd-comment tsd-typography">
<p>The command (excluding arguments) that will be invoked when the proc is executed. It will be invoked from the directory containing the proc <code>files</code> and may be any command that can be resolved from that directory. It need not refer to a file actually in that directory; for example, it could be 'java' if the proc is a Java application; however, any necessary external programs must be preinstalled on every database node. If the command refers to a file in that directory, it must be preceded with './' as per Linux convention. If not specified, and exactly one file is provided in <code>files</code>, that file will be invoked.</p>
</div>
