<div className="tsd-comment tsd-typography">
<p>List of member table columns or column expressions to be included in the join. Columns can be prefixed with 'table\_id.column\_name', where 'table\_id' is the table name or alias. Columns can be aliased via the syntax 'column\_name as alias'. Wild cards '<span className="em">' can be used to include all columns across member tables or 'table\_id.</span>' for all of a single table's columns. Columns and column expressions composing the join must be uniquely named or aliased--therefore, the '\*' wild card cannot be used if column names aren't unique across all tables.</p>
