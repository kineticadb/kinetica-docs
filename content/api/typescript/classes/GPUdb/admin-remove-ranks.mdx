<div className="tsd-description">
<div className="tsd-comment tsd-typography">
<p>Remove one or more ranks from an existing Kinetica cluster. All data will be rebalanced to other ranks before the rank(s) is removed unless the rebalance\_sharded\_data or rebalance\_unsharded\_data parameters are set to false in the <code>options</code>, in which case the corresponding sharded data and/or unsharded data (a.k.a. randomly-sharded) will be deleted.</p>
<p>The database must be offline for this operation, see <code>admin\_offline</code></p>
<p>This endpoint's processing time depends on the amount of data in the system, thus the API call may time out if run directly. It is recommended to run this endpoint asynchronously via <code>create\_job</code>.</p>
<p><strong>Note:</strong> This method should be used for on-premise deployments only.</p>
</div>

<div className="tsd-comment tsd-typography">
<p>Each array value designates one or more ranks to remove from the cluster. Values can be formatted as 'rankN' for a specific rank, 'hostN' (from the gpudb.conf file) to remove all ranks on that host, or the host IP address (hostN.address from the gpub.conf file) which also removes all ranks on that host. Rank 0 (the head rank) cannot be removed (but can be moved to another host using <code>admin\_switchover</code>). At least one worker rank must be left in the cluster after the operation.</p>
