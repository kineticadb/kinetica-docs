<div className="tsd-description">
<div className="tsd-comment tsd-typography">
<p>Retrieves the complete series/track records from the given <code>world\_table\_name</code> based on the partial track information contained in the <code>table\_name</code>.</p>
<p>This operation supports paging through the data via the <code>offset</code> and <code>limit</code> parameters.</p>
<p>In contrast to <code>get\_records</code> this returns records grouped by series/track. So if <code>offset</code> is 0 and <code>limit</code> is 5 this operation would return the first 5 series/tracks in <code>table\_name</code>. Each series/track will be returned sorted by their TIMESTAMP column.</p>
</div>
