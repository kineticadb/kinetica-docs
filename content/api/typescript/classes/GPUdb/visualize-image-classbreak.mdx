<div className="tsd-comment tsd-typography">
<p>For internal use only. Generates 'class break' rasterized image tiles for an area of interest using the given tables and the provided parameters.</p>
<p>A class break rendering is where data from one or more tables is rasterized with styling applied on a per-class basis. Class breaks based on one or more data columns are supported. Distinct values (for strings) or ranges (for numeric attributes) must be provided in the cb\_column\_name1/cb\_vals1 and cb\_column\_name2/cb\_vals2 parameters. The styling parameters must be specified for each class.</p>
<p>All color values must be in the format RRGGBB or AARRGGBB (to specify the alpha value).</p>
<p>The image is contained in the <code>image\_data</code> field.</p>
</div>
