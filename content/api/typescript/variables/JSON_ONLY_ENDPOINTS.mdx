<p>Endpoints sent as JSON even by a client using binary encoding.</p>
<p>Each carries a bytes field that is not record data -- file contents, job payloads, rendered images. JSON carries those as strings and Avro as raw bytes, so encoding them as Avro would change the values a caller passes and gets back.</p>
