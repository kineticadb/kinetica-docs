<p>Blocking request, for legacy code that expects a return value rather than a promise. Uses a synchronous XMLHttpRequest, which browsers still support but have deprecated: it blocks the UI thread. Only reachable when the client was constructed with <code>sync: true</code>, which the standalone build does by default.</p>
