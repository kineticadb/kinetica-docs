<div className="tsd-comment tsd-typography">
<p>An Avro type, compiled from its schema, that encodes values to Avro binary and decodes them back.</p>
<p>Values map to JavaScript as JSON-style data: records and maps to plain objects, arrays to arrays, bytes and fixed to Uint8Array, enums to their symbol strings, and null to null. A union takes the value as-is and is written as its first branch that accepts it.</p>
</div>
<div className="tsd-comment tsd-typography">
<div className="tsd-tag-example">
<h4 className="tsd-anchor-link" id="example">Example</h4>
<div>

```
const type = AvroType.forSchema({
    type: 'record', name: 'point',
    fields: [{ name: 'x', type: 'double' }, { name: 'label', type: ['string', 'null'] }],
});
const bytes = type.encode({ x: 1.5, label: null });
type.decode(bytes); // { x: 1.5, label: null }
```
