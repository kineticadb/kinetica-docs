<div className="tsd-comment tsd-typography">
<p>Closes this client: drops the SQL <code>#name</code> temp tables it created, if any. The client cannot be used afterwards: every request fails at once, without failing over. Closing a closed client does nothing, and a close already under way is waited for.</p>
<p>The drop fails over like any request. A failure is logged, not thrown, since the server reclaims the session on its own. It is skipped where no temp table was created, and against a server that does not support session temp tables, which never reports one. A session given by <a href="/content/api/nodejs/interfaces/GPUdbOptions#session_id" className="tsd-kind-property">GPUdbOptions.session\_id</a> is not dropped: the caller drops it with <code>drop\_session()</code>.</p>
<p>A client that is never closed still has its temp tables dropped when it is garbage collected, on a best-effort basis, where the runtime has FinalizationRegistry; failing that, the server reclaims them on its own. Closing it is what makes the drop prompt.</p>
