<div className="tsd-description">
<div className="tsd-comment tsd-typography">
<p>Iterates the results of an SQL statement, fetching in batches.</p>
<p>Pages through the result set so arbitrarily large queries can be consumed without holding everything in memory at once, cleaning up any server-side paging tables when iteration finishes -- including when the caller breaks out of the loop early.</p>
<p>Records are yielded as objects keyed by column name. This differs from the JavaScript API, which yields positional arrays; use <code>Object.values(record)</code> if you need those.</p>
</div>
