<div className="tsd-comment tsd-typography">
<p>Decoded payload of an endpoint that returns a dynamic schema, such as execute\_sql or aggregate\_group\_by.</p>
<p>Always present on the responses that declare it: the client decodes the payload on every such response before handing it back, so consumers never need to guard the field.</p>
<p>A statement that returns no result set -- DDL such as CREATE TABLE ... AS SELECT -- still carries the field, but with no columns: read <code>count\_affected</code> for those rather than <code>column\_headers</code>.</p>
<p>The values are column-major, not a list of records: <code>column\_1</code> holds every value for the column named by <code>column\_headers\[0\]</code>, <code>column\_2</code> for <code>column\_headers\[1\]</code>, and so on.</p>
</div>
<div className="tsd-comment tsd-typography">
<div className="tsd-tag-example">
<h4 className="tsd-anchor-link" id="example">Example</h4>
<div>

```
const response = await gpudb.execute_sql('SELECT category FROM t', 0, 10, '', [], {});
const data = response.data;
// data.column_headers -> ['category']
// data.column_1       -> ['A', 'B']
```
