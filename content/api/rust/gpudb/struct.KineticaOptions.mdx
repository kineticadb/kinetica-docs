<div className="docblock">
<p>Extended configuration options for the Kinetica client.</p>
<p>This struct provides comprehensive configuration for the Kinetica client including authentication, connection settings, and HA configuration.</p>
<p>Large batches are encoded and decoded on rayon’s threads, with the same results as one thread gives (see <a href="/content/api/rust/avro/index" title="mod gpudb_api::avro"><code>crate::avro</code></a>). The connection pool checks every connection before it hands one out, and <code>timeout</code> applies to every request.</p>
</div>

<div className="docblock">
<p>Request timeout in milliseconds (0 = infinite).</p>
<p>A read timeout: it bounds the wait for a response once the request has been sent, and then each read of the response body, never the upload or the body as a whole. A timeout waiting for a response is treated like an unreachable server and triggers HA failover.</p>
