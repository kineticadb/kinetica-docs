<p>Returns the worker rank URLs, where entry <code>i</code> is rank <code>i + 1</code>.</p>
<p>A rank removed from the cluster keeps its slot, as <code>None</code>, so that these indices stay aligned with the rank numbering used by the shard routing table. Callers walking this list must skip the empty slots; to iterate only reachable ranks, use <a href="/content/api/rust/gpudb/struct.ClusterAddressInfo#method.live_worker_rank_urls" title="method gpudb_api::gpudb::ClusterAddressInfo::live_worker_rank_urls"><code>Self::live\_worker\_rank\_urls</code></a>.</p>
