<div className="docblock">
<p>Show information about tables, views, or schemas.</p>
<p>Retrieves detailed information about a table, view, or schema, specified in <code>table\_name</code>. If the supplied <code>table\_name</code> is a schema the call can return information about either the schema itself or the tables and views it contains. If <code>table\_name</code> is empty, information about all schemas will be returned.</p>
<p>If the option get\_sizes is set to true, then the number of records in each table is returned (in <code>sizes</code> and <code>full\_sizes</code>), along with the total number of objects across all requested tables (in <code>total\_size</code> and <code>total\_full\_size</code>).</p>
<p>For a schema, setting the show\_children option to false returns only information about the schema itself; setting show\_children to true returns a list of tables and views contained in the schema, along with their corresponding detail.</p>
<p>To retrieve a list of every table, view, and schema in the database, set <code>table\_name</code> to ‘\*’ and show\_children to true. When doing this, the returned <code>total\_size</code> and <code>total\_full\_size</code> will not include the sizes of non-base tables (e.g., filters, views, joins, etc.).</p>
<h5 id="arguments-384">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of the table for which to retrieve the information, in \[schema\_name.\]table\_name format, using standard name resolution rules. If blank, then returns information about all tables and views.</li>
</ul>
