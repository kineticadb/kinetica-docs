<div className="docblock">
<p>Switches to the next available cluster URL for HA failover.</p>
<p>This method:</p>
<ul>
<li>Checks if failover is disabled</li>
<li>Checks if only one cluster exists (no failover possible)</li>
<li>Checks if another thread has already switched</li>
<li>Selects the next available cluster</li>
<li>Skips clusters that aren’t running</li>
</ul>
<h5 id="arguments-1">Arguments</h5>
<ul>
<li><code>old\_url</code> - The URL that was in use when the failure occurred</li>
<li><code>old\_num\_cluster\_switches</code> - The switch count before this switch was initiated</li>
</ul>
<h5 id="returns-4">Returns</h5>
<p>The new URL to use, or an error if failover is not possible.</p>
