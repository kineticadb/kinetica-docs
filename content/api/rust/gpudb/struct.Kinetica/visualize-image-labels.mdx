<p>Generate a rasterized image tile containing text labels</p>
<p>For internal use only. Generates a rasterized image tile containing text labels defined by data contained in the given table, suitable for overlaying onto a feature image tile covering the same area (for example one generated using <code>/visualize/image</code>).</p>
<p>All color values must be integers encoded in the format AARRGGBB when represented in hexadecimal.</p>
<p>Fonts are specified as strings of the form ‘FAMILY STYLE-OPTIONS SIZE’, where FAMILY is the font family, STYLE-OPTIONS is a whitespace separated list of words defining style, variant, weight, stretch, or gravity, and SIZE is a decimal number (size in points) or optionally followed by the unit modifier ‘px’ for absolute size. All three sub-fields are optional; default values will be used for omitted sub-fields. (For example, ‘Helvetica Bold Italic 10’ specifies Helvetica, Bold and Italic, 10 points.) A substitute font will be used if a requested font is not installed.</p>
<h5 id="arguments-422">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of the table containing the data defining the labels to render.</li>
<li><code>x\_column\_name</code> - Double, float or decimal expression that evaluates to the x coordinates of the center points of the labels.</li>
<li><code>y\_column\_name</code> - Double, float or decimal expression that evaluates to the y coordinates of the center points of the labels.</li>
<li><code>x\_offset</code> - Numeric expression that evaluates to the number of output pixels by which the labels will be offset horizontally from their specified x coordinates. If blank, an offset of 0 will be used.</li>
<li><code>y\_offset</code> - Numeric expression that evaluates to the number of output pixels by which the labels will be offset vertically from their specified y coordinates. If blank, an offset of 0 will be used.</li>
<li><code>text\_string</code> - Expression that evaluates to the text for the labels.</li>
<li><code>font</code> - Expression that evaluates to the fonts for the labels. If blank, a default system font will be used.</li>
<li><code>text\_color</code> - Numeric expression that evaluates to the text color for the labels. If blank, opaque black will be used.</li>
<li><code>text\_angle</code> - Numeric expression that evaluates to the angle of clockwise rotation (in degrees) for the labels. If blank, an angle of 0 will be used.</li>
<li><code>text\_scale</code> - Numeric expression that evaluates to the scaling factor for the labels. (1 is normal size, 0.5 is half size, 2 is double size, etc.) If blank, a scaling factor of 1 will be used.</li>
<li><code>draw\_box</code> - Boolean expression indicating whether boxes will be drawn around the labels. If blank, no boxes will be drawn.</li>
<li><code>draw\_leader</code> - Boolean expression indicating whether leader lines will be drawn from the labels to points specified using <code>leader\_x\_column\_name</code> and <code>leader\_y\_column\_name</code>. If blank, no leader lines will be drawn.</li>
<li><code>line\_width</code> - Numeric expression that evaluates to the line width in output pixels for the labels’ boxes and leader lines. If blank, a line width of 1 will be used.</li>
<li><code>line\_color</code> - Numeric expression that evaluates to the line color for the labels’ boxes and leader lines. If blank, opaque black will be used.</li>
<li><code>fill\_color</code> - Numeric expression that evaluates to the fill color for the labels’ boxes. If blank, the boxes will not be filled.</li>
<li><code>leader\_x\_column\_name</code> - Double, float or decimal expression that evaluates to the x coordinates of the points to which the labels’ leader lines will be drawn. May be left blank if no leader lines are to be drawn.</li>
<li><code>leader\_y\_column\_name</code> - Double, float or decimal expression that evaluates to the y coordinates of the points to which the labels’ leader lines will be drawn. May be left blank if no leader lines are to be drawn.</li>
<li><code>filter</code> - Boolean expression indicating which labels to include in the image. If blank, all labels will be included.</li>
<li><code>min\_x</code> - Lower bound for the x coordinates of labels to include in the image.</li>
<li><code>max\_x</code> - Upper bound for the x coordinates of labels to include in the image.</li>
<li><code>min\_y</code> - Lower bound for the y coordinates of labels to include in the image.</li>
<li><code>max\_y</code> - Upper bound for the y coordinates of labels to include in the image.</li>
<li><code>width</code> - Width of the generated image.</li>
<li><code>height</code> - Height of the generated image.</li>
<li><code>projection</code> - Spatial Reference System (i.e. EPSG Code).</li>
</ul>
