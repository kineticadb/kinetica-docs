<p>Alter system configuration</p>
<p>The <code>/alter/system/properties</code> endpoint is primarily used to simplify the testing of the system and is not expected to be used during normal execution. Commands are given through the <code>property\_updates\_map</code> whose keys are commands and values are strings representing integer values (for example ‘8000’) or boolean values (‘true’ or ‘false’).</p>
