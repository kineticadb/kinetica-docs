<p>Filter a dataset for records with specific column values</p>
<p>Calculates which records from a table have values in the given list for the corresponding column. The operation is synchronous, meaning that a response will not be returned until all the objects are fully available. The response payload provides the count of the resulting set. A new resultant set (view) which satisfies the input filter specification is also created if a <code>view\_name</code> is passed in as part of the request.</p>
<p>For example, if a type definition has the columns ‘x’ and ‘y’, then a filter by list query with the column map {"{"}“x”:\[“10.1”, “2.3”\], “y”:\[“0.0”, “-31.5”, “42.0”\]{"}"} will return the count of all data points whose x and y values match both in the respective x- and y-lists, e.g., “x = 10.1 and y = 0.0”, “x = 2.3 and y = -31.5”, etc. However, a record with “x = 10.1 and y = -31.5” or “x = 2.3 and y = 0.0” would not be returned because the values in the given lists do not correspond.</p>
<h5 id="arguments-233">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of the table to filter, in \[schema\_name.\]table\_name format, using standard name resolution rules. This may be the name of a table or a view (when chaining queries).</li>
<li><code>view\_name</code> - If provided, then this will be the name of the view containing the results, in \[schema\_name.\]view\_name format, using standard name resolution rules and meeting table naming criteria. Must not be an already existing table or view.</li>
<li><code>column\_values\_map</code> - List of values for the corresponding column in the table.</li>
</ul>
