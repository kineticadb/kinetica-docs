<p>Insert records from a text-based or binary payload into the specified target table</p>
<p>Reads from the given text-based or binary payload and inserts the data into a new or existing table. The table will be created if it doesn’t already exist.</p>
<p>Returns once all records are processed.</p>
<h5 id="arguments-300">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of the table into which the data will be inserted, in \[schema\_name.\]table\_name format, using standard name resolution rules. If the table does not exist, the table will be created using either an existing type\_id or the type inferred from the payload, and the new table name will have to meet standard table naming criteria.</li>
<li><code>data\_text</code> - Records formatted as delimited text.</li>
<li><code>data\_bytes</code> - Records formatted as binary data.</li>
<li><code>modify\_columns</code> - Not implemented yet.</li>
<li><code>create\_table\_options</code> - Options used when creating the target table. Includes type to use. The other options match those in <code>/create/table</code>.</li>
</ul>
