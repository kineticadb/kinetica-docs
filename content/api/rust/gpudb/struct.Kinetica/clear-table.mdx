<div className="docblock">
<p>Delete a table</p>
<p>Clears (drops) one or all tables in the database cluster. The operation is synchronous meaning that the table will be cleared before the function returns. The response payload returns the status of the operation along with the name of the table that was cleared.</p>
<h5 id="arguments-105">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of the table to be cleared, in \[schema\_name.\]table\_name format, using standard name resolution rules. Must be an existing table. Empty string clears all available tables, though this behavior is prevented by default via system configuration parameter disable\_clear\_all.</li>
<li><code>authorization</code> - No longer used. User can pass an empty string.</li>
</ul>
