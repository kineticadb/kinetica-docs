<p>Delete matching records from a dataset</p>
<p>Deletes record(s) matching the provided criteria from the given table. The record selection criteria can either be one or more <code>expressions</code> (matching multiple records), a single record identified by record\_id options, or all records when using delete\_all\_records. Note that the three selection criteria are mutually exclusive. This operation cannot be run on a view. The operation is synchronous meaning that a response will not be available until the request is completely processed and all the matching records are deleted.</p>
<h5 id="arguments-181">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of the table from which to delete records, in \[schema\_name.\]table\_name format, using standard name resolution rules. Must contain the name of an existing table; not applicable to views.</li>
<li><code>expressions</code> - A list of the actual predicates, one for each select; format should follow the guidelines provided here. Specifying one or more <code>expressions</code> is mutually exclusive to specifying record\_id in the <code>options</code>.</li>
</ul>
