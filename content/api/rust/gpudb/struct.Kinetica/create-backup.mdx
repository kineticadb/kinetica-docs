<p>Create a database backup</p>
<p>Creates a database backup, containing a snapshot of existing objects, at the remote file store accessible via the data sink specified by <code>datasink\_name</code>.</p>
<h5 id="arguments-115">Arguments</h5>
<ul>
<li><code>backup\_name</code> - Name for this backup. If the backup already exists, only an incremental or differential backup can be made, unless recreate is set to true.</li>
<li><code>backup\_type</code> - Type of snapshot to create.</li>
<li><code>backup\_objects\_map</code> - Map of objects to be captured in the backup; must be specified when creating a full snapshot and left unspecified when creating an incremental or differential snapshot.</li>
<li><code>datasink\_name</code> - Data sink through which the backup will be stored.</li>
</ul>
