<div className="docblock">
<p>Submits a request to the Kinetica server with HA failover support.</p>
<p>This method implements HA failover:</p>
<ul>
<li>Captures the current cluster switch count before attempting the request</li>
<li>On connection errors, attempts to switch to the next available cluster</li>
<li>Retries the request on the new cluster</li>
<li>Propagates API errors (server-side errors) without failover</li>
</ul>
<h5 id="arguments-2">Arguments</h5>
<ul>
<li><code>endpoint</code> - The API endpoint (e.g., “/show/table”)</li>
<li><code>req\_schema</code> - Pre-parsed Avro schema for the request</li>
<li><code>resp\_schema</code> - Pre-parsed Avro schema for the response</li>
<li><code>request</code> - The request object</li>
</ul>
<h5 id="returns-5">Returns</h5>
<p>The response object, or an error if the request fails on all clusters.</p>
