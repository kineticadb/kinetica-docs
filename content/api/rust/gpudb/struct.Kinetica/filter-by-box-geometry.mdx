<p>Filter a dataset for geospatial geometry objects intersecting a rectangle’s boundary</p>
<p>Calculates which geospatial geometry objects from a table intersect a rectangular box. The operation is synchronous, meaning that a response will not be returned until all the objects are fully available. The response payload provides the count of the resulting set. A new resultant set which satisfies the input NAI restriction specification is also created when a <code>view\_name</code> is passed in as part of the input payload.</p>
<h5 id="arguments-229">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of the table on which the bounding box operation will be performed, in \[schema\_name.\]table\_name format, using standard name resolution rules. Must be an existing table.</li>
<li><code>view\_name</code> - If provided, then this will be the name of the view containing the results, in \[schema\_name.\]view\_name format, using standard name resolution rules and meeting table naming criteria. Must not be an already existing table or view.</li>
<li><code>column\_name</code> - Name of the geospatial geometry column to be filtered.</li>
<li><code>min\_x</code> - Lower bound for the x-coordinate of the rectangular box. Must be less than or equal to <code>max\_x</code>.</li>
<li><code>max\_x</code> - Upper bound for the x-coordinate of the rectangular box. Must be greater than or equal to <code>min\_x</code>.</li>
<li><code>min\_y</code> - Lower bound for the y-coordinate of the rectangular box. Must be less than or equal to <code>max\_y</code>.</li>
<li><code>max\_y</code> - Upper bound for the y-coordinate of the rectangular box. Must be greater than or equal to <code>min\_y</code>.</li>
</ul>
