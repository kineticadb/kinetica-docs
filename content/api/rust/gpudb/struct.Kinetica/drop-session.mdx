<p>Drop the objects owned by a session</p>
<p>Ends the client session named by the X-Kinetica-Session HTTP header of this request, dropping every session temp table (a table created in SQL as #name) that belongs to it. Objects outside the session that depend on those tables are invalidated, not dropped.</p>
<p>A client sends its session ID in the X-Kinetica-Session HTTP header to every endpoint (e.g., /execute/sql), and needs to call this endpoint only when a response’s info map has carried session\_id\_used set to true.</p>
<p>Only the user that owns the session, or a system administrator, may drop it. Dropping an unknown session is a no-op.</p>
