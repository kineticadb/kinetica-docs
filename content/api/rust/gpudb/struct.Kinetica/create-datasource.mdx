<p>Create a data source</p>
<p>Creates a data source, which contains the location and connection information for a data store that is external to the database.</p>
<h5 id="arguments-125">Arguments</h5>
<ul>
<li>
<p><code>name</code> - Name of the data source to be created.</p>
</li>
<li>
<p><code>location</code> - Location of the remote storage in ‘storage\_provider\_type://\[storage\_path\[:storage\_port\]\]’ format.</p>
<p>Supported storage provider types are ‘azure’, ‘gcs’, ‘hdfs’, ‘jdbc’, ‘kafka’, ‘confluent’, and ‘s3’.</p>
</li>
<li>
<p><code>user\_name</code> - Name of the remote system user; may be an empty string.</p>
</li>
<li>
<p><code>password</code> - Password for the remote system user; may be an empty string.</p>
</li>
</ul>
