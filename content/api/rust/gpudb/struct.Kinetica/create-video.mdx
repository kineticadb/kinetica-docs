<p>Create a video.</p>
<p>Creates a job to generate a sequence of raster images that visualize data over a specified time.</p>
<h5 id="arguments-171">Arguments</h5>
<ul>
<li><code>attribute</code> - The animated attribute to map to the video’s frames. Must be present in the LAYERS specified for the visualization. This is often a time-related field but may be any numeric type.</li>
<li><code>begin</code> - The start point for the video. Accepts an expression evaluable over the <code>attribute</code>.</li>
<li><code>duration\_seconds</code> - Seconds of video to produce.</li>
<li><code>end</code> - The end point for the video. Accepts an expression evaluable over the <code>attribute</code>.</li>
<li><code>frames\_per\_second</code> - The presentation frame rate of the encoded video in frames per second.</li>
<li><code>style</code> - The name of the visualize mode; should correspond to the schema used for the <code>style\_parameters</code> field.</li>
<li><code>path</code> - Fully-qualified KiFS path. Write access is required. A file must not exist at that path, unless replace\_if\_exists is true.</li>
<li><code>style\_parameters</code> - A string containing the JSON-encoded visualize request. Must correspond to the visualize mode specified in the <code>style</code> field.</li>
</ul>
