<p>Collect statistics on a column.</p>
<p>Collect statistics for a column(s) in a specified table.</p>
<h5 id="arguments-113">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of a table, in \[schema\_name.\]table\_name format, using standard name resolution rules. Must be an existing table. A value of ‘<span className="em">’ collects statistics on every user table the caller may read (excluding system schemas, views, and temporary tables); when used, <code>column\_names</code> must be ‘</span>’.</li>
<li><code>column\_names</code> - List of one or more column names in <code>table\_name</code> for which to collect statistics (cardinality, mean value, etc.). A single entry of ‘\*’ expands to every collectable column on the table (geometry, vector, JSON, and array columns are skipped).</li>
</ul>
