<p>Show the statuses of running or completed proc instances.</p>
<p>Shows the statuses of running or completed proc instances. Results are grouped by run ID (as returned from <code>/execute/proc</code>) and data segment ID (each invocation of the proc command on a data segment is assigned a data segment ID).</p>
<h5 id="arguments-367">Arguments</h5>
<ul>
<li><code>run\_id</code> - The run ID of a specific proc instance for which the status will be returned. If a proc with a matching run ID is not found, the response will be empty. If not specified, the statuses of all executed proc instances will be returned.</li>
</ul>
