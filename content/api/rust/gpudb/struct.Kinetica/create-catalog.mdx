<p>Create a catalog</p>
<p>Creates a catalog, which contains the location and connection information for a deltalake catalog that is external to the database.</p>
<h5 id="arguments-117">Arguments</h5>
<ul>
<li><code>name</code> - Name of the catalog to be created.</li>
<li><code>table\_format</code> - Table format (iceberg, hudi, deltalake).</li>
<li><code>location</code> - Location of the catalog in ‘http\[s\]://\[server\[:port\]\]\]’ format.</li>
<li><code>r#type</code> - Type of the catalog (REST (unity, polaris, tabular), nessie, hive, glue).</li>
<li><code>credential</code> - Name of the credential object to be used in catalog.</li>
<li><code>datasource</code> - Password for the remote system user; may be an empty string.</li>
