<p>Filter a dataset for records falling within a 2-D polygon’s boundary</p>
<p>Calculates which objects from a table are within a named area of interest (NAI/polygon). The operation is synchronous, meaning that a response will not be returned until all the matching objects are fully available. The response payload provides the count of the resulting set. A new resultant set (view) which satisfies the input NAI restriction specification is created with the name <code>view\_name</code> passed in as part of the input.</p>
<h5 id="arguments-223">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of the table to filter, in \[schema\_name.\]table\_name format, using standard name resolution rules. This may be the name of a table or a view (when chaining queries).</li>
<li><code>view\_name</code> - If provided, then this will be the name of the view containing the results, in \[schema\_name.\]view\_name format, using standard name resolution rules and meeting table naming criteria. Must not be an already existing table or view.</li>
<li><code>x\_column\_name</code> - Name of the column containing the x values to be filtered.</li>
<li><code>x\_vector</code> - List of x coordinates of the vertices of the polygon representing the area to be filtered.</li>
<li><code>y\_column\_name</code> - Name of the column containing the y values to be filtered.</li>
<li><code>y\_vector</code> - List of y coordinates of the vertices of the polygon representing the area to be filtered.</li>
</ul>
