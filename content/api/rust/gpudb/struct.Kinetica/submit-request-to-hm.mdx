<div className="docblock">
<p>Submits a request to the host manager of the cluster in use: once, with no fail-over.</p>
<p>The generated host manager endpoints (<code>/admin/add/host</code>, <code>/admin/alter/host</code>, <code>/admin/remove/host</code>, <code>/admin/show/alerts</code> and <code>/admin/switchover</code>) come through here. They name hosts and ranks within the cluster they are sent to, so a failure goes back to the caller rather than replaying the operation on another cluster.</p>
