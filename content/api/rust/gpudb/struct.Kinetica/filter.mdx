<div className="docblock">
<p>Filter a dataset for records matching an expression</p>
<p>Filters data based on the specified expression. The results are stored in a result set with the given <code>view\_name</code>.</p>
<p>For details see Expressions.</p>
<p>The response message contains the number of points for which the expression evaluated to be true, which is equivalent to the size of the result view.</p>
<h5 id="arguments-221">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of the table to filter, in \[schema\_name.\]table\_name format, using standard name resolution rules. This may be the name of a table or a view (when chaining queries).</li>
<li><code>view\_name</code> - If provided, then this will be the name of the view containing the results, in \[schema\_name.\]view\_name format, using standard name resolution rules and meeting table naming criteria. Must not be an already existing table or view.</li>
<li><code>expression</code> - The select expression to filter the specified table. For details see Expressions.</li>
</ul>
