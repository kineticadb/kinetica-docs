<div className="docblock">
<p>Creates a new Kinetica client instance with full initialization.</p>
<p>This constructor performs the full initialization sequence:</p>
<ul>
<li>Parses and validates URLs</li>
<li>Discovers cluster information (unless auto-discovery is disabled)</li>
<li>Sets up HA failover configuration</li>
<li>Checks connectivity: fails over from a first cluster that is not usable, then reads the server version from the cluster selected, and fails if either cannot be done</li>
</ul>
<h5 id="arguments">Arguments</h5>
<ul>
<li><code>urls</code> - List of URLs to connect to (e.g., <code>vec!\["http://localhost:9191".to\_string()\]</code>)</li>
<li><code>options</code> - Configuration options including credentials and connection settings</li>
</ul>
<h5 id="returns">Returns</h5>
<p>Returns a fully initialized <code>Kinetica</code> instance or an error if initialization fails.</p>
<h5 id="example-1">Example</h5>
<div>

```rust
use gpudb_api::{Kinetica, KineticaOptions};
use std::sync::Arc;

let mut options = KineticaOptions::new();
options.set_username("admin")
       .set_password("password")
       .set_use_snappy(true);

let kinetica = Arc::new(
    Kinetica::new(vec!["http://localhost:9191".to_string()], options).await?
);
```
