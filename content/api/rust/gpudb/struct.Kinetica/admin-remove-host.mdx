<p>Removes a host from the cluster.</p>
<p>Removes a host from an existing cluster. If the host to be removed has any ranks running on it, the ranks must be removed using <code>/admin/remove/ranks</code> or manually switched over to a new host using <code>/admin/switchover</code> prior to host removal. If the host to be removed has the graph server or SQL planner running on it, these must be manually switched over to a new host using <code>/admin/switchover</code>.</p>
<h5 id="arguments-20">Arguments</h5>
<ul>
<li><code>host</code> - Identifies the host this applies to. Can be the host address, or formatted as ‘hostN’ where N is the host number as specified in gpudb.conf.</li>
</ul>
