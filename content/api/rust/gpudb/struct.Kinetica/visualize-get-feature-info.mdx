<p>Retrieve the underlying data for a pixel location on a rasterized image.</p>
<p>For internal use only.</p>
<h5 id="arguments-410">Arguments</h5>
<ul>
<li><code>table\_names</code> - Names of the tables containing the data to be retrieved.</li>
<li><code>x\_column\_names</code> - For each table, name of the column containing X coordinates, if applicable, empty string otherwise.</li>
<li><code>y\_column\_names</code> - For each table, name of the column containing Y coordinates, if applicable, empty string otherwise.</li>
<li><code>geometry\_column\_names</code> - For each table, name of the column containing geometry data, if applicable, empty string otherwise.</li>
<li><code>query\_column\_names</code> - For each table, list of names of the columns to retrieve; ‘\*’ indicates all columns in the table other than the geometry column (which may be requested directly if desired).</li>
<li><code>projection</code> - Projection of the spatial data in the image.</li>
<li><code>min\_x</code> - Lower bound of the projected X coordinates in the image.</li>
<li><code>max\_x</code> - Upper bound of the projected X coordinates in the image.</li>
<li><code>min\_y</code> - Lower bound of the projected Y coordinates in the image.</li>
<li><code>max\_y</code> - Upper bound of the projected Y coordinates in the image.</li>
<li><code>width</code> - Width of the image in pixels.</li>
<li><code>height</code> - Height of the image in pixels.</li>
<li><code>x</code> - Pixel X coordinate within the image for which to retrieve data.</li>
<li><code>y</code> - Pixel Y coordinate within the image for which to retrieve data.</li>
<li><code>radius</code> - Radius in pixels around the X and Y coordinates for which to retrieve data.</li>
<li><code>limit</code> - The maximum number of results to be returned, or END\_OF\_SET (-9999) for the maximum allowed by the server.</li>
<li><code>encoding</code> - Encoding for returned records.</li>
</ul>
