<p>Clears statistics for column(s) in a table.</p>
<p>Clears statistics (cardinality, mean value, etc.) for a column in a specified table.</p>
<h5 id="arguments-103">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of a table, in \[schema\_name.\]table\_name format, using standard name resolution rules. Must be an existing table. A value of ‘\*’ clears statistics on every user table the caller may read (excluding system schemas, views, and temporary tables); when used, <code>column\_name</code> must be empty.</li>
<li><code>column\_name</code> - Name of the column in <code>table\_name</code> for which to clear statistics. The column must be from an existing table. An empty string clears statistics for all columns in the table. Must be empty when <code>table\_name</code> is ‘\*’.</li>
</ul>
