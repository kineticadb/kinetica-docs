<p>Delete tables</p>
<p>Clears (drops) tables in the database cluster. The operation is synchronous meaning that the tables will be cleared before the function returns. The response payload returns the status of the operation for each table requested.</p>
<h5 id="arguments-109">Arguments</h5>
<ul>
<li><code>table\_names</code> - Names of the tables to be cleared, in \[schema\_name.\]table\_name format, using standard name resolution rules. Must be existing tables. Empty list clears all available tables, though this behavior is prevented by default via system configuration parameter disable\_clear\_all.</li>
</ul>
