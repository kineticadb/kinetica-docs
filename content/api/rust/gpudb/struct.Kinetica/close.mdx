<div className="docblock">
<p>Closes this connection: drops the SQL <code>#name</code> temp tables it created, if any, and stops it sending requests. Closing a closed connection does nothing.</p>
<p>The drop goes through <a href="/content/api/rust/gpudb/struct.Kinetica/drop-session#method.drop_session" title="method gpudb_api::gpudb::Kinetica::drop_session"><code>Self::drop\_session</code></a>, failing over as any request does; a failure is logged, not returned, since the server reclaims the session on its own. It is skipped where no temp table was created, and against a server that does not support session temp tables, which never reports one. A session given by <a href="/content/api/rust/gpudb/struct.KineticaOptions#structfield.session_id" title="field gpudb_api::gpudb::KineticaOptions::session_id"><code>KineticaOptions::session\_id</code></a> is not dropped: the caller drops it with <a href="/content/api/rust/gpudb/struct.Kinetica/drop-session#method.drop_session" title="method gpudb_api::gpudb::Kinetica::drop_session"><code>Self::drop\_session</code></a>.</p>
<p>After this every request fails, at once and without failing over. The fail-back poller is stopped. A connection that is never closed has its session dropped when it is dropped, on a best-effort basis; closing it is what makes the drop prompt.</p>
