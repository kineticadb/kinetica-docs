<div className="docblock">
<p>Find unique values in a column</p>
<p>Returns all the unique values from a particular column (specified by <code>column\_name</code>) of a particular table or view (specified by <code>table\_name</code>). If <code>column\_name</code> is a numeric column, the values will be in <code>binary\_encoded\_response</code>. Otherwise if <code>column\_name</code> is a string column, the values will be in <code>json\_encoded\_response</code>. The results can be paged via <code>offset</code> and <code>limit</code> parameters.</p>
<div>

```text
{"limit":"10","sort_order":"descending"}
```

</div>
<p>The response is returned as a dynamic schema. For details see: dynamic schemas documentation.</p>
<p>If a result\_table name is specified in the <code>options</code>, the results are stored in a new table with that name–no results are returned in the response. Both the table name and resulting column name must adhere to standard naming conventions; any column expression will need to be aliased. If the source table’s shard key is used as the <code>column\_name</code>, the result table will be sharded, in all other cases it will be replicated. Sorting will properly function only if the result table is replicated or if there is only one processing node and should not be relied upon in other cases. Not available if the value of <code>column\_name</code> is an unrestricted-length string.</p>
<h5 id="arguments-55">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of an existing table or view on which the operation will be performed, in \[schema\_name.\]table\_name format, using standard name resolution rules.</li>
<li><code>column\_name</code> - Name of the column or an expression containing one or more column names on which the unique function would be applied.</li>
<li><code>offset</code> - A positive integer indicating the number of initial results to skip (this can be useful for paging through the results).</li>
<li><code>limit</code> - A positive integer indicating the maximum number of results to be returned, or END\_OF\_SET (-9999) to indicate that the maximum number of results allowed by the server should be returned. The number of records returned will never exceed the server’s own limit, defined by the max\_get\_records\_size parameter in the server configuration. Use <code>has\_more\_records</code> to see if more records exist in the result to be fetched, and <code>offset</code> and <code>limit</code> to request subsequent pages of results.</li>
</ul>
