<p>Generate ‘class break’ rasterized image tiles</p>
<p>For internal use only. Generates ‘class break’ rasterized image tiles for an area of interest using the given tables and the provided parameters.</p>
<p>A class break rendering is where data from one or more tables is rasterized with styling applied on a per-class basis. Class breaks based on one or more data columns are supported. Distinct values (for strings) or ranges (for numeric attributes) must be provided in the cb\_column\_name1/cb\_vals1 and cb\_column\_name2/cb\_vals2 parameters. The styling parameters must be specified for each class.</p>
<p>All color values must be in the format RRGGBB or AARRGGBB (to specify the alpha value).</p>
<h5 id="arguments-416">Arguments</h5>
<ul>
<li><code>table\_names</code> - Name of the table containing the data for the various layers to be rendered.</li>
<li><code>world\_table\_names</code> - Optional name of the tables containing the data for the entire track when the <code>table\_names</code> contains only part of the track data, but the entire track has to be rendered.</li>
<li><code>x\_column\_name</code> - Name of the column containing the x coordinates.</li>
<li><code>y\_column\_name</code> - Name of the column containing the y coordinates.</li>
<li><code>symbol\_column\_name</code> - Name of the column containing the symbol code coordinates.</li>
<li><code>geometry\_column\_name</code> - Name of the column containing geometry data.</li>
<li><code>track\_ids</code> - Tracks from the <code>table\_names</code> to be rendered.</li>
<li><code>cb\_attr</code> - Name of the column for the generic class break.</li>
<li><code>cb\_vals</code> - A list of class break values or ranges (e.g. ‘0:5,5:10,15:30’).</li>
<li><code>cb\_pointcolor\_attr</code> - Name of the column for the point color class break.</li>
<li><code>cb\_pointcolor\_vals</code> - A list of class break values or ranges (e.g. ‘0:5,5:10,15:30’).</li>
<li><code>cb\_pointalpha\_attr</code> - Name of the column for the point alpha class break.</li>
<li><code>cb\_pointalpha\_vals</code> - A list of class break values or ranges (e.g. ‘0:5,5:10,15:30’).</li>
<li><code>cb\_pointsize\_attr</code> - Name of the column for the point size class break.</li>
<li><code>cb\_pointsize\_vals</code> - A list of class break values or ranges (e.g. ‘0:5,5:10,15:30’).</li>
<li><code>cb\_pointshape\_attr</code> - Name of the column for the point shape class break.</li>
<li><code>cb\_pointshape\_vals</code> - A list of class break values or ranges (e.g. ‘0:5,5:10,15:30’).</li>
<li><code>min\_x</code> - Lower bound for the x values.</li>
<li><code>max\_x</code> - Upper bound for the x values.</li>
<li><code>min\_y</code> - Lower bound for the y values.</li>
<li><code>max\_y</code> - Upper bound for the y values.</li>
<li><code>width</code> - Width of the generated image.</li>
<li><code>height</code> - Height of the generated image.</li>
<li><code>projection</code> - Spatial Reference System (i.e. EPSG Code).</li>
<li><code>bg\_color</code> - Background color of the generated image.</li>
<li><code>style\_options</code> - Styling options for the image.</li>
<li><code>cb\_transparency\_vec</code> - Used for internal purpose. Indicating the color of each class is semi-transparent or not (0: opaque or completely transparent, 1: semi-transparent).</li>
</ul>
