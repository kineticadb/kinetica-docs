<div className="docblock">
<p>Retrieve the values of the given columns within a specified range.</p>
<p>For a given table, retrieves the values from the requested column(s). Maps of column name to the array of values as well as the column data type are returned. This endpoint supports pagination with the <code>offset</code> and <code>limit</code> parameters.</p>
<p>Window functions, which can perform operations like moving averages, are available through this endpoint as well as <code>/create/projection</code>.</p>
<p>When using pagination, if the table (or the underlying table in the case of a view) is modified (records are inserted, updated, or deleted) during a call to the endpoint, the records or values retrieved may differ between calls based on the type of the update, e.g., the contiguity across pages cannot be relied upon.</p>
<p>If <code>table\_name</code> is empty, selection is performed against a single-row virtual table. This can be useful in executing temporal (NOW()), identity (USER()), or constant-based functions (GEODIST(-77.11, 38.88, -71.06, 42.36)).</p>
<p>The response is returned as a dynamic schema. For details see: dynamic schemas documentation.</p>
<h5 id="arguments-256">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of the table or view on which this operation will be performed, in \[schema\_name.\]table\_name format, using standard name resolution rules. An empty table name retrieves one record from a single-row virtual table, where columns specified should be constants or constant expressions.</li>
<li><code>column\_names</code> - The list of column values to retrieve.</li>
<li><code>offset</code> - A positive integer indicating the number of initial results to skip (this can be useful for paging through the results).</li>
<li><code>limit</code> - A positive integer indicating the maximum number of results to be returned, or END\_OF\_SET (-9999) to indicate that the maximum number of results allowed by the server should be returned. The number of records returned will never exceed the server’s own limit, defined by the max\_get\_records\_size parameter in the server configuration. Use <code>has\_more\_records</code> to see if more records exist in the result to be fetched, and <code>offset</code> and <code>limit</code> to request subsequent pages of results.</li>
</ul>
