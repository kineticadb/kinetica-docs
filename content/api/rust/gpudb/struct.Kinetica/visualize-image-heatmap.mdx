<p>Generate rasterized heatmap image tiles</p>
<p>For internal use only. Generates rasterized heatmap image tiles for an area of interest using the given tables and the provided parameters.</p>
<p>All color values must be in the format RRGGBB or AARRGGBB (to specify the alpha value).</p>
<h5 id="arguments-420">Arguments</h5>
<ul>
<li><code>table\_names</code> - Name of the table containing the data for the various layers to be rendered.</li>
<li><code>x\_column\_name</code> - Name of the column containing the x coordinates.</li>
<li><code>y\_column\_name</code> - Name of the column containing the y coordinates.</li>
<li><code>value\_column\_name</code></li>
<li><code>geometry\_column\_name</code> - Name of the column containing geometry data.</li>
<li><code>min\_x</code> - Lower bound for the x values.</li>
<li><code>max\_x</code> - Upper bound for the x values.</li>
<li><code>min\_y</code> - Lower bound for the y values.</li>
<li><code>max\_y</code> - Upper bound for the y values.</li>
<li><code>width</code> - Width of the generated image.</li>
<li><code>height</code> - Height of the generated image.</li>
<li><code>projection</code> - Spatial Reference System (i.e. EPSG Code).</li>
<li><code>style\_options</code> - Various style related options.</li>
</ul>
