<p>Rotate column values into rows values.</p>
<p>Rotate the column values into rows values.</p>
<p>For unpivot details and examples, see Unpivot. For limitations, see Unpivot Limitations.</p>
<p>Unpivot is used to normalize tables that are built for cross tabular reporting purposes. The unpivot operator rotates the column values for all the pivoted columns. A variable column, value column and all columns from the source table except the unpivot columns are projected into the result table. The variable column and value columns in the result table indicate the pivoted column name and values respectively.</p>
<p>The response is returned as a dynamic schema. For details see: dynamic schemas documentation.</p>
<h5 id="arguments-57">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of the table on which the operation will be performed. Must be an existing table/view, in \[schema\_name.\]table\_name format, using standard name resolution rules.</li>
<li><code>column\_names</code> - List of column names or expressions. A wildcard ‘\*’ can be used to include all the non-pivoted columns from the source table.</li>
<li><code>variable\_column\_name</code> - Specifies the variable/parameter column name.</li>
<li><code>value\_column\_name</code> - Specifies the value column name.</li>
<li><code>pivoted\_columns</code> - List of one or more values typically the column names of the input table. All the columns in the source table must have the same data type.</li>
</ul>
