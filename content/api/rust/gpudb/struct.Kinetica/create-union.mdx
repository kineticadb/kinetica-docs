<p>Create a table that is the merge of one or more tables</p>
<p>Merges data from one or more tables with comparable data types into a new table.</p>
<p>The following merges are supported:</p>
<p>UNION (DISTINCT/ALL) - For data set union details and examples, see Union. For limitations, see Union Limitations and Cautions.</p>
<p>INTERSECT (DISTINCT/ALL) - For data set intersection details and examples, see Intersect. For limitations, see Intersect Limitations.</p>
<p>EXCEPT (DISTINCT/ALL) - For data set subtraction details and examples, see Except. For limitations, see Except Limitations.</p>
<h5 id="arguments-165">Arguments</h5>
<ul>
<li><code>table\_name</code> - Name of the table to be created, in \[schema\_name.\]table\_name format, using standard name resolution rules and meeting table naming criteria.</li>
<li><code>table\_names</code> - The list of table names to merge, in \[schema\_name.\]table\_name format, using standard name resolution rules. Must contain the names of one or more existing tables.</li>
<li><code>input\_column\_names</code> - The list of columns from each of the corresponding input tables.</li>
<li><code>output\_column\_names</code> - The list of names of the columns to be stored in the output table.</li>
