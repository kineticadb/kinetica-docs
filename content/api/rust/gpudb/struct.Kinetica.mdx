<div className="docblock">
<p>The main Kinetica client for communicating with a Kinetica database.</p>
<p>This client is thread-safe and can be shared across tasks using <code>Arc&lt;Kinetica&gt;</code>.</p>
<h2 id="performance">Performance</h2>
<ul>
<li>Uses connection pooling for efficient reuse of HTTP connections</li>
<li>Enables TCP\_NODELAY for lower latency</li>
<li>Supports parallel requests via async/await</li>
</ul>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::{Kinetica, KineticaOptions};
use std::sync::Arc;

let mut options = KineticaOptions::new();
options.set_username("admin")
       .set_password("password")
       .set_use_snappy(true);

let kinetica = Arc::new(
    Kinetica::new(vec!["http://localhost:9191".to_string()], options).await?
);
```
