<p>The high availability synchronicity override sent with each request. Anything but <code>Default</code> is sent as the <code>X-Kinetica-Group</code> header.</p>
</div>
</div>
<h2 id="variants" className="variants section-header">Variants</h2>
<div className="variants">
<div id="variant.Default" className="section variant">
<h3 className="code-header">Default</h3>
</div>
<div className="docblock">
<p>No override; the HA process decides which endpoints are synchronous.</p>
</div>
<div id="variant.None" className="section variant">
<h3 className="code-header">None</h3>
</div>
<div className="docblock">
<p>Do not replicate the endpoint calls.</p>
</div>
<div id="variant.Synchronous" className="section variant">
<h3 className="code-header">Synchronous</h3>
</div>
<div className="docblock">
<p>Execute the query locally, then send it to each cluster in turn.</p>
</div>
<div id="variant.SynchronousParallel" className="section variant">
<h3 className="code-header">SynchronousParallel</h3>
</div>
<div className="docblock">
<p>Send the query to each cluster and execute it locally, at once.</p>
</div>
<div id="variant.Asynchronous" className="section variant">
<h3 className="code-header">Asynchronous</h3>
</div>
<div className="docblock">
<p>Execute the query locally, then queue it for each cluster.</p>
</div>
<div id="variant.AsynchronousParallel" className="section variant">
<h3 className="code-header">AsynchronousParallel</h3>
</div>
<div className="docblock">
<p>Queue the query for each cluster and execute it locally, at once.</p>
</div>
</div>
