<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::avro_schema_builder::{TypePropertiesBuilder, KineticaColumnProperties};

let props = TypePropertiesBuilder::new()
    .column("id", KineticaColumnProperties::new().primary_key())
    .column("timestamp", KineticaColumnProperties::new().timestamp())
    .column("name", KineticaColumnProperties::new().char_n(64))
    .column("data", KineticaColumnProperties::new().data())
    .build();
```

<div className="docblock">
<p>Adds column properties for the given column name</p>
<p>Properties accumulate: calling this (or <a href="/content/api/rust/avro_schema_builder/struct.TypePropertiesBuilder#method.column_property" title="method gpudb_api::avro_schema_builder::TypePropertiesBuilder::column_property"><code>column\_property</code></a> or any shorthand such as <a href="/content/api/rust/avro_schema_builder/struct.TypePropertiesBuilder#method.primary_key" title="method gpudb_api::avro_schema_builder::TypePropertiesBuilder::primary_key"><code>primary\_key</code></a>) again for the same column appends to that column’s list rather than replacing it, so <code>.primary\_key("id").shard\_key("id")</code> yields <code>\["primary\_key", "shard\_key"\]</code>. A property already present on the column is not added a second time; the first-seen order is kept.</p>
</div>
