<div className="docblock">
<p>Builds the schema and leaks it to get a <code>&amp;'static str</code></p>
<p>This is useful for implementing <code>KineticaRecord::avro\_schema()</code> which requires returning <code>&amp;'static str</code>. The memory is intentionally leaked since schemas are typically created once and live for the program’s lifetime.</p>
<h5 id="example-1">Example</h5>
<div>

```rust
use gpudb_api::avro_schema_builder::{AvroSchemaBuilder, AvroType};

let schema: &'static str = AvroSchemaBuilder::new("MyRecord")
    .int_field("id")
    .string_field("name")
    .build_static();
```
