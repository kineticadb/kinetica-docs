<p>The <code>Authorization</code> header to send: <code>Bearer &lt;token&gt;</code> when an OAuth token is set, otherwise <code>Basic</code> with the credentials when the username or the password is set, and no header at all when neither is.</p>
<p>The credentials are encoded as UTF-8.</p>
