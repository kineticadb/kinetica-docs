<div className="docblock">
<p>Sends a POST request like <a href="/content/api/rust/hyper_client/struct.HyperClient#method.post_binary_with_compression" title="method gpudb_api::hyper_client::HyperClient::post_binary_with_compression"><code>Self::post\_binary\_with\_compression</code></a>, but returns the response whatever its status, for the caller to interpret.</p>
<p>Failures are classified as follows:</p>
<ul>
<li>Failing to send the request or to receive a response, including a timeout, is a <a href="/content/api/rust/errors/enum.KineticaError#variant.Connection" title="variant gpudb_api::errors::KineticaError::Connection"><code>KineticaError::Connection</code></a>, which fails over.</li>
<li>A TLS failure is a <a href="/content/api/rust/errors/enum.KineticaError#variant.Config" title="variant gpudb_api::errors::KineticaError::Config"><code>KineticaError::Config</code></a>, which does not: another cluster would present the same certificate problem.</li>
<li>Failing to read the body, including a timeout, is a <a href="/content/api/rust/errors/enum.KineticaError#variant.Http" title="variant gpudb_api::errors::KineticaError::Http"><code>KineticaError::Http</code></a>.</li>
</ul>
<p>Before any of that, a failed send or a 502 or 503 is retried up to <a href="/content/api/rust/hyper_client/struct.HttpClientConfig#structfield.max_retries" title="field gpudb_api::hyper_client::HttpClientConfig::max_retries"><code>HttpClientConfig::max\_retries</code></a> times; the last outcome is what is classified.</p>
</div>
