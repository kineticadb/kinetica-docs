<div className="docblock">
<p>A response as received, before its status is interpreted.</p>
<p>Kinetica can report an error with a non-2xx status and still send an Avro body that says what went wrong, so the caller needs both; see <code>Kinetica::submit\_request\_raw</code>, which interprets them.</p>
