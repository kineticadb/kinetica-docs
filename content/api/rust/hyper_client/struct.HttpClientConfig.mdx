</div>
<span id="structfield.max_retries" className="structfield section-header"><code>max\_retries: <a className="primitive" href="https://doc.rust-lang.org/1.98.1/std/primitive.usize.html">usize</a></code></span>
<div className="docblock">
<p>How many times an API request is retried, at once and on the same server: when sending it fails without a response (the connection is refused, reset or closed, the host is unknown, or no response arrives within the timeout), or the response is a 502 or 503. A connect timeout, a TLS failure or a failure reading the response body is not retried, and neither are health checks.</p>
</div>

<div className="docblock">
<p>Takes the connection settings from <code>options</code>:</p>
<ul>
<li><code>server\_connection\_timeout</code> is the connect timeout,</li>
<li><code>timeout</code> is the request timeout,</li>
<li><code>max\_connections\_per\_host</code> and <code>max\_total\_connections</code> cap the requests in flight.</li>
</ul>
<p>A timeout of 0 means no limit. A connection limit below 1, which <code>Kinetica</code> refuses, is raised to 1 here for a configuration built some other way.</p>
</div>
