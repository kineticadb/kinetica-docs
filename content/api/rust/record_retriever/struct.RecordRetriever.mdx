<div className="docblock">
<p>Object that permits efficient retrieval of records from GPUdb, with support for multi-head access.</p>
<p><code>RecordRetriever</code> instances are thread safe and may be used from any number of tasks simultaneously. Records are returned as <code>R</code>: <a href="/content/api/rust/generic_record/struct.GenericRecord" title="struct gpudb_api::generic_record::GenericRecord"><code>GenericRecord</code></a>s by default, or any type serde can deserialize (see <a href="/content/api/rust/record_retriever/trait.RetrievedRecord" title="trait gpudb_api::record_retriever::RetrievedRecord"><code>RetrievedRecord</code></a>).</p>

<div className="docblock">
<p>Creates a retriever of the records of <code>table\_name</code>, which are of <code>record\_type</code>, returning them as <a href="/content/api/rust/generic_record/struct.GenericRecord" title="struct gpudb_api::generic_record::GenericRecord"><code>GenericRecord</code></a>s.</p>
<p>The worker list is derived from the connection’s own worker addresses, and records are retrieved with no options.</p>
<h5 id="example">Example</h5>
<div>

```rust
use gpudb_api::{Kinetica, KineticaOptions, RecordRetriever, Type};
use std::sync::Arc;

let options = KineticaOptions::new();
let kinetica = Arc::new(
    Kinetica::new(vec!["http://localhost:9191".to_string()], options).await?
);
let record_type = Arc::new(Type::from_table(&kinetica, "my_table").await?);

let retriever = RecordRetriever::new(kinetica, "my_table", record_type).await?;
```

<h4 className="code-header">pub async fn <a href="#method.get_by_key" className="fn">get\_by\_key</a>( &amp;self, key\_values: &amp;\[<a className="enum" href="/content/api/rust/bulk_inserter_common/enum.ShardKeyValue" title="enum gpudb_api::bulk_inserter_common::ShardKeyValue">ShardKeyValue</a>&lt;'\_&gt;\], expression: <a className="enum" href="https://doc.rust-lang.org/1.98.1/core/option/enum.Option.html" title="enum core::option::Option">Option</a>&lt;&amp;<a className="primitive" href="https://doc.rust-lang.org/1.98.1/std/primitive.str.html">str</a>&gt;, ) -&gt; <a className="enum" href="https://doc.rust-lang.org/1.98.1/core/result/enum.Result.html" title="enum core::result::Result">Result</a>&lt;<a className="struct" href="/content/api/rust/generated/api/struct.GetRecordsResponse" title="struct gpudb_api::generated::api::GetRecordsResponse">GetRecordsResponse</a>&lt;R&gt;, <a className="enum" href="/content/api/rust/errors/enum.KineticaError" title="enum gpudb_api::errors::KineticaError">KineticaError</a>&gt;</h4>
</div>
</div>
<div className="docblock">
<p>Retrieves records with the given key values and filter expression.</p>
<p>This method operates in four modes, depending on the parameters passed:</p>
<ul>
<li><strong>key values only</strong>: attempts a direct-to-rank lookup for records matching the given key values</li>
<li><strong>key values and expression</strong>: attempts a direct-to-rank lookup for records matching the given key values, filtering them by the given expression</li>
<li><strong>expression only</strong>: requests, via the head rank, all records in the table matching the given filter expression</li>
<li><strong>neither</strong>: retrieves all records from the table via the head rank</li>
</ul>
<h5 id="arguments">Arguments</h5>
<ul>
<li><code>key\_values</code> - The key values to use for the lookup, one per key column in key order, or none; these must correspond to either the explicit or implicit shard key for sharded tables or the primary key of replicated tables. Each must be of a type its column takes (see <a href="/content/api/rust/record_key_builder/struct.RecordKeyBuilder#method.build_expression" title="method gpudb_api::record_key_builder::RecordKeyBuilder::build_expression"><code>RecordKeyBuilder::build\_expression</code></a>).</li>
<li><code>expression</code> - A filter expression that will be applied to the data requested by the key values; if no key values are specified this filter will be applied to all of the data in the target table</li>
</ul>
<h5 id="returns">Returns</h5>
<p>The requested records, decoded.</p>
