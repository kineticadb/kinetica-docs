<div className="docblock">
<p>A record a <a href="/content/api/rust/record_retriever/struct.RecordRetriever" title="struct gpudb_api::record_retriever::RecordRetriever"><code>RecordRetriever</code></a> returns, decoded from the Avro binary form the server sends by the <a href="/content/api/rust/generic_record/struct.Type" title="struct gpudb_api::generic_record::Type"><code>Type</code></a> the retriever was given.</p>
<p>Implemented for <a href="/content/api/rust/generic_record/struct.GenericRecord" title="struct gpudb_api::generic_record::GenericRecord"><code>GenericRecord</code></a>, and for any type serde can deserialize, whose fields are then read by the names in the type’s Avro schema.</p>
