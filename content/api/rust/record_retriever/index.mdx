<p>Record retriever for efficient record retrieval from Kinetica with multi-head support.</p>
<p>This module provides the <a href="/content/api/rust/record_retriever/struct.RecordRetriever" title="struct gpudb_api::record_retriever::RecordRetriever"><code>RecordRetriever</code></a> struct which allows efficient retrieval of records from GPUdb, with support for multi-head access. <code>RecordRetriever</code> instances are thread safe and may be used from any number of tasks simultaneously.</p>
<p>A retriever is given the <a href="/content/api/rust/generic_record/struct.Type" title="struct gpudb_api::generic_record::Type"><code>Type</code></a> of the table’s records, takes typed key values (<a href="/content/api/rust/bulk_inserter_common/enum.ShardKeyValue" title="enum gpudb_api::bulk_inserter_common::ShardKeyValue"><code>ShardKeyValue</code></a>, with <a href="/content/api/rust/bulk_inserter_common/enum.ShardKeyValue#variant.Null" title="variant gpudb_api::bulk_inserter_common::ShardKeyValue::Null"><code>ShardKeyValue::Null</code></a> for a null), and returns the records decoded: as <a href="/content/api/rust/generic_record/struct.GenericRecord" title="struct gpudb_api::generic_record::GenericRecord"><code>GenericRecord</code></a>s, or as any type serde can deserialize from the type’s Avro schema.</p>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::{Kinetica, KineticaOptions, RecordRetriever, ShardKeyValue, Type};
use std::sync::Arc;

let options = KineticaOptions::new();
let kinetica = Arc::new(
    Kinetica::new(vec!["http://localhost:9191".to_string()], options).await?
);
let record_type = Arc::new(Type::from_table(&kinetica, "my_table").await?);

// Create retriever with default options
let retriever = RecordRetriever::new(kinetica.clone(), "my_table", record_type).await?;

// Retrieve all records
let response = retriever.get_by_key(&[], None).await?;

// Retrieve records by key
let response = retriever.get_by_key(&[ShardKeyValue::Int(123)], None).await?;
for record in &response.data {
    println!("{:?}", record.get(0));
}

// Retrieve with expression filter
let response = retriever.get_by_key(&[], Some("status = 'active'")).await?;
```
