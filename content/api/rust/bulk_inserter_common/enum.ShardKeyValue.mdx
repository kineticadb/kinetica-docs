<p>Typed shard key value to avoid string parsing overhead.</p>
<p>Use typed variants when possible for better performance. String variants are provided for complex types that require parsing.</p>
<h2 id="performance-notes">Performance Notes</h2>
<ul>
<li>Numeric types (<code>Int</code>, <code>Long</code>, <code>Float</code>, <code>Double</code>, <code>Boolean</code>, <code>Int8</code>, <code>Int16</code>) are <code>Copy</code> and zero-cost</li>
<li>String references (<code>String</code>, <code>Date</code>, <code>Ipv4</code>, <code>Decimal</code>, etc.) are borrowed - no allocation</li>
<li>All variants are <code>Copy</code> for zero-cost passing</li>
</ul>
</div>
</div>
