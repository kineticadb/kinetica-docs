<div className="docblock">
<p>Trait for extracting shard key values from a record.</p>
<p>Records must implement this trait to enable shard-aware routing. Returns a SmallVec of (column\_name, typed\_value) pairs for shard key columns.</p>
<h2 id="performance">Performance</h2>
<ul>
<li>Returns <code>ShardKeyValues</code> (SmallVec) which is stack-allocated for up to 4 columns</li>
<li>Use typed variants (<code>Int</code>, <code>Long</code>, <code>Float</code>, <code>Double</code>) when possible to avoid string parsing overhead</li>
<li>The <code>String</code> variants are for string/char columns, and specialized variants (<code>Date</code>, <code>Ipv4</code>, <code>Decimal</code>) handle formatted types</li>
<li>Use the <code>smallvec!</code> macro for convenient construction</li>
</ul>
<h2 id="example">Example</h2>
<div>

```rust
use smallvec::smallvec;
use gpudb_api::{ShardKeyExtractor, ShardKeyValue, ShardKeyValues};

impl ShardKeyExtractor for MyRecord {
    fn shard_key_values(&self) -> ShardKeyValues<'_> {
        smallvec![
            ("id", ShardKeyValue::Int(self.id)),
            ("region", ShardKeyValue::String(&self.region)),
        ]
    }
}
```
