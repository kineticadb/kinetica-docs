<p>Type alias for shard key values - stack-allocated for up to 4 columns (covers most use cases).</p>
<p>Column names may borrow from the record, like the values, so a record whose columns are only known at runtime (such as a <code>GenericRecord</code>) can name them without allocating; a string literal still works, being <code>'static</code>.</p>
