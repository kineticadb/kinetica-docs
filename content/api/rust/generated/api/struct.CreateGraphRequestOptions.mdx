<span id="structfield.add_table_monitor" className="structfield section-header"><code>add\_table\_monitor: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Adds a table monitor to every table used in the creation of the graph; this table monitor will trigger the graph to update dynamically upon inserts to the source table(s). Note that upon database restart, if save\_persist is also set to true, the graph will be fully reconstructed and the table monitors will be reattached. For more details on table monitors, see <code>/create/tablemonitor</code>. Server default: <code>false</code>.</p>
</div>
<span id="structfield.graph_table" className="structfield section-header"><code>graph\_table: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>

</div>
