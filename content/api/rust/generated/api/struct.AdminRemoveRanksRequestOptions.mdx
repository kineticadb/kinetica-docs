<h2 id="fields" className="fields section-header">Fields</h2>
<span id="structfield.rebalance_sharded_data" className="structfield section-header"><code>rebalance\_sharded\_data: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true, sharded data will be rebalanced approximately equally across the cluster. Note that for clusters with large amounts of sharded data, this data transfer could be time consuming and result in delayed query responses. Server default: <code>true</code>.</p>
</div>
<span id="structfield.rebalance_unsharded_data" className="structfield section-header"><code>rebalance\_unsharded\_data: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true, unsharded data (a.k.a. randomly-sharded) will be rebalanced approximately equally across the cluster. Note that for clusters with large amounts of unsharded data, this data transfer could be time consuming and result in delayed query responses. Server default: <code>true</code>.</p>
</div>
<span id="structfield.aggressiveness" className="structfield section-header"><code>aggressiveness: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Influences how much data is moved at a time during rebalance. A higher aggressiveness will complete the rebalance faster. A lower aggressiveness will take longer but allow for better interleaving between the rebalance and other queries. Valid values are constants from 1 (lowest) to 10 (highest). Server default: <code>10</code>.</p>
</div>
