<h2 id="fields" className="fields section-header">Fields</h2>
<span id="structfield.max_solution_radius" className="structfield section-header"><code>max\_solution\_radius: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>For ALLPATHS, SHORTEST\_PATH and INVERSE\_SHORTEST\_PATH solvers only. Sets the maximum solution cost radius, which ignores the <code>destination\_nodes</code> list and instead outputs the nodes within the radius sorted by ascending cost. If set to ‘0.0’, the setting is ignored. Server default: <code>0.0</code>.</p>
</div>
<span id="structfield.min_solution_radius" className="structfield section-header"><code>min\_solution\_radius: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>For ALLPATHS, SHORTEST\_PATH and INVERSE\_SHORTEST\_PATH solvers only. Applicable only when max\_solution\_radius is set. Sets the minimum solution cost radius, which ignores the <code>destination\_nodes</code> list and instead outputs the nodes within the radius sorted by ascending cost. If set to ‘0.0’, the setting is ignored. Server default: <code>0.0</code>.</p>
</div>
<span id="structfield.max_solution_targets" className="structfield section-header"><code>max\_solution\_targets: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>For ALLPATHS, SHORTEST\_PATH and INVERSE\_SHORTEST\_PATH solvers only. Sets the maximum number of solution targets, which ignores the <code>destination\_nodes</code> list and instead outputs no more than n number of nodes sorted by ascending cost where n is equal to the setting value. If set to 0, the setting is ignored. Server default: <code>1000</code>.</p>
</div>
<span id="structfield.uniform_weights" className="structfield section-header"><code>uniform\_weights: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>When specified, assigns the given value to all the edges in the graph. Note that weights provided in <code>weights\_on\_edges</code> will override this value.</p>
</div>
<span id="structfield.left_turn_penalty" className="structfield section-header"><code>left\_turn\_penalty: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>This will add an additional weight over the edges labeled as ‘left turn’ if the ‘add\_turn’ option parameter of the <code>/create/graph</code> was invoked at graph creation. Server default: <code>0.0</code>.</p>
</div>
<span id="structfield.right_turn_penalty" className="structfield section-header"><code>right\_turn\_penalty: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>This will add an additional weight over the edges labeled as’ right turn’ if the ‘add\_turn’ option parameter of the <code>/create/graph</code> was invoked at graph creation. Server default: <code>0.0</code>.</p>
</div>
<span id="structfield.intersection_penalty" className="structfield section-header"><code>intersection\_penalty: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>This will add an additional weight over the edges labeled as ‘intersection’ if the ‘add\_turn’ option parameter of the <code>/create/graph</code> was invoked at graph creation. Server default: <code>0.0</code>.</p>
</div>
<span id="structfield.sharp_turn_penalty" className="structfield section-header"><code>sharp\_turn\_penalty: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>This will add an additional weight over the edges labeled as ‘sharp turn’ or ‘u-turn’ if the ‘add\_turn’ option parameter of the <code>/create/graph</code> was invoked at graph creation. Server default: <code>0.0</code>.</p>
</div>
<span id="structfield.num_best_paths" className="structfield section-header"><code>num\_best\_paths: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>For MULTIPLE\_ROUTING solvers only; sets the number of shortest paths computed from each node. This is the heuristic criterion. Default value of zero allows the number to be computed automatically by the solver. The user may want to override this parameter to speed-up the solver. Server default: <code>0</code>.</p>
</div>
<span id="structfield.max_num_combinations" className="structfield section-header"><code>max\_num\_combinations: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>For MULTIPLE\_ROUTING solvers only; sets the cap on the combinatorial sequences generated. If the default value of two millions is overridden to a lesser value, it can potentially speed up the solver. Server default: <code>2000000</code>.</p>
</div>
<span id="structfield.output_edge_path" className="structfield section-header"><code>output\_edge\_path: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true then concatenated edge IDs will be added as the EDGE path column of the solution table for each source and target pair in shortest path solves. Server default: <code>false</code>.</p>
</div>
<span id="structfield.output_wkt_path" className="structfield section-header"><code>output\_wkt\_path: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true then concatenated wkt line segments will be added as the Wktroute column of the solution table for each source and target pair in shortest path solves. Server default: <code>true</code>.</p>
</div>
<span id="structfield.server_id" className="structfield section-header"><code>server\_id: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Indicates which graph server(s) to send the request to. Default is to send to the server, amongst those containing the corresponding graph, that has the most computational bandwidth. For SHORTEST\_PATH solver type, the input is split amongst the server containing the corresponding graph.</p>
</div>
<span id="structfield.convergence_limit" className="structfield section-header"><code>convergence\_limit: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>For PAGE\_RANK solvers only; Maximum percent relative threshold on the page rank scores of each node between consecutive iterations to satisfy convergence. Default value is 1 (one) percent. Server default: <code>1.0</code>.</p>
</div>
<span id="structfield.max_iterations" className="structfield section-header"><code>max\_iterations: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>For PAGE\_RANK solvers only; Maximum number of page rank iterations for satisfying convergence. Default value is 100. Server default: <code>100</code>.</p>
</div>
<span id="structfield.max_runs" className="structfield section-header"><code>max\_runs: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>For all CENTRALITY solvers only; Sets the maximum number of shortest path runs; maximum possible value is the number of nodes in the graph. Default value of 0 enables this value to be auto computed by the solver. Server default: <code>0</code>.</p>
</div>
<span id="structfield.output_clusters" className="structfield section-header"><code>output\_clusters: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>For STATS\_ALL solvers only; the cluster index for each node will be inserted as an additional column in the output. Server default: <code>false</code>.</p>
</div>
<span id="structfield.solve_heuristic" className="structfield section-header"><code>solve\_heuristic: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Specify heuristic search criterion only for the geo graphs and shortest path solves towards a single target. Server default: <code>none</code>.</p>
</div>
<span id="structfield.astar_radius" className="structfield section-header"><code>astar\_radius: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>For path solvers only when ‘solve\_heuristic’ option is ‘astar’. The shortest path traversal front includes nodes only within this radius (kilometers) as it moves towards the target location. Server default: <code>70</code>.</p>
</div>
