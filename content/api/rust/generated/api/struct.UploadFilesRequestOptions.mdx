</div>
<span id="structfield.delete_if_exists" className="structfield section-header"><code>delete\_if\_exists: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true, any existing files specified in <code>file\_names</code> will be deleted prior to start of upload. Otherwise the file is replaced once the upload completes. Rollback of the original file is no longer possible if the upload is cancelled, aborted or fails if the file was deleted beforehand. Server default: <code>false</code>.</p>
</div>
