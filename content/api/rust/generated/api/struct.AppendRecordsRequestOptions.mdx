<h2 id="fields" className="fields section-header">Fields</h2>
<span id="structfield.offset" className="structfield section-header"><code>offset: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>A positive integer indicating the number of initial results to skip from <code>source\_table\_name</code>. Default is 0. The minimum allowed value is 0. The maximum allowed value is MAX\_INT. Server default: <code>0</code>.</p>
</div>
<span id="structfield.limit" className="structfield section-header"><code>limit: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>A positive integer indicating the maximum number of results to be returned from <code>source\_table\_name</code>. Or END\_OF\_SET (-9999) to indicate that the max number of results should be returned. Server default: <code>-9999</code>.</p>
</div>
<span id="structfield.expression" className="structfield section-header"><code>expression: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Filter expression to apply to the <code>source\_table\_name</code>.</p>
</div>
<span id="structfield.order_by" className="structfield section-header"><code>order\_by: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Comma-separated list of the columns to be sorted by from source table (specified by <code>source\_table\_name</code>), e.g., ‘timestamp asc, x desc’. The order\_by columns do not have to be present in <code>field\_map</code>.</p>
</div>
<span id="structfield.error_handling" className="structfield section-header"><code>error\_handling: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Specifies how record errors are handled while appending source table records into the target table. Currently this governs primary-key collision behavior: skip and permissive drop the colliding source records and continue, while abort rejects the batch. Explicit update\_on\_existing\_pk or ignore\_existing\_pk take precedence over this option. Server default: <code>abort</code>.</p>
</div>
<span id="structfield.update_on_existing_pk" className="structfield section-header"><code>update\_on\_existing\_pk: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Specifies the record collision policy for inserting source table records (specified by <code>source\_table\_name</code>) into a target table (specified by <code>table\_name</code>) with a primary key. If set to true, any existing table record with primary key values that match those of a source table record being inserted will be replaced by that new record (the new data will be “upserted”). If set to false, any existing table record with primary key values that match those of a source table record being inserted will remain unchanged, while the source record will be rejected and an error handled as determined by ignore\_existing\_pk. If the specified table does not have a primary key, then this option has no effect. Server default: <code>false</code>.</p>
</div>
<span id="structfield.enable_inplace_updates" className="structfield section-header"><code>enable\_inplace\_updates: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Applies only when upserting (when update\_on\_existing\_pk is true). If set to true, an existing record matched by primary key is modified in place. If set to false, it is updated by deleting the existing record and inserting a replacement (delete and insert), which prevents the change from being reflected in dependent materialized views until they are refreshed. Server default: <code>true</code>.</p>
</div>
<span id="structfield.ignore_existing_pk" className="structfield section-header"><code>ignore\_existing\_pk: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Specifies the record collision error-suppression policy for inserting source table records (specified by <code>source\_table\_name</code>) into a target table (specified by <code>table\_name</code>) with a primary key, only used when not in upsert mode (upsert mode is disabled when update\_on\_existing\_pk is false). If set to true, any source table record being inserted that is rejected for having primary key values that match those of an existing target table record will be ignored with no error generated. If false, the rejection of any source table record for having primary key values matching an existing target table record will result in an error being raised. If the specified table does not have a primary key or if upsert mode is in effect (update\_on\_existing\_pk is true), then this option has no effect. Server default: <code>false</code>.</p>
</div>
<span id="structfield.pk_conflict_predicate_higher" className="structfield section-header"><code>pk\_conflict\_predicate\_higher: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>The record with higher value for the column resolves the primary-key insert conflict.</p>
</div>
<span id="structfield.pk_conflict_predicate_lower" className="structfield section-header"><code>pk\_conflict\_predicate\_lower: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>The record with lower value for the column resolves the primary-key insert conflict.</p>
</div>
<span id="structfield.truncate_strings" className="structfield section-header"><code>truncate\_strings: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If set to true, it allows inserting longer strings into smaller charN string columns by truncating the longer strings to fit. Server default: <code>false</code>.</p>
</div>
