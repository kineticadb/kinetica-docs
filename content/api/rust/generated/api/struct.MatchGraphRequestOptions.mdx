</div>

</div>

</div>

Server default: <code>0.0</code>.</p>
</div>

Server default: <code>0</code>.</p>
</div>

</div>
<span id="structfield.enable_reuse" className="structfield section-header"><code>enable\_reuse: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>

</div>
