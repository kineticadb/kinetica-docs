<div className="docblock">
<p>If true, enables the use of distributed joins in servicing the given query. Any query requiring a distributed join will succeed, though hints can be used in the query to change the distribution of the source data to allow the query to succeed. Server default: <code>false</code>.</p>
</div>
<span id="structfield.distributed_operations" className="structfield section-header"><code>distributed\_operations: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true, enables the use of distributed operations in servicing the given query. Any query requiring a distributed join will succeed, though hints can be used in the query to change the distribution of the source data to allow the query to succeed. Server default: <code>false</code>.</p>
</div>
<span id="structfield.ignore_existing_pk" className="structfield section-header"><code>ignore\_existing\_pk: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Specifies the record collision error-suppression policy for inserting into or updating a table with a primary key, only used when primary key record collisions are rejected (update\_on\_existing\_pk is false). If set to true, any record insert/update that is rejected for resulting in a primary key collision with an existing table record will be ignored with no error generated. If false, the rejection of any insert/update for resulting in a primary key collision will cause an error to be reported. If the specified table does not have a primary key or if update\_on\_existing\_pk is true, then this option has no effect. Server default: <code>false</code>.</p>
</div>
<span id="structfield.late_materialization" className="structfield section-header"><code>late\_materialization: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true, Joins/Filters results will always be materialized ( saved to result tables format). Server default: <code>false</code>.</p>
</div>
<span id="structfield.paging_table" className="structfield section-header"><code>paging\_table: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>When specified (or paging\_table\_ttl is set), the system will create a paging table to hold the results of the query, when the output has more records than are in the response (i.e., when <code>has\_more\_records</code> is true). If the specified paging table exists, the records from the paging table are returned without re-evaluating the query. It is the caller’s responsibility to clear the <code>paging\_table</code> and other tables in the result\_table\_list (both returned in the response) when they are done with this query.</p>
</div>
<span id="structfield.paging_table_ttl" className="structfield section-header"><code>paging\_table\_ttl: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Sets the TTL of the paging table. -1 indicates no timeout. Setting this option will cause a paging table to be generated when needed. The <code>paging\_table</code> and other tables in the result\_table\_list (both returned in the response) will be automatically cleared after the TTL expires, if set to a positive number. However, it is still recommended that the caller clear these tables when they are done with this query.</p>
</div>
<span id="structfield.parallel_execution" className="structfield section-header"><code>parallel\_execution: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>

<span id="structfield.preserve_dict_encoding" className="structfield section-header"><code>preserve\_dict\_encoding: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>

<span id="structfield.ttl" className="structfield section-header"><code>ttl: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>

</div>
<span id="structfield.update_on_existing_pk" className="structfield section-header"><code>update\_on\_existing\_pk: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Specifies the record collision policy for inserting into or updating a table with a primary key. If set to true, any existing table record with primary key values that match those of a record being inserted or updated will be replaced by that record. If set to false, any such primary key collision will result in the insert/update being rejected and the error handled as determined by ignore\_existing\_pk. If the specified table does not have a primary key, then this option has no effect. Server default: <code>false</code>.</p>
</div>
<span id="structfield.validate_change_column" className="structfield section-header"><code>validate\_change\_column: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>When changing a column using alter table, validate the change before applying it. If true, then validate all values. A value too large (or too long) for the new type will prevent any change. If false, then when a value is too large or long, it will be truncated. Server default: <code>true</code>.</p>
</div>
