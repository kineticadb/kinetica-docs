<div className="docblock">

<span id="structfield.create_temp_table" className="structfield section-header"><code>create\_temp\_table: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true, a unique temporary table name will be generated in the sys\_temp schema and used in place of <code>table\_name</code>. If is\_result\_table is true, then this is always allowed even if the caller does not have permission to create tables. The generated name is returned in qualified\_table\_name. Server default: <code>false</code>.</p>
</div>
<span id="structfield.collection_name" className="structfield section-header"><code>collection\_name: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>

</div>
<span id="structfield.is_collection" className="structfield section-header"><code>is\_collection: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>

<span id="structfield.is_replicated" className="structfield section-header"><code>is\_replicated: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Affects the distribution scheme for the table’s data. If true and the given type has no explicit shard key defined, the table will be replicated. If false, the table will be sharded according to the shard key specified in the given <code>type\_id</code>, or randomly sharded, if no shard key is specified. Note that a type containing a shard key cannot be used to create a replicated table. Server default: <code>false</code>.</p>
</div>
