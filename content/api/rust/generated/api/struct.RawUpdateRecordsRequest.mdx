<p>The request payload for the <code>/update/records</code> endpoint.</p>
<p>Perform predicate-based updates to table data</p>
</div>
</div>
<h2 id="fields" className="fields section-header">Fields</h2>
<span id="structfield.table_name" className="structfield section-header"><code>table\_name: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Name of table to be updated, in \[schema\_name.\]table\_name format, using standard name resolution rules. Must be a currently existing table and not a view.</p>
</div>
<span id="structfield.expressions" className="structfield section-header"><code>expressions: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/vec/struct.Vec.html" title="struct alloc::vec::Vec">Vec</a>&lt;<a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a>&gt;</code></span>
<div className="docblock">
<p>A list of the actual predicates, one for each update; format should follow the guidelines here.</p>
</div>
<span id="structfield.new_values_maps" className="structfield section-header"><code>new\_values\_maps: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/vec/struct.Vec.html" title="struct alloc::vec::Vec">Vec</a>&lt;<a className="struct" href="https://doc.rust-lang.org/1.98.1/std/collections/hash/map/struct.HashMap.html" title="struct std::collections::hash::map::HashMap">HashMap</a>&lt;<a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a>, <a className="enum" href="https://doc.rust-lang.org/1.98.1/core/option/enum.Option.html" title="enum core::option::Option">Option</a>&lt;<a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a>&gt;&gt;&gt;</code></span>
<div className="docblock">
<p>List of new values for the matching records. Each element is a map with (key, value) pairs where the keys are the names of the columns whose values are to be updated; the values are the new values. The number of elements in the list should match the length of <code>expressions</code>.</p>
</div>
<span id="structfield.records_to_insert" className="structfield section-header"><code>records\_to\_insert: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/vec/struct.Vec.html" title="struct alloc::vec::Vec">Vec</a>&lt;<a className="struct" href="/content/api/rust/struct.ByteBuf" title="struct gpudb_api::ByteBuf">ByteBuf</a>&gt;</code></span>
<div className="docblock">
<p>An <span className="em">optional</span> list of new binary-avro encoded records to insert, one for each update. If one of <code>expressions</code> does not yield a matching record to be updated, then the corresponding element from this list will be added to the table.</p>
</div>
<span id="structfield.records_to_insert_str" className="structfield section-header"><code>records\_to\_insert\_str: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/vec/struct.Vec.html" title="struct alloc::vec::Vec">Vec</a>&lt;<a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a>&gt;</code></span>
<div className="docblock">
<p>An optional list of JSON encoded objects to insert, one for each update, to be added if the particular update did not match any objects.</p>
</div>
<span id="structfield.record_encoding" className="structfield section-header"><code>record\_encoding: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Identifies which of <code>records\_to\_insert</code> and <code>records\_to\_insert\_str</code> should be used.</p>
</div>
<span id="structfield.options" className="structfield section-header"><code>options: <a className="struct" href="https://doc.rust-lang.org/1.98.1/std/collections/hash/map/struct.HashMap.html" title="struct std::collections::hash::map::HashMap">HashMap</a>&lt;<a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a>, <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a>&gt;</code></span>
