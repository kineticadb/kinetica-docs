<span id="structfield.dry_run" className="structfield section-header"><code>dry\_run: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If set to true, only validation checks will be performed. No host is added. Server default: <code>false</code>.</p>
</div>
<span id="structfield.accepts_failover" className="structfield section-header"><code>accepts\_failover: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If set to true, the host will accept processes (ranks, graph server, etc.) in the event of a failover on another node in the cluster. Server default: <code>false</code>.</p>
</div>
<span id="structfield.public_address" className="structfield section-header"><code>public\_address: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>The publicly-accessible IP address for the host being added, typically specified for clients using multi-head operations. This setting is required if any other host(s) in the cluster specify a public address.</p>
</div>
<span id="structfield.host_manager_public_url" className="structfield section-header"><code>host\_manager\_public\_url: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>The publicly-accessible full path URL to the host manager on the host being added, e.g., ‘http://172.123.45.67:9300’. The default host manager port can be found in the list of ports used by Kinetica.</p>
</div>
<span id="structfield.ram_limit" className="structfield section-header"><code>ram\_limit: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>The desired RAM limit for the host being added, i.e. the sum of RAM usage for all processes on the host will not be able to exceed this value. Supported units: K (thousand), KB (kilobytes), M (million), MB (megabytes), G (billion), GB (gigabytes); if no unit is provided, the value is assumed to be in bytes. For example, if ram\_limit is set to 10M, the resulting RAM limit is 10 million bytes. Set ram\_limit to -1 to have no RAM limit.</p>
</div>
<span id="structfield.gpus" className="structfield section-header"><code>gpus: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Comma-delimited list of GPU indices (starting at 1) that are eligible for running worker processes. If left blank, all GPUs on the host being added will be eligible.</p>
</div>
