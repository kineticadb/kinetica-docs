<p>Optional parameters for the <code>/restore/backup</code> endpoint.</p>
<p><code>Default::default()</code> is the empty set: only options set explicitly are sent, and anything left empty falls back to the server’s own default.</p>

<span id="structfield.backup_id" className="structfield section-header"><code>backup\_id: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>ID of the snapshot to restore. Leave empty to restore the most recent snapshot in the backup.</p>
</div>
<span id="structfield.checksum" className="structfield section-header"><code>checksum: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Whether or not to verify checksums for backup files when restoring. Server default: <code>false</code>.</p>
</div>
<span id="structfield.cascade_foreign_keys" className="structfield section-header"><code>cascade\_foreign\_keys: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Whether to drop live foreign-key-referencing tables that are not themselves part of the backup, when the table they reference is being replaced. Only applies when restore\_policy is replace. Server default: <code>false</code>.</p>
</div>
<span id="structfield.create_schema_if_not_exist" className="structfield section-header"><code>create\_schema\_if\_not\_exist: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Behavior to apply when the schema containing any database object to restore does not already exist. Server default: <code>true</code>.</p>
</div>
<span id="structfield.ddl_only" className="structfield section-header"><code>ddl\_only: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Behavior to apply when restoring tables. Server default: <code>false</code>.</p>
</div>
<span id="structfield.dry_run" className="structfield section-header"><code>dry\_run: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Whether or not to perform a dry run of the restoration operation. With a restore\_policy of clean or clean\_all, a dry run lists the objects the clean would drop in the clean\_dropped\_objects entry of the response <code>info</code> map and drops nothing, and fails as the restore would if the clean is refused. Server default: <code>false</code>.</p>
</div>
<span id="structfield.restore_subscriptions" className="structfield section-header"><code>restore\_subscriptions: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Behavior to apply when restoring datasource subscriptions on tables. Server default: <code>resume</code>.</p>
</div>
<span id="structfield.reingest" className="structfield section-header"><code>reingest: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Behavior to apply when restoring table data. Server default: <code>false</code>.</p>
</div>
<span id="structfield.renamed_objects_schema" className="structfield section-header"><code>renamed\_objects\_schema: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If the restore\_policy is rename, use this schema for relocated existing objects instead of the default generated one.</p>
</div>
<span id="structfield.restore_all_permissions" className="structfield section-header"><code>restore\_all\_permissions: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Whether or not all permissions of restored principals should be restored or scoped to the restored objects. When restore\_policy is clean or clean\_all, the default is true: the clean drops each principal in scope along with all of its permissions, including those on objects it does not drop. Server default: <code>false</code>.</p>
</div>
<span id="structfield.restore_policy" className="structfield section-header"><code>restore\_policy: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Behavior to apply when any database object to restore already exists. Server default: <code>none</code>.</p>
</div>
<span id="structfield.target_schema_map" className="structfield section-header"><code>target\_schema\_map: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Restore schema-based objects to alternate schema. Value is a comma delimitted list of key:value pairs mapping the original (source) schema name as it exists in the backup to a target (destination) schema namespace: “src: dst \[, src: dst \[, …\]\]”. Note that schema names are case sensitive and must adhere to the database schema naming criteria.</p>
</div>
