<div className="dl item-table">
<div id="options.ASTAR" className="dt constant-def"><code>pub const ASTAR: &amp;str = &quot;astar&quot;;</code></div>
<div className="dd">
<p>Employs A-STAR heuristics to speed up the shortest path traversal.</p>
</div>
<div id="options.ASTAR_RADIUS" className="dt constant-def"><code>pub const ASTAR\_RADIUS: &amp;str = &quot;astar\_radius&quot;;</code></div>
<div className="dd">
<p>For path solvers only when ‘solve\_heuristic’ option is ‘astar’. The shortest path traversal front includes nodes only within this radius (kilometers) as it moves towards the target location.</p>
</div>
<div id="options.CONVERGENCE_LIMIT" className="dt constant-def"><code>pub const CONVERGENCE\_LIMIT: &amp;str = &quot;convergence\_limit&quot;;</code></div>
<div className="dd">
<p>For PAGE\_RANK solvers only; Maximum percent relative threshold on the page rank scores of each node between consecutive iterations to satisfy convergence. Default value is 1 (one) percent.</p>
</div>
<div id="options.FALSE" className="dt constant-def"><code>pub const FALSE: &amp;str = &quot;false&quot;;</code></div>
<div className="dd">
<p>No extra cluster info per node will be available in the output.</p>
</div>
<div id="options.INTERSECTION_PENALTY" className="dt constant-def"><code>pub const INTERSECTION\_PENALTY: &amp;str = &quot;intersection\_penalty&quot;;</code></div>
<div className="dd">
<p>This will add an additional weight over the edges labeled as ‘intersection’ if the ‘add\_turn’ option parameter of the <code>/create/graph</code> was invoked at graph creation.</p>
</div>
<div id="options.LEFT_TURN_PENALTY" className="dt constant-def"><code>pub const LEFT\_TURN\_PENALTY: &amp;str = &quot;left\_turn\_penalty&quot;;</code></div>
<div className="dd">
<p>This will add an additional weight over the edges labeled as ‘left turn’ if the ‘add\_turn’ option parameter of the <code>/create/graph</code> was invoked at graph creation.</p>
</div>
<div id="options.MAX_ITERATIONS" className="dt constant-def"><code>pub const MAX\_ITERATIONS: &amp;str = &quot;max\_iterations&quot;;</code></div>
<div className="dd">
<p>For PAGE\_RANK solvers only; Maximum number of page rank iterations for satisfying convergence. Default value is 100.</p>
</div>
<div id="options.MAX_NUM_COMBINATIONS" className="dt constant-def"><code>pub const MAX\_NUM\_COMBINATIONS: &amp;str = &quot;max\_num\_combinations&quot;;</code></div>
<div className="dd">
<p>For MULTIPLE\_ROUTING solvers only; sets the cap on the combinatorial sequences generated. If the default value of two millions is overridden to a lesser value, it can potentially speed up the solver.</p>
</div>
<div id="options.MAX_RUNS" className="dt constant-def"><code>pub const MAX\_RUNS: &amp;str = &quot;max\_runs&quot;;</code></div>
<div className="dd">
<p>For all CENTRALITY solvers only; Sets the maximum number of shortest path runs; maximum possible value is the number of nodes in the graph. Default value of 0 enables this value to be auto computed by the solver.</p>
</div>
<div id="options.MAX_SOLUTION_RADIUS" className="dt constant-def"><code>pub const MAX\_SOLUTION\_RADIUS: &amp;str = &quot;max\_solution\_radius&quot;;</code></div>
<div className="dd">
<p>For ALLPATHS, SHORTEST\_PATH and INVERSE\_SHORTEST\_PATH solvers only. Sets the maximum solution cost radius, which ignores the <code>destination\_nodes</code> list and instead outputs the nodes within the radius sorted by ascending cost. If set to ‘0.0’, the setting is ignored.</p>
</div>
<div id="options.MAX_SOLUTION_TARGETS" className="dt constant-def"><code>pub const MAX\_SOLUTION\_TARGETS: &amp;str = &quot;max\_solution\_targets&quot;;</code></div>
<div className="dd">
<p>For ALLPATHS, SHORTEST\_PATH and INVERSE\_SHORTEST\_PATH solvers only. Sets the maximum number of solution targets, which ignores the <code>destination\_nodes</code> list and instead outputs no more than n number of nodes sorted by ascending cost where n is equal to the setting value. If set to 0, the setting is ignored.</p>
</div>
<div id="options.MIN_SOLUTION_RADIUS" className="dt constant-def"><code>pub const MIN\_SOLUTION\_RADIUS: &amp;str = &quot;min\_solution\_radius&quot;;</code></div>
<div className="dd">
<p>For ALLPATHS, SHORTEST\_PATH and INVERSE\_SHORTEST\_PATH solvers only. Applicable only when max\_solution\_radius is set. Sets the minimum solution cost radius, which ignores the <code>destination\_nodes</code> list and instead outputs the nodes within the radius sorted by ascending cost. If set to ‘0.0’, the setting is ignored.</p>
</div>
<div id="options.NONE" className="dt constant-def"><code>pub const NONE: &amp;str = &quot;none&quot;;</code></div>
<div className="dd">
<p>No heuristics are applied.</p>
</div>
<div id="options.NUM_BEST_PATHS" className="dt constant-def"><code>pub const NUM\_BEST\_PATHS: &amp;str = &quot;num\_best\_paths&quot;;</code></div>
<div className="dd">
<p>For MULTIPLE\_ROUTING solvers only; sets the number of shortest paths computed from each node. This is the heuristic criterion. Default value of zero allows the number to be computed automatically by the solver. The user may want to override this parameter to speed-up the solver.</p>
</div>
<div id="options.OUTPUT_CLUSTERS" className="dt constant-def"><code>pub const OUTPUT\_CLUSTERS: &amp;str = &quot;output\_clusters&quot;;</code></div>
<div className="dd">
<p>For STATS\_ALL solvers only; the cluster index for each node will be inserted as an additional column in the output.</p>
</div>
<div id="options.OUTPUT_EDGE_PATH" className="dt constant-def"><code>pub const OUTPUT\_EDGE\_PATH: &amp;str = &quot;output\_edge\_path&quot;;</code></div>
<div className="dd">
<p>If true then concatenated edge IDs will be added as the EDGE path column of the solution table for each source and target pair in shortest path solves.</p>
</div>
<div id="options.OUTPUT_WKT_PATH" className="dt constant-def"><code>pub const OUTPUT\_WKT\_PATH: &amp;str = &quot;output\_wkt\_path&quot;;</code></div>
<div className="dd">
<p>If true then concatenated wkt line segments will be added as the Wktroute column of the solution table for each source and target pair in shortest path solves.</p>
</div>
<div id="options.RIGHT_TURN_PENALTY" className="dt constant-def"><code>pub const RIGHT\_TURN\_PENALTY: &amp;str = &quot;right\_turn\_penalty&quot;;</code></div>
<div className="dd">
<p>This will add an additional weight over the edges labeled as’ right turn’ if the ‘add\_turn’ option parameter of the <code>/create/graph</code> was invoked at graph creation.</p>
</div>
<div id="options.SERVER_ID" className="dt constant-def"><code>pub const SERVER\_ID: &amp;str = &quot;server\_id&quot;;</code></div>
<div className="dd">
<p>Indicates which graph server(s) to send the request to. Default is to send to the server, amongst those containing the corresponding graph, that has the most computational bandwidth. For SHORTEST\_PATH solver type, the input is split amongst the server containing the corresponding graph.</p>
</div>
<div id="options.SHARP_TURN_PENALTY" className="dt constant-def"><code>pub const SHARP\_TURN\_PENALTY: &amp;str = &quot;sharp\_turn\_penalty&quot;;</code></div>
<div className="dd">
<p>This will add an additional weight over the edges labeled as ‘sharp turn’ or ‘u-turn’ if the ‘add\_turn’ option parameter of the <code>/create/graph</code> was invoked at graph creation.</p>
</div>
<div id="options.SOLVE_HEURISTIC" className="dt constant-def"><code>pub const SOLVE\_HEURISTIC: &amp;str = &quot;solve\_heuristic&quot;;</code></div>
<div className="dd">
<p>Specify heuristic search criterion only for the geo graphs and shortest path solves towards a single target.</p>
</div>
<div id="options.TRUE" className="dt constant-def"><code>pub const TRUE: &amp;str = &quot;true&quot;;</code></div>
<div className="dd">
<p>An additional column ‘CLUSTER’ will be added for each node.</p>
</div>
<div id="options.UNIFORM_WEIGHTS" className="dt constant-def"><code>pub const UNIFORM\_WEIGHTS: &amp;str = &quot;uniform\_weights&quot;;</code></div>
<div className="dd">
<p>When specified, assigns the given value to all the edges in the graph. Note that weights provided in <code>weights\_on\_edges</code> will override this value.</p>
</div>

<h3 id="solver_type" className="section-header"><code>solver\_type</code></h3>
<div className="details toggle top-doc">
<div className="docblock">
<p>Constants for <code>solver\_type</code>.</p>
</div>
</div>
<div className="dl item-table">
<div id="solver_type.ALLPATHS" className="dt constant-def"><code>pub const ALLPATHS: &amp;str = &quot;ALLPATHS&quot;;</code></div>
<div className="dd">
<p>Solves for paths that would give costs between max and min solution radia - Make sure to limit by the ‘max\_solution\_targets’ option. Min cost should be &gt;= shortest\_path cost.</p>
</div>
<div id="solver_type.BACKHAUL_ROUTING" className="dt constant-def"><code>pub const BACKHAUL\_ROUTING: &amp;str = &quot;BACKHAUL\_ROUTING&quot;;</code></div>
<div className="dd">
<p>Solves for optimal routes that connect remote asset nodes to the fixed (backbone) asset nodes.</p>
</div>
<div id="solver_type.CENTRALITY" className="dt constant-def"><code>pub const CENTRALITY: &amp;str = &quot;CENTRALITY&quot;;</code></div>
<div className="dd">
<p>Solves for the degree of a node to depict how many pairs of individuals that would have to go through the node to reach one another in the minimum number of hops. Also known as betweenness.</p>
</div>
<div id="solver_type.CLOSENESS" className="dt constant-def"><code>pub const CLOSENESS: &amp;str = &quot;CLOSENESS&quot;;</code></div>
<div className="dd">
<p>Solves for the centrality closeness score per node as the sum of the inverse shortest path costs to all nodes in the graph.</p>
</div>
<div id="solver_type.INVERSE_SHORTEST_PATH" className="dt constant-def"><code>pub const INVERSE\_SHORTEST\_PATH: &amp;str = &quot;INVERSE\_SHORTEST\_PATH&quot;;</code></div>
<div className="dd">
<p>Solves for finding the optimal path cost for each destination node to route to the source node. Also known as inverse Dijkstra or the service man routing problem.</p>
</div>
<div id="solver_type.MULTIPLE_ROUTING" className="dt constant-def"><code>pub const MULTIPLE\_ROUTING: &amp;str = &quot;MULTIPLE\_ROUTING&quot;;</code></div>
<div className="dd">
<p>Solves for finding the minimum cost cumulative path for a round-trip starting from the given source and visiting each given destination node once then returning to the source. Also known as the traveling salesman problem.</p>
</div>
<div id="solver_type.PAGE_RANK" className="dt constant-def"><code>pub const PAGE\_RANK: &amp;str = &quot;PAGE\_RANK&quot;;</code></div>
<div className="dd">
<p>Solves for the probability of each destination node being visited based on the links of the graph topology. Weights are not required to use this solver.</p>
</div>
<div id="solver_type.PROBABILITY_RANK" className="dt constant-def"><code>pub const PROBABILITY\_RANK: &amp;str = &quot;PROBABILITY\_RANK&quot;;</code></div>
<div className="dd">
<p>Solves for the transitional probability (Hidden Markov) for each node based on the weights (probability assigned over given edges).</p>
</div>
<div id="solver_type.SHORTEST_PATH" className="dt constant-def"><code>pub const SHORTEST\_PATH: &amp;str = &quot;SHORTEST\_PATH&quot;;</code></div>
<div className="dd">
<p>Solves for the optimal (shortest) path based on weights and restrictions from one source to destinations nodes. Also known as the Dijkstra solver.</p>
</div>
<div id="solver_type.STATS_ALL" className="dt constant-def"><code>pub const STATS\_ALL: &amp;str = &quot;STATS\_ALL&quot;;</code></div>
<div className="dd">
<p>Solves for graph statistics such as graph diameter, longest pairs, vertex valences, topology numbers, average and max cluster sizes, etc.</p>
</div>
</div>
</div>
