<div className="dl item-table">
<div id="solve_method.MARKOV_CHAIN" className="dt constant-def"><code>pub const MARKOV\_CHAIN: &amp;str = &quot;markov\_chain&quot;;</code></div>
<div className="dd">
<p>Matches <code>sample\_points</code> to the graph using the Hidden Markov Model (HMM)-based method, which conducts a range-tree closest-edge search to find the best combinations of possible road segments (num\_segments) for each sample point to create the best route. The route is secured one point at a time while looking ahead chain\_width number of points, so the prediction is corrected after each point. This solution type is the most accurate but also the most computationally intensive. Related options: num\_segments and chain\_width.</p>
</div>
<div id="solve_method.MATCH_BATCH_SOLVES" className="dt constant-def"><code>pub const MATCH\_BATCH\_SOLVES: &amp;str = &quot;match\_batch\_solves&quot;;</code></div>
<div className="dd">
<p>Matches <code>sample\_points</code> source and destination pairs for the shortest path solves in batch mode.</p>
</div>
<div id="solve_method.MATCH_CHARGING_STATIONS" className="dt constant-def"><code>pub const MATCH\_CHARGING\_STATIONS: &amp;str = &quot;match\_charging\_stations&quot;;</code></div>
<div className="dd">
<p>Matches an optimal path across a number of ev-charging stations between source and target locations.</p>
</div>
<div id="solve_method.MATCH_CLUSTERS" className="dt constant-def"><code>pub const MATCH\_CLUSTERS: &amp;str = &quot;match\_clusters&quot;;</code></div>
<div className="dd">
