<div className="dd">
<p>Repairs replicated tables whose record counts differ across the worker ranks and toms: the copy with the most records is kept, and every other copy is replaced with it. That copy may include records from a load that did not complete, or records that a delete did not remove. A table whose copies all have the same number of records is not repaired, even if their contents differ. Views cannot be named in <code>table\_names</code>; a named table that is not replicated is reported in <code>repair\_status</code>. An asterisk selects every replicated table. The repair runs only while no other requests are running. The repaired tables are listed in the repaired\_replicated\_tables entry of the response <code>info</code> map.</p>
</div>
