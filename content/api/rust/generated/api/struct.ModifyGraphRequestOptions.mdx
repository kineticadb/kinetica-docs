<h2 id="fields" className="fields section-header">Fields</h2>
<span id="structfield.restriction_threshold_value" className="structfield section-header"><code>restriction\_threshold\_value: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Value-based restriction comparison. Any node or edge with a RESTRICTIONS\_VALUECOMPARED value greater than the restriction\_threshold\_value will not be included in the graph.</p>
</div>
<span id="structfield.export_create_results" className="structfield section-header"><code>export\_create\_results: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If set to true, returns the graph topology in the response as arrays. Server default: <code>false</code>.</p>
</div>
<span id="structfield.enable_graph_draw" className="structfield section-header"><code>enable\_graph\_draw: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If set to true, adds a ‘EDGE\_WKTLINE’ column identifier to the specified graph\_table so the graph can be viewed via WMS; for social and non-geospatial graphs, the ‘EDGE\_WKTLINE’ column identifier will be populated with spatial coordinates derived from a flattening layout algorithm so the graph can still be viewed. Server default: <code>false</code>.</p>
</div>
<span id="structfield.save_persist" className="structfield section-header"><code>save\_persist: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If set to true, the graph will be saved in the persist directory (see the config reference for more information). If set to false, the graph will be removed when the graph server is shutdown. Server default: <code>false</code>.</p>
</div>
<span id="structfield.add_table_monitor" className="structfield section-header"><code>add\_table\_monitor: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Adds a table monitor to every table used in the creation of the graph; this table monitor will trigger the graph to update dynamically upon inserts to the source table(s). Note that upon database restart, if save\_persist is also set to true, the graph will be fully reconstructed and the table monitors will be reattached. For more details on table monitors, see <code>/create/tablemonitor</code>. Server default: <code>false</code>.</p>
</div>
<span id="structfield.graph_table" className="structfield section-header"><code>graph\_table: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If specified, the created graph is also created as a table with the given name, in \[schema\_name.\]table\_name format, using standard name resolution rules and meeting table naming criteria. This table will have the following identifier columns: ‘EDGE\_ID’, ‘EDGE\_NODE1\_ID’, ‘EDGE\_NODE2\_ID’. If left blank, no table is created.</p>
</div>
<span id="structfield.remove_label_only" className="structfield section-header"><code>remove\_label\_only: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>When RESTRICTIONS on labeled entities requested, if set to true this will NOT delete the entity but only the label associated with the entity. Otherwise (default), it’ll delete the label AND the entity. Server default: <code>false</code>.</p>
</div>
<span id="structfield.add_turns" className="structfield section-header"><code>add\_turns: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Adds dummy ‘pillowed’ edges around intersection nodes where there are more than three edges so that additional weight penalties can be imposed by the solve endpoints. (increases the total number of edges). Server default: <code>false</code>.</p>
</div>
<span id="structfield.turn_angle" className="structfield section-header"><code>turn\_angle: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Value in degrees modifies the thresholds for attributing right, left, sharp turns, and intersections. It is the vertical deviation angle from the incoming edge to the intersection node. The larger the value, the larger the threshold for sharp turns and intersections; the smaller the value, the larger the threshold for right and left turns; 0 &lt; turn\_angle &lt; 90. Server default: <code>60</code>.</p>
</div>
<span id="structfield.use_rtree" className="structfield section-header"><code>use\_rtree: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Use an range tree structure to accelerate and improve the accuracy of snapping, especially to edges. Server default: <code>true</code>.</p>
</div>
<span id="structfield.label_delimiter" className="structfield section-header"><code>label\_delimiter: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If provided the label string will be split according to this delimiter and each sub-string will be applied as a separate label onto the specified edge.</p>
</div>
<span id="structfield.allow_multiple_edges" className="structfield section-header"><code>allow\_multiple\_edges: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Multigraph choice; allowing multiple edges with the same node pairs if set to true, otherwise, new edges with existing same node pairs will not be inserted. Server default: <code>true</code>.</p>
</div>
<span id="structfield.embedding_table" className="structfield section-header"><code>embedding\_table: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If table exists (should be generated by the match/graph match\_embedding solver), the vector embeddings for the newly inserted nodes will be appended into this table.</p>
</div>
