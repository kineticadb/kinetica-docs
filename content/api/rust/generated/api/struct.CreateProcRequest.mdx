<h2 id="fields" className="fields section-header">Fields</h2>
<span id="structfield.proc_name" className="structfield section-header"><code>proc\_name: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Name of the proc to be created. Must not be the name of a currently existing proc.</p>
</div>
<span id="structfield.execution_mode" className="structfield section-header"><code>execution\_mode: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>The execution mode of the proc.</p>
</div>
<span id="structfield.files" className="structfield section-header"><code>files: <a className="struct" href="https://doc.rust-lang.org/1.98.1/std/collections/hash/map/struct.HashMap.html" title="struct std::collections::hash::map::HashMap">HashMap</a>&lt;<a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a>, <a className="struct" href="/content/api/rust/struct.ByteBuf" title="struct gpudb_api::ByteBuf">ByteBuf</a>&gt;</code></span>
<div className="docblock">
<p>A map of the files that make up the proc. The keys of the map are file names, and the values are the binary contents of the files. The file names may include subdirectory names (e.g. ‘subdir/file’) but must not resolve to a directory above the root for the proc.</p>
<p>Files may be loaded from existing files in KiFS. Those file names should be prefixed with the uri kifs:// and the values in the map should be empty</p>
</div>
<span id="structfield.command" className="structfield section-header"><code>command: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>The command (excluding arguments) that will be invoked when the proc is executed. It will be invoked from the directory containing the proc <code>files</code> and may be any command that can be resolved from that directory. It need not refer to a file actually in that directory; for example, it could be ‘java’ if the proc is a Java application; however, any necessary external programs must be preinstalled on every database node. If the command refers to a file in that directory, it must be preceded with ‘./’ as per Linux convention. If not specified, and exactly one file is provided in <code>files</code>, that file will be invoked.</p>
</div>
<span id="structfield.args" className="structfield section-header"><code>args: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/vec/struct.Vec.html" title="struct alloc::vec::Vec">Vec</a>&lt;<a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a>&gt;</code></span>
<div className="docblock">
<p>An array of command-line arguments that will be passed to <code>command</code> when the proc is executed.</p>
</div>
<span id="structfield.options" className="structfield section-header"><code>options: <a className="struct" href="https://doc.rust-lang.org/1.98.1/std/collections/hash/map/struct.HashMap.html" title="struct std::collections::hash::map::HashMap">HashMap</a>&lt;<a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a>, <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a>&gt;</code></span>
