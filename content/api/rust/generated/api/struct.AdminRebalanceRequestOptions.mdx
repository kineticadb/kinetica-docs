<h2 id="fields" className="fields section-header">Fields</h2>
<span id="structfield.rebalance_sharded_data" className="structfield section-header"><code>rebalance\_sharded\_data: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true, sharded data will be rebalanced approximately equally across the cluster. Note that for clusters with large amounts of sharded data, this data transfer could be time consuming and result in delayed query responses. Server default: <code>true</code>.</p>
</div>
<span id="structfield.rebalance_unsharded_data" className="structfield section-header"><code>rebalance\_unsharded\_data: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true, unsharded data (a.k.a. randomly-sharded) will be rebalanced approximately equally across the cluster. Note that for clusters with large amounts of unsharded data, this data transfer could be time consuming and result in delayed query responses. Server default: <code>true</code>.</p>
</div>
<span id="structfield.table_includes" className="structfield section-header"><code>table\_includes: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Comma-separated list of unsharded table names to rebalance. Not applicable to sharded tables because they are always rebalanced. Cannot be used simultaneously with table\_excludes. This parameter is ignored if rebalance\_unsharded\_data is false.</p>
</div>
<span id="structfield.table_excludes" className="structfield section-header"><code>table\_excludes: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Comma-separated list of unsharded table names to not rebalance. Not applicable to sharded tables because they are always rebalanced. Cannot be used simultaneously with table\_includes. This parameter is ignored if rebalance\_unsharded\_data is false.</p>
</div>
<span id="structfield.aggressiveness" className="structfield section-header"><code>aggressiveness: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Influences how much data is moved at a time during rebalance. A higher aggressiveness will complete the rebalance faster. A lower aggressiveness will take longer but allow for better interleaving between the rebalance and other queries. Valid values are constants from 1 (lowest) to 10 (highest). Server default: <code>10</code>.</p>
</div>
<span id="structfield.compact_after_rebalance" className="structfield section-header"><code>compact\_after\_rebalance: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Perform compaction of deleted records once the rebalance completes to reclaim memory and disk space. Default is true, unless repair\_incorrectly\_sharded\_data is set to true. Server default: <code>true</code>.</p>
</div>
<span id="structfield.compact_only" className="structfield section-header"><code>compact\_only: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If set to true, ignore rebalance options and attempt to perform compaction of deleted records to reclaim memory and disk space without rebalancing first. Server default: <code>false</code>.</p>
</div>
<span id="structfield.repair_incorrectly_sharded_data" className="structfield section-header"><code>repair\_incorrectly\_sharded\_data: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Scans for any data sharded incorrectly and re-routes the data to the correct location. Only necessary if <code>/admin/verifydb</code> reports an error in sharding alignment. This can be done as part of a typical rebalance after expanding the cluster or in a standalone fashion when it is believed that data is sharded incorrectly somewhere in the cluster. Compaction will not be performed by default when this is enabled. If this option is set to true, the time necessary to rebalance and the memory used by the rebalance may increase. Server default: <code>false</code>.</p>
</div>
