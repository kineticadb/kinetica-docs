<h2 id="fields" className="fields section-header">Fields</h2>
<span id="structfield.update_on_existing_pk" className="structfield section-header"><code>update\_on\_existing\_pk: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Specifies the record collision policy for inserting into a table with a primary key. If set to true, any existing table record with primary key values that match those of a record being inserted will be replaced by that new record (the new data will be “upserted”). If set to false, any existing table record with primary key values that match those of a record being inserted will remain unchanged, while the new record will be rejected and the error handled as determined by ignore\_existing\_pk, allow\_partial\_batch, and return\_individual\_errors. If the specified table does not have a primary key, then this option has no effect. Server default: <code>false</code>.</p>
</div>
<span id="structfield.enable_inplace_updates" className="structfield section-header"><code>enable\_inplace\_updates: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Applies only when upserting (when update\_on\_existing\_pk is true). If set to true, an existing record matched by primary key is modified in place. If set to false, it is updated by deleting the existing record and inserting a replacement (delete and insert), which prevents the change from being reflected in dependent materialized views until they are refreshed. Server default: <code>true</code>.</p>
</div>
<span id="structfield.ignore_existing_pk" className="structfield section-header"><code>ignore\_existing\_pk: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Specifies the record collision error-suppression policy for inserting into a table with a primary key, only used when not in upsert mode (upsert mode is disabled when update\_on\_existing\_pk is false). If set to true, any record being inserted that is rejected for having primary key values that match those of an existing table record will be ignored with no error generated. If false, the rejection of any record for having primary key values matching an existing record will result in an error being reported, as determined by allow\_partial\_batch and return\_individual\_errors. If the specified table does not have a primary key or if upsert mode is in effect (update\_on\_existing\_pk is true), then this option has no effect. Server default: <code>false</code>.</p>
</div>
<span id="structfield.pk_conflict_predicate_higher" className="structfield section-header"><code>pk\_conflict\_predicate\_higher: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>The record with higher value for the column resolves the primary-key insert conflict.</p>
</div>
<span id="structfield.pk_conflict_predicate_lower" className="structfield section-header"><code>pk\_conflict\_predicate\_lower: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>The record with lower value for the column resolves the primary-key insert conflict.</p>
</div>
<span id="structfield.return_record_ids" className="structfield section-header"><code>return\_record\_ids: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true then return the internal record id along for each inserted record. Server default: <code>false</code>.</p>
</div>
<span id="structfield.truncate_strings" className="structfield section-header"><code>truncate\_strings: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If set to true, any strings which are too long for their target charN string columns will be truncated to fit. Server default: <code>false</code>.</p>
</div>
<span id="structfield.return_individual_errors" className="structfield section-header"><code>return\_individual\_errors: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If set to true, success will always be returned, and any errors found will be included in the info map. The “bad\_record\_indices” entry is a comma-separated list of bad records (0-based). If so, there will also be an “error\_N” entry for each record with an error, where N is the index (0-based). Server default: <code>false</code>.</p>
</div>
<span id="structfield.allow_partial_batch" className="structfield section-header"><code>allow\_partial\_batch: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If set to true, all correct records will be inserted and incorrect records will be rejected and reported. Otherwise, the entire batch will be rejected if any records are incorrect. Server default: <code>false</code>.</p>
</div>
<span id="structfield.error_handling" className="structfield section-header"><code>error\_handling: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Specifies how errors should be handled upon insertion. When set, this option is authoritative; supplying a contradictory allow\_partial\_batch is an error. Server default: <code>abort</code>.</p>
</div>
<span id="structfield.dry_run" className="structfield section-header"><code>dry\_run: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If set to true, no data will be saved and any errors will be returned. Server default: <code>false</code>.</p>
</div>
<span id="structfield.request_schema_str" className="structfield section-header"><code>request\_schema\_str: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Type schema of <code>list</code> (when <code>list\_encoding</code> is binary), in \[\[“{"{"}column\_name{"}"}”,“{"{"}column\_type{"}"}”\]\] format. When non-empty and different from the table’s schema, the server remaps the incoming records to the table’s full schema. Columns present in the table but absent from this schema are filled using their default values, NULL (if nullable), or an error is returned. If empty, records must match the table’s full schema.</p>
</div>
<span id="structfield.transformations" className="structfield section-header"><code>transformations: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Comma-separated expressions, one per target table column. Each expression is evaluated per record. Empty entries (two consecutive commas) mean no transformation for that column – the value is resolved from the input record, table default, NULL, or an error. Expressions may reference input columns by name or by position ($1 for the first input column, $2 for the second, etc.).</p>
</div>
