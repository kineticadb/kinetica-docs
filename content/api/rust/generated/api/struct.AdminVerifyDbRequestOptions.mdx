<div className="docblock">
<p>When true, verifies that null values are set to zero. Server default: <code>false</code>.</p>
</div>
<span id="structfield.verify_persist" className="structfield section-header"><code>verify\_persist: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>When true, persistent objects will be compared against their state in memory and workers will be checked for orphaned table data in persist. To check for orphaned worker data, either set concurrent\_safe in <code>options</code> to true or place the database offline. Server default: <code>false</code>.</p>
</div>
<span id="structfield.concurrent_safe" className="structfield section-header"><code>concurrent\_safe: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>When true, halts other jobs while the verify operation runs. Server default: <code>true</code>.</p>
</div>
<span id="structfield.verify_rank0" className="structfield section-header"><code>verify\_rank0: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true, compare rank0 table metadata against workers’ metadata. Server default: <code>false</code>.</p>
</div>
<span id="structfield.delete_orphaned_tables" className="structfield section-header"><code>delete\_orphaned\_tables: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true, orphaned table directories found on workers for which there is no corresponding metadata will be deleted. It is recommended to run this while the database is offline OR set concurrent\_safe in <code>options</code> to true. Server default: <code>false</code>.</p>
</div>
<span id="structfield.verify_orphaned_tables_only" className="structfield section-header"><code>verify\_orphaned\_tables\_only: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>If true, only the presence of orphaned table directories will be checked, all persistence and table consistency checks will be skipped. Server default: <code>false</code>.</p>
</div>
<span id="structfield.table_includes" className="structfield section-header"><code>table\_includes: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Comma-separated list of table names to include when verifying table consistency on workers. Cannot be used simultaneously with table\_excludes.</p>
</div>
<span id="structfield.table_excludes" className="structfield section-header"><code>table\_excludes: <a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/string/struct.String.html" title="struct alloc::string::String">String</a></code></span>
<div className="docblock">
<p>Comma-separated list of table names to exclude when verifying table consistency on workers. Cannot be used simultaneously with table\_includes.</p>
