<div className="details toggle top-doc">
<div className="docblock">
<p>Options for configuring the BulkInserter.</p>
<p>The insert options map is passed directly to <code>insert\_records</code> calls and supports the same options as the <code>/insert/records</code> endpoint.</p>
</div>
</div>

</div>
<span id="structfield.max_retries" className="structfield section-header"><code>max\_retries: <a className="primitive" href="https://doc.rust-lang.org/1.98.1/std/primitive.usize.html">usize</a></code></span>
<div className="docblock">
<p>Maximum number of retries for failed insertions. Default is 3.</p>
<p>This counts retries after the first attempt (0 means one attempt), only connection failures are retried, and the count starts again on another cluster after an HA failover.</p>
</div>
<span id="structfield.worker_list" className="structfield section-header"><code>worker\_list: <a className="enum" href="https://doc.rust-lang.org/1.98.1/core/option/enum.Option.html" title="enum core::option::Option">Option</a>&lt;<a className="struct" href="/content/api/rust/worker_list/struct.WorkerList" title="struct gpudb_api::worker_list::WorkerList">WorkerList</a>&gt;</code></span>
<div className="docblock">
<p>Optional worker list for multi-head ingest. If None, the worker list will be automatically configured from the server. Pass an empty WorkerList to disable multi-head ingest.</p>
</div>
<span id="structfield.max_in_flight_batches" className="structfield section-header"><code>max\_in\_flight\_batches: <a className="primitive" href="https://doc.rust-lang.org/1.98.1/std/primitive.usize.html">usize</a></code></span>
<div className="docblock">
<p>Maximum number of concurrent in-flight batch requests. Limits memory usage by blocking when this limit is reached. Default is 100.</p>
</div>
<span id="structfield.batch_listener" className="structfield section-header"><code>batch\_listener: <a className="enum" href="https://doc.rust-lang.org/1.98.1/core/option/enum.Option.html" title="enum core::option::Option">Option</a>&lt;<a className="struct" href="https://doc.rust-lang.org/1.98.1/alloc/sync/struct.Arc.html" title="struct alloc::sync::Arc">Arc</a>&lt;dyn <a className="trait" href="/content/api/rust/bulk_inserter/trait.BatchInsertionListener" title="trait gpudb_api::bulk_inserter::BatchInsertionListener">BatchInsertionListener</a>&gt;&gt;</code></span>
<div className="docblock">
<p>Optional batch insertion listener for callbacks. Called when each batch completes (success or failure).</p>

<h5 id="example">Example</h5>
<div>

```rust
use gpudb_api::{BatchInsertionListener, BatchInsertionResult, BulkInserterOptions};
use std::sync::Arc;

struct MyListener;
impl BatchInsertionListener for MyListener {
    fn on_batch_inserted(&self, result: &BatchInsertionResult) {
        println!("Batch completed: {} records", result.batch_size);
    }
}

let mut options = BulkInserterOptions::new();
options.set_batch_listener(Arc::new(MyListener));
```
