<h2 id="fields" className="fields section-header">Fields</h2>
<span id="structfield.flush_interval" className="structfield section-header"><code>flush\_interval: <a className="primitive" href="https://doc.rust-lang.org/1.98.1/std/primitive.i32.html">i32</a></code></span>
<div className="docblock">
<p>Time interval in seconds for automatic periodic flush. Set to -1 (NO\_PERIODIC\_FLUSH) to disable automatic flush.</p>
</div>
<span id="structfield.flush_when_full" className="structfield section-header"><code>flush\_when\_full: <a className="primitive" href="https://doc.rust-lang.org/1.98.1/std/primitive.bool.html">bool</a></code></span>
<div className="docblock">
<p>What the timed flush sends: if true (the default) only queues that have reached the batch size; if false, every buffered record regardless of queue fullness.</p>
<p>Only the timed flush reads this; <a href="/content/api/rust/bulk_inserter/struct.BulkInserter#method.flush" title="method gpudb_api::bulk_inserter::BulkInserter::flush"><code>BulkInserter::flush</code></a> and <a href="/content/api/rust/bulk_inserter/struct.BulkInserter#method.close" title="method gpudb_api::bulk_inserter::BulkInserter::close"><code>BulkInserter::close</code></a> always send everything. Because the insert paths already send a queue the moment it fills, a timed flush with <code>true</code> usually finds nothing to send. Use <code>false</code> if the timer should push partial batches out.</p>
</div>
