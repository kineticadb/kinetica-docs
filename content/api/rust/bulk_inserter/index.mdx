<p>Shard-aware high-performance bulk insert using serde\_avro\_fast for encoding.</p>
<p><code>BulkInserter</code> routes records to the correct worker based on shard key computation, enabling true multi-head ingest where each record is sent directly to the worker that owns its shard.</p>
<h2 id="how-shard-aware-routing-works">How Shard-Aware Routing Works</h2>
<ol>
<li>On initialization, fetch the routing table via <code>admin\_show\_shards</code></li>
<li>Fetch the table schema via <code>show\_table</code> to identify shard key columns</li>
<li>Build a <code>RecordKeyBuilder</code> to compute routing keys</li>
<li>For each record, compute its shard key hash using all shard key columns</li>
<li>Use the routing table to determine which worker owns that shard</li>
<li>Route the record directly to that worker</li>
</ol>
<h2 id="performance">Performance</h2>
<ul>
<li>Shard-aware routing eliminates server-side record redistribution</li>
<li>Each worker receives only records that belong to its shards</li>
<li>Faster Avro encoding with <code>serde\_avro\_fast</code> (\~6-7x faster than apache-avro)</li>
<li>Parallel encoding with rayon for maximum throughput</li>
</ul>

<p>The batch methods use parallel shard key computation and reduce lock contention by grouping records before acquiring locks. This provides up to 8x faster client-side queue throughput for large batches.</p>

<h2 id="further-features">Further Features</h2>
<h3 id="backpressure-control">Backpressure Control</h3>
<p>Use <code>insert\_with\_backpressure()</code> for memory-bounded operation:</p>
<div>

```rust
let mut options = BulkInserterOptions::new();
options.set_max_in_flight_batches(50);  // Limit concurrent batches

let inserter = BulkInserter::with_options(kinetica, "my_table".into(), 50000, 8, Some(options)).await?;

for record in records {
    inserter.insert_with_backpressure(Arc::new(record)).await?;
}
```

</div>
<h3 id="timed-flush">Timed Flush</h3>
<p>Configure automatic periodic flush:</p>
<div>

```rust
let mut options = BulkInserterOptions::new();
options.set_flush_options(FlushOptions::new(false, 30));  // Flush every 30 seconds

let inserter = BulkInserter::with_options(kinetica, "my_table".into(), 50000, 8, Some(options)).await?;
// Timed flush runs automatically in background
```

</div>
<h3 id="error-queue">Error Queue</h3>
<p>Non-blocking async error collection:</p>
<div>

```rust
// After insertion, check for errors
let errors = inserter.drain_errors();
for err in errors {
    eprintln!("Error: {} at {}", err.message, err.worker_url);
}
```

</div>
<h3 id="batch-callbacks">Batch Callbacks</h3>
<p>Real-time monitoring via <code>BatchInsertionListener</code>:</p>
<div>

```rust
use gpudb_api::{BatchInsertionListener, BatchInsertionResult};

struct MyListener;
```

<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::{Kinetica, BulkInserter, BulkInserterOptions, KineticaRecord, ShardKeyExtractor, ShardKeyValue, ShardKeyValues};
use smallvec::smallvec;
use std::sync::Arc;

#[derive(serde::Serialize, Default)]
struct MyRecord { id: i32, name: String }

impl ShardKeyExtractor for MyRecord {
    fn shard_key_values(&self) -> ShardKeyValues<'_> {
        smallvec![("id", ShardKeyValue::Int(self.id))]
    }
}

// Simple usage with defaults
let inserter = BulkInserter::new(
    kinetica.clone(),
    "my_schema.my_table".into(),
    50000,  // batch size
    16      // num workers
).await?;

// Or with options
let mut options = BulkInserterOptions::default();
options.set_update_on_existing_pk(true);
let inserter_with_options = BulkInserter::<MyRecord>::with_options(
    kinetica,
    "my_schema.my_table".into(),
    50000,
    16,
    Some(options),
).await?;

// Single record insertion (good for streaming)
for i in 0..1_000_000 {
    let record = Arc::new(MyRecord { id: i, name: format!("name_{}", i) });
    inserter.insert(record)?;
}

// Or batch insertion (faster for bulk loading)
let records: Vec<MyRecord> = (0..100_000)
    .map(|i| MyRecord { id: i, name: format!("name_{}", i) })
    .collect();
inserter.insert_batch(records)?;

inserter.flush().await?;
```
