<div className="details toggle top-doc">
<div className="docblock">
<p>Records the inserter did not queue, and why, for the caller to retry or report.</p>
<p>For <a href="/content/api/rust/bulk_inserter/struct.BulkInserter#method.insert" title="method gpudb_api::bulk_inserter::BulkInserter::insert"><code>BulkInserter::insert</code></a>, the record. For <a href="/content/api/rust/bulk_inserter/struct.BulkInserter#method.insert_batch" title="method gpudb_api::bulk_inserter::BulkInserter::insert_batch"><code>BulkInserter::insert\_batch</code></a>: the records before the first that cannot be queued are queued, and that one and every one after it come back here; a batch whose JSON does not validate comes back whole. Where the inserter is closed, a full batch it could not send comes back too.</p>
<p>Converts into its <a href="/content/api/rust/errors/enum.KineticaError" title="enum gpudb_api::errors::KineticaError"><code>KineticaError</code></a>, so <code>?</code> works where one is returned, and displays as it does.</p>
