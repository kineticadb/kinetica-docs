</div>
</div>
<div className="docblock">
<p>Appends an unsigned long given as text: the value’s low 64 bits, little-endian like every other number in the key.</p>
<p>The text must be one to twenty digits, or this writes nothing and fails. That check is of the form, not the range, so a twenty-digit value above <code>u64::MAX</code> passes and keeps only its low 64 bits.</p>
<p>Only ASCII digits are accepted, as for a look-up filter (see <code>RecordKeyBuilder::build\_expression</code>). The server refuses other digits too (“invalid ulong”), so such a record fails either way; here it fails before it is sent.</p>
</div>
