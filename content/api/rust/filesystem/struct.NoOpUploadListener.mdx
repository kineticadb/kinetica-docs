<div className="docblock">
<p>A no-op upload listener that ignores all callbacks. Useful for operations where progress tracking is not needed.</p>
<p>Passing it behaves exactly like passing <code>None</code>; it is for code that needs a <code>&amp;dyn FileUploadListener</code> in hand regardless.</p>
