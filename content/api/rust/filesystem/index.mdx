<p>KiFS (Kinetica File System) API module.</p>
<p>This module provides a high-level API for interacting with Kinetica’s distributed file system (KiFS). It supports file uploads, downloads, directory management, and file operations with support for both single-file and multi-part transfers.</p>
<h2 id="features">Features</h2>
<ul>
<li><strong>File Upload</strong>: Upload single files or multiple files with glob pattern support</li>
<li><strong>File Download</strong>: Download single files or entire directories</li>
<li><strong>Directory Management</strong>: Create, delete, and list KiFS directories</li>
<li><strong>Progress Callbacks</strong>: Optional listeners for tracking upload/download progress</li>
<li><strong>Multi-part Transfers</strong>: Automatic handling of large files using chunked transfers</li>
<li><strong>Glob Pattern Support</strong>: Use patterns like <code>\*.csv</code> or <code>data/\*\*/\*.json</code> for batch operations</li>
</ul>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::{Kinetica, KineticaOptions};
use gpudb_api::filesystem::{KifsFileHandler, KifsFileHandlerOptions, UploadOptions};
use std::sync::Arc;

let kinetica = Arc::new(
    Kinetica::new(vec!["http://localhost:9191".to_string()], KineticaOptions::new()).await?
);

// Create a file handler
let handler = KifsFileHandler::new(kinetica, None);

// Create a directory
handler.create_directory("my_directory", true).await?;

// Upload a file
handler.upload("/path/to/file.csv", "my_directory", None, None).await?;

// Upload multiple files with glob pattern
handler.upload("/data/*.csv", "my_directory", None, None).await?;

// Download a file
handler.download("my_directory/file.csv", "/local/path", None, None).await?;

// List files in a directory
let files = handler.show_files(vec!["my_directory".to_string()]).await?;
for file in files {
    println!("File: {} ({} bytes)", file.file_name, file.file_size);
}

// Delete a file
handler.delete_files(vec!["my_directory/file.csv".to_string()], true).await?;

// Delete a directory
handler.delete_directory("my_directory", true, true).await?;
```
