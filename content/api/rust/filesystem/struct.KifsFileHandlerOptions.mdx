<div className="docblock">
<p>Options for the KiFS file handler.</p>
<p>These options control the behavior of file uploads and downloads, including batch sizes and upload concurrency.</p>
<p>The fields are private and are set only through the validating <code>with\_\*</code> methods. A public <code>file\_size\_to\_split</code> could be set to 0 or a negative number, which the multi-part part-count arithmetic divides by.</p>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::filesystem::KifsFileHandlerOptions;

// Create default options
let options = KifsFileHandlerOptions::default();

// Create custom options
let options = KifsFileHandlerOptions::new()
    .with_file_size_to_split(50 * 1024 * 1024)? // 50 MB
    .with_thread_pool_size(1)?;
```

<div className="docblock">
<p>Sets how many full-file upload batches are sent concurrently.</p>
<p>Uploads proceed in waves: up to this many batches are sent at once, and the next wave starts when every batch of the current one has finished.</p>
<h5 id="arguments-1">Arguments</h5>
<ul>
<li><code>size</code> - Number of concurrent batches. Must be between 1 and the number of available CPUs.</li>
</ul>
<h5 id="errors-1">Errors</h5>
<p>Fails if the size is 0 or greater than the number of available CPUs.</p>

<div className="docblock">
<p>Sets the ceiling on full-file upload payload bytes held in memory at once.</p>
<p>Lower it where memory is tight: an upload then waits for outstanding batches to finish more often, trading throughput for a smaller peak. Raise it for more throughput where memory is plentiful.</p>
<h5 id="arguments-2">Arguments</h5>
<ul>
<li><code>bytes</code> - The ceiling in bytes. Must be positive.</li>
</ul>
<h5 id="errors-2">Errors</h5>
<p>Fails if <code>bytes</code> is &lt;= 0.</p>
</div>
