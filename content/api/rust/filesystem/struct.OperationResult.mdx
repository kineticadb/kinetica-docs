<div className="docblock">
<p>Result of an upload or download operation.</p>
<p>This struct encapsulates information about the outcome of a file transfer, including success/failure status, error information, and multi-part details.</p>
<p>Results compare and hash by <code>successful</code>, <code>multi\_part</code>, <code>file\_name</code>, <code>error\_message</code> and <code>op\_mode</code>.</p>
</div>
