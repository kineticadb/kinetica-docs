<div className="docblock">
<p>A no-op download listener that ignores all callbacks. Useful for operations where progress tracking is not needed.</p>
<p>Passing it behaves exactly like passing <code>None</code>; it is for code that needs a <code>&amp;dyn FileDownloadListener</code> in hand regardless.</p>
