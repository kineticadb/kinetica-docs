<p>Options for file upload operations.</p>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::filesystem::UploadOptions;

// Create default options (recursive search, no TTL)
let options = UploadOptions::default();

// Create custom options
let options = UploadOptions::new()
    .with_recursive(true)
    .with_ttl(3600); // Files expire in 1 hour
```

</div>
</div>

<h2 id="fields" className="fields section-header">Fields</h2>
<span id="structfield.recursive" className="structfield section-header"><code>recursive: <a className="primitive" href="https://doc.rust-lang.org/1.98.1/std/primitive.bool.html">bool</a></code></span>
<div className="docblock">
<p>Whether to search subdirectories for the files to upload. Default: <code>true</code></p>
<p>This applies to glob patterns and to a directory given by name, which uploads its files as <code>&lt;directory&gt;/\*</code> does. A file given by name is uploaded alone either way: <code>upload("/data/file.csv")</code> uploads that file, not also <code>/data/sub/file.csv</code>. Files found below a pattern’s or directory’s base go to the same path below the remote directory.</p>
</div>
<span id="structfield.ttl" className="structfield section-header"><code>ttl: <a className="primitive" href="https://doc.rust-lang.org/1.98.1/std/primitive.i32.html">i32</a></code></span>
<div className="docblock">
<p>Time-to-live value for uploaded files in seconds. A value of -1 or 0 means no expiration. Default: <code>-1</code></p>
</div>
