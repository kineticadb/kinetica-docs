<h2 id="gpudb-api-rust-client">GPUdb API Rust Client</h2>
<p>A high-performance, async Rust client for Kinetica (GPUdb) - a distributed GPU-accelerated database.</p>
<h3 id="features">Features</h3>
<ul>
<li><strong>Async/await</strong> - Built on Tokio for non-blocking I/O</li>
<li><strong>High Performance</strong> - Achieves 600K+ records/sec with optimized bulk insert</li>
<li><strong>Type Safe</strong> - Auto-generated API from Avro schemas</li>
<li><strong>Fast Avro Encoding</strong> - Uses <code>serde\_avro\_fast</code> for 6-7x faster serialization</li>
<li><strong>Parallel Processing</strong> - Multi-worker architecture with rayon for encoding</li>
<li><strong>Worker Distribution</strong> - Direct routing to worker nodes for maximum throughput</li>
<li><strong>Logging</strong> - Built-in logging via the <code>log</code> crate (default level: WARN)</li>
</ul>
<h3 id="logging">Logging</h3>
<p>This library uses the <a href="https://docs.rs/log"><code>log</code></a> crate for logging. To enable logging output, add a logging implementation like <code>env\_logger</code> to your application:</p>
<div>

```toml
[dependencies]
env_logger = "0.11"
```

</div>
<p>Then initialize it in your main function:</p>
<div>

```rust
// Enable logging with default WARN level
env_logger::init();
// Or with a specific level: RUST_LOG=gpudb_api=debug cargo run
```

</div>
<h4 id="log-levels">Log Levels</h4>
<p>Messages are logged at these levels:</p>
<ul>
<li><strong>ERROR</strong>: A request that could not be sent (“Giving up with an exit error after &lt;n&gt;ms …”), and failures the call goes on past, such as a KiFS file that could not be transferred. Errors are also returned via <code>Result</code>.</li>
<li><strong>WARN</strong>: Failing over to another cluster, and settings that are ignored</li>
<li><strong>INFO</strong>: Failing back to the primary cluster, and KiFS files transferred</li>
<li><strong>DEBUG</strong>: Connecting, configuration details, worker setup, routing info</li>
<li><strong>TRACE</strong>: Per-batch details, HTTP request/response info (very verbose)</li>
</ul>
<p>The level is the application’s logger’s to set, for the <code>gpudb\_api</code> target (as with <code>RUST\_LOG=gpudb\_api=debug</code> above), or for all with <a href="https://docs.rs/log/0.4.29/log/fn.set_max_level.html" title="fn log::set_max_level"><code>log::set\_max\_level</code></a>.</p>
<h3 id="quick-start">Quick Start</h3>
<div>

```rust
use gpudb_api::{
    Kinetica, KineticaOptions, BulkInserter, BulkInserterOptions,
    KineticaRecord, ShardKeyExtractor, ShardKeyValue, ShardKeyValues,
    avro_schema, AvroSchemaBuilder, TypePropertiesBuilder,
};
use smallvec::smallvec;
use std::sync::Arc;
use std::collections::HashMap;
use serde::Serialize;

// Define your record type
#[derive(Serialize, Clone, Default)]
struct MyRecord {
    id: i32,
    name: String,
}

impl ShardKeyExtractor for MyRecord {
    fn shard_key_values(&self) -> ShardKeyValues<'_> {
        smallvec![("id", ShardKeyValue::Int(self.id))]
    }
}

impl KineticaRecord for MyRecord {
    fn avro_schema(&self) -> &'static str {
        avro_schema!(
            AvroSchemaBuilder::new("MyRecord")
                .int_field("id")
                .string_field("name")
        )
    }

    fn type_properties() -> HashMap<String, Vec<String>> {
        TypePropertiesBuilder::new().build()
    }
}

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    // Create client with authentication
    let mut options = KineticaOptions::new();
    options.set_username("admin")
           .set_password("password")
           .set_use_snappy(false);

    let kinetica = Arc::new(
        Kinetica::new(vec!["http://localhost:9191".to_string()], options).await?
    );

    // Simple usage: Create bulk inserter with default options
    let inserter = BulkInserter::<MyRecord>::new(
        kinetica.clone(),
        "my_table".into(),
        50000,  // batch size
        8       // num workers
    ).await?;

    // Or with options:
    let mut bulk_options = BulkInserterOptions::new();
    bulk_options.set_update_on_existing_pk(true);  // Enable upsert mode

    let inserter_with_options = BulkInserter::<MyRecord>::with_options(
        kinetica,
        "my_table".into(),
        50000,
        8,
        Some(bulk_options),
    ).await?;

    // Insert records...

    Ok(())
}
```
