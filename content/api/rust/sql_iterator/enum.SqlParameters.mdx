</div>
<div className="docblock">
<p>Parameter values, sent as a JSON array.</p>
</div>
<div id="variant.Json" className="section variant">
<h3 className="code-header">Json(<a className="enum" href="https://docs.rs/serde_json/1.0.149/serde_json/value/enum.Value.html" title="enum serde_json::value::Value">Value</a>)</h3>
</div>
<div className="docblock">
<p>Parameters of any JSON type – numbers, booleans, nulls, text, arrays and objects – sent as JSON text. So <code>\[1, 2.5, null\]</code> goes as <code>\[1,2.5,null\]</code>, typed, where <a href="/content/api/rust/sql_iterator/enum.SqlParameters#variant.Values" title="variant gpudb_api::sql_iterator::SqlParameters::Values"><code>Self::Values</code></a> would send text. Build it with <code>serde\_json::json!</code>, or from a <code>Vec&lt;serde\_json::Value&gt;</code>.</p>
<p>The server decides what it takes. Kinetica 7.2.3.21 binds numbers, text and nulls with their types (<code>SELECT $1</code> of <code>\[1, null\]</code> is an int and a null), refuses a boolean (“Unexpected json value in query\_parameters”), and takes nested arrays only for an INSERT.</p>
</div>
