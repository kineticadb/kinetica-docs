<p>Iterates over the records an SQL query returns.</p>
<p>The first batch is fetched when the iterator is created. Call <a href="/content/api/rust/sql_iterator/struct.SqlIterator#method.close" title="method gpudb_api::sql_iterator::SqlIterator::close"><code>SqlIterator::close</code></a> when done to drop the paging tables; nothing drops them otherwise.</p>
