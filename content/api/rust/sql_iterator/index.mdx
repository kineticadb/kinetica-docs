<p>Iterating over the records an SQL query returns, a batch at a time.</p>
<p>The query runs against a paging table of the iterator’s own, named by a random UUID, so batches come from one result set in one order, and the server-side tables the iteration creates are dropped by <a href="/content/api/rust/sql_iterator/struct.SqlIterator#method.close" title="method gpudb_api::sql_iterator::SqlIterator::close"><code>SqlIterator::close</code></a>.</p>
<div>

```rust
use gpudb_api::{Kinetica, KineticaOptions, SqlIterator};
use std::sync::Arc;

let kinetica = Arc::new(Kinetica::new(vec!["http://localhost:9191".to_string()], KineticaOptions::new()).await?);
let mut records = SqlIterator::new(kinetica, "SELECT * FROM my_table").await?;
while records.has_next() {
    println!("{:?}", records.next().await?);
}
records.close().await;
```
