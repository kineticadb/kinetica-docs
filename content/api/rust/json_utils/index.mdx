<div className="docblock">
<p>Whether a text is a JSON object or array, and how a list of JSON records is sent as one array.</p>
<p>A text is read leniently: unquoted and single-quoted names and values, <code>;</code> between members, and trailing, empty and leading commas are taken, and whatever follows the outermost object or array is ignored. A name twice in one object is not taken. Only whether the text parses is answered.</p>
<p>The parse keeps its own stack, so it has no limit on nesting depth.</p>
