<p>High-performance Avro encoding and decoding utilities.</p>
<p>This module provides optimized Avro serialization and deserialization using <code>serde\_avro\_fast</code> for best performance, with <code>rayon</code> parallelism for large batches.</p>
<h2 id="performance">Performance</h2>
<ul>
<li><strong>Encoding</strong>: Uses <code>serde\_avro\_fast</code> for 2-3x faster encoding than <code>apache\_avro</code></li>
<li><strong>Decoding</strong>: Uses <code>serde\_avro\_fast</code> + rayon for up to 8x faster decoding</li>
<li><strong>Parallelism</strong>: Automatically enabled for batches above threshold (500 records)</li>
</ul>
<p>These helpers split large batches over rayon’s threads, with the results of a sequential pass: records come back in order, and a batch with several bad records reports the first of them. Failures read “Could not encode object: …” and “Could not decode object: …”.</p>
<h2 id="usage">Usage</h2>
<h3 id="encoding-records">Encoding Records</h3>
<div>

```rust
use gpudb_api::avro::{encode_records, parse_fast_schema};

let schema = parse_fast_schema(schema_str)?;
let encoded: Vec<Vec<u8>> = encode_records(&schema, &records)?;
```

</div>
<h3 id="decoding-records">Decoding Records</h3>
<div>

```rust
use gpudb_api::avro::{decode_records, parse_fast_schema};

#[derive(serde::Deserialize)]
struct Employee { id: i32, name: String }

let schema = parse_fast_schema(&response.type_schema)?;
let employees: Vec<Employee> = decode_records(&schema, &response.records_binary)?;
```
