<p>Decodes binary Avro records sequentially using serde\_avro\_fast.</p>
<p>Use this for small result sets (&lt;500 records) where parallel overhead would outweigh benefits. For automatic threshold handling, use <code>decode\_records</code>.</p>
<h2 id="performance">Performance</h2>
<p>Achieves 2-4M records/second, 3-5x faster than apache\_avro.</p>
