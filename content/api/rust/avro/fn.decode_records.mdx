<p>Decodes binary Avro records to typed Rust structs.</p>
<p>This is the <strong>recommended</strong> decoding function. It automatically chooses between sequential and parallel decoding based on record count, and uses <code>serde\_avro\_fast</code> for optimal performance.</p>
<h2 id="type-parameters">Type Parameters</h2>
<ul>
<li><code>T</code> - The target type to decode into. Must implement <code>serde::Deserialize</code>.</li>
</ul>
<h2 id="arguments">Arguments</h2>
<ul>
<li><code>schema</code> - The serde\_avro\_fast schema to use for decoding</li>
<li><code>binary\_records</code> - Slice of binary Avro-encoded records</li>
</ul>
<h2 id="returns">Returns</h2>
<p>A vector of decoded typed records, or an error if any record fails to decode.</p>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::avro::{decode_records, parse_fast_schema};

#[derive(serde::Deserialize)]
struct Employee { id: i32, name: String, salary: f64 }

let response = kinetica.get_records_raw(&request).await?;
let schema = parse_fast_schema(&response.type_schema)?;
let employees: Vec<Employee> = decode_records(&schema, &response.records_binary)?;
```
