<p>Encodes Arc-wrapped records, partitioning the batch over threads.</p>
<p>This strategy partitions the batch into chunks (one per thread) and processes each chunk sequentially within the thread. This reduces:</p>
<ul>
<li>Lock contention (each thread has its own chunk)</li>
<li>SerializerConfig creation overhead (reused within chunks)</li>
<li>Memory allocation (pre-allocated buffers per chunk)</li>
</ul>
