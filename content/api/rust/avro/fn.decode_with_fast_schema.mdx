<p>Decodes binary Avro records using a pre-parsed serde\_avro\_fast schema.</p>
<p>This is equivalent to <code>decode\_records</code> but accepts the schema by reference. Useful when decoding multiple batches with the same schema to avoid repeated schema parsing.</p>
<h2 id="example">Example</h2>
<div>

```rust
let schema = parse_fast_schema(&response.type_schema)?;

// Decode multiple batches without re-parsing schema
for batch in batches {
    let records: Vec<MyRecord> = decode_with_fast_schema(&schema, &batch)?;
}
```
