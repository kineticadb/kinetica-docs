<p>Encodes records to Avro binary format.</p>
<p>Automatically chooses between sequential and parallel encoding based on record count. Uses <code>serde\_avro\_fast</code> for optimal performance.</p>
<h2 id="type-parameters">Type Parameters</h2>
<ul>
<li><code>T</code> - The record type. Must implement <code>serde::Serialize</code>.</li>
</ul>
<h2 id="arguments">Arguments</h2>
<ul>
<li><code>schema</code> - The serde\_avro\_fast schema to use for encoding</li>
<li><code>records</code> - Slice of records to encode</li>
</ul>
<h2 id="returns">Returns</h2>
<p>A vector of binary-encoded Avro records.</p>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::avro::{encode_records, parse_fast_schema};

let schema = parse_fast_schema(schema_str)?;
let encoded = encode_records(&schema, &records)?;
```
