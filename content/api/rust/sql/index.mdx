<p>SQL client and result parser for Kinetica’s HTTP API</p>
<p>Statements are sent to <code>/execute/sql</code> over the same <a href="/content/api/rust/gpudb/struct.Kinetica" title="struct gpudb_api::gpudb::Kinetica"><code>Kinetica</code></a> connection used by the rest of the API, so they share its authentication, TLS and HA failover. For the PostgreSQL wire protocol, see the <code>sqlx\_support</code> module (feature <code>sqlx</code>).</p>

<ul>
<li><strong><a href="/content/api/rust/sql/struct.SqlClient" title="struct gpudb_api::sql::SqlClient"><code>SqlClient</code></a></strong> - Executes SQL, with paging support for large result sets</li>

<h2 id="quick-start">Quick Start</h2>
<div>

```rust
use gpudb_api::{Kinetica, KineticaOptions, SqlClient};
use std::sync::Arc;

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let options = KineticaOptions::new();
    let kinetica = Arc::new(
        Kinetica::new(vec!["http://localhost:9191".to_string()], options).await?
    );

    let client = SqlClient::new(kinetica);
    let mut result = client
        .execute("SELECT id, name FROM my_table WHERE value > 100 ORDER BY id LIMIT 10")
        .await?;

    for row in result.rows()? {
        let id: i64 = row.get("id")?;
        let name: String = row.get("name")?;
        println!("id={}, name={}", id, name);
    }

    Ok(())
}
```

    // Process row...
