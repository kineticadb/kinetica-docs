<p>SQL hints that can be embedded in statements or passed as execute\_sql options.</p>
<p>Kinetica supports SQL hints (KI\_HINT) that can be added as comments within queries to control query execution behavior. This struct provides a builder interface for configuring hints programmatically.</p>
<h2 id="hint-types">Hint Types</h2>
<p>There are two ways to apply hints:</p>
<ol>
<li><strong>Inline hints</strong>: Embedded in the SQL statement as comments (<code>/\* KI\_HINT\_... \*/</code>)</li>
<li><strong>Options hints</strong>: Passed in the <code>options</code> map of the execute\_sql API</li>
</ol>
<p>This struct supports both approaches.</p>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::SqlHints;

// Create hints for upsert operation
let hints = SqlHints::new()
    .update_on_existing_pk(true)
    .distributed_operations(true);

// Convert to inline SQL comment
let sql_with_hints = format!(
    "INSERT INTO my_table {} (id, name) VALUES (1, 'test')",
    hints.to_inline_hint()
);
// Result: "INSERT INTO my_table /* KI_HINT_UPDATE_ON_EXISTING_PK */ (id, name) VALUES (1, 'test')"

// Or convert to options map for execute_sql API
let options = hints.to_options_map();
```
