<div className="docblock">
<p>A SQL client that automatically batches INSERT statements for high-performance bulk loading.</p>
<p>When you execute INSERT statements in a loop, this client accumulates them and automatically flushes through <code>BulkInserter&lt;GenericRecord&gt;</code> when the batch size is reached. This provides massive performance improvements over executing individual INSERT statements.</p>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::{Kinetica, KineticaOptions, BatchingSqlClient};
use std::sync::Arc;

let kinetica = Arc::new(Kinetica::new(
    vec!["http://localhost:9191".to_string()],
    KineticaOptions::new()
).await?);

// Create batching client with 10000 record batch size
let mut client = BatchingSqlClient::new(kinetica, 10000, 8);

// Execute 1 million INSERT statements - they are automatically batched!
for i in 0..1_000_000 {
    client.execute(&format!(
        "INSERT INTO my_table (id, name, value) VALUES ({}, 'user_{}', {})",
        i, i, i as f64 * 1.5
    )).await?;
}

// Flush any remaining records
let stats = client.close().await?;
println!("Inserted {} records at {:.0} rec/sec",
    stats.records_inserted, stats.records_per_second);
```

<div className="docblock">
<p>Execute a SQL statement.</p>
<ul>
<li>INSERT statements are accumulated and batched automatically</li>
<li>Other statements (SELECT, CREATE, etc.) are executed immediately with hints applied</li>
</ul>
<p>When the batch size is reached, records are automatically flushed through <code>BulkInserter&lt;GenericRecord&gt;</code> with shard-aware routing.</p>
<p>For non-INSERT statements, any configured SQL hints (via <code>set\_hints()</code> or <code>with\_hints()</code>) will be applied to the execute\_sql request.</p>
