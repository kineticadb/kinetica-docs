<p>A single row from a SQL result set.</p>
<p>Provides type-safe access to column values by name.</p>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::Row;

let id: i64 = row.get("id")?;
let name: String = row.get("name")?;
let score: Option<f64> = row.get_opt("score")?;
```
