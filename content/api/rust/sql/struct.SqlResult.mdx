<div className="docblock">
<p>Wrapper around <code>RawExecuteSqlResponse</code> with convenient parsing methods.</p>
<p><code>SqlResult</code> provides ergonomic access to query results including:</p>
<ul>
<li>Row iteration</li>
<li>Column extraction</li>
<li>Scalar value retrieval</li>
<li>Direct deserialization to structs</li>
</ul>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::SqlResult;

// Check metadata
println!("Total records: {}", result.total_records());
println!("Has more: {}", result.has_more());

// Get a single value
let count: i64 = result.scalar()?;

// Extract a column
let names: Vec<String> = result.column("name")?;

// Iterate rows
for row in result.rows()? {
    let id: i64 = row.get("id")?;
    println!("ID: {}", id);
}
```
