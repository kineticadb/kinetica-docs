<p>How records are sent as JSON.</p>
<p><code>compression\_on</code> changes nothing: JSON requests are not compressed. <code>validate\_json</code> has a JSON <a href="/content/api/rust/bulk_inserter/struct.BulkInserter" title="struct gpudb_api::bulk_inserter::BulkInserter"><code>BulkInserter</code></a> check each record it is given; <code>insert\_records\_from\_json</code> leaves the checking to the server.</p>
