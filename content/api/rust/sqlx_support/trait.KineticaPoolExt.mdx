<div className="docblock">
<p>Execute a query and process all results page by page with a callback.</p>
<p>This is memory-efficient as it only loads one page at a time.</p>
<h5 id="arguments-1">Arguments</h5>
<ul>
<li><code>sql</code> - The base SQL query (without LIMIT/OFFSET)</li>
<li><code>page\_size</code> - Number of rows per page</li>
<li><code>callback</code> - Function called for each page; return <code>false</code> to stop early</li>
</ul>
<h5 id="example-1">Example</h5>
<div>

```rust
use gpudb_api::sqlx_support::{KineticaPoolExt, KineticaPool, SqlxPaginationStats};
use sqlx::Row;

let stats = pool.fetch_all_pages(
    "SELECT * FROM large_table ORDER BY id",
    10000,
    |rows, page_num| {
        println!("Processing page {} with {} rows", page_num, rows.len());
        for row in &rows {
            let id: i32 = row.get("id");
            // Process row...
        }
        Ok(true) // Continue to next page
    }
).await?;

println!("Processed {} pages, {} total rows", stats.pages_fetched, stats.rows_fetched);
```
