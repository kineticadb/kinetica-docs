<p>Bulk inserter for SQLx that uses Kinetica’s HTTP API for efficient data loading.</p>
<p>SQLx uses the PostgreSQL wire protocol which is less efficient for bulk loading than Kinetica’s native HTTP API with Avro encoding. This helper bridges the gap by sending the records through a <a href="/content/api/rust/gpudb/struct.Kinetica" title="struct gpudb_api::gpudb::Kinetica"><code>Kinetica</code></a> client, connected and configured (TLS, HA failover and the rest) as for any other HTTP API use.</p>
<p>Uses <code>GenericRecord</code> for dynamic record creation.</p>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::sqlx_support::SqlxBulkInserter;
use gpudb_api::{GenericRecord, Kinetica, KineticaError, KineticaOptions};
use std::sync::Arc;

// The HTTP API client the records are sent through
let mut options = KineticaOptions::new();
options.set_username("admin").set_password("password");
let kinetica = Arc::new(Kinetica::new(vec!["http://localhost:9191".to_string()], options).await?);

let bulk_inserter = SqlxBulkInserter::new(kinetica);

// Fetch type schema and create records
let record_type = Arc::new(bulk_inserter.fetch_type("my_table").await?);

// Setting a column fails on a name the type does not have
let records = (0..10000)
    .map(|i| {
        let mut r = record_type.new_record();
        r.set_by_name("id", i)?;
        r.set_by_name("name", format!("user_{i}"))?;
        Ok(r)
    })
    .collect::<Result<Vec<GenericRecord>, KineticaError>>()?;

// Bulk insert
let stats = bulk_inserter.insert("my_table", records, 10000).await?;
println!("Inserted {} records", stats.records_inserted);
```

<p>Perform a bulk insert of GenericRecords with shard-aware multi-head ingest.</p>
<p>This uses the high-performance <code>BulkInserter&lt;GenericRecord&gt;</code> which provides:</p>
<ul>
<li>Shard-aware routing to worker nodes (multi-head ingest)</li>
<li>Parallel batch processing</li>
<li>Avro binary encoding for maximum throughput</li>
</ul>
<h5 id="arguments">Arguments</h5>
<ul>
<li><code>table\_name</code> - The name of the table to insert into</li>
<li><code>records</code> - Vector of GenericRecords to insert</li>
<li><code>batch\_size</code> - Number of records per batch (recommended: 10000-50000)</li>
</ul>
