<div className="details toggle top-doc">
<div className="docblock">
<p>Values for the Kinetica types SQLx’s own PostgreSQL types cannot read or write over Kinetica’s protocol, or cannot reliably: see their module. A <code>JSON</code> column’s value: anything serde serializes, bound directly as JSON, and read back from the JSON Kinetica sends.</p>
<p>SQLx’s own <code>serde\_json::Value</code> and <code>sqlx::types::Json</code> bind as PostgreSQL’s <code>JSONB</code>, whose binary form starts with a version byte, which Kinetica refuses as invalid JSON. This binds the <code>JSON</code> type instead, whose value is the JSON text itself, so it reaches its column in any parameter position. It reads <code>JSON</code> and <code>JSONB</code> columns, and text such as <code>JSON\_QUERY</code>’s.</p>
