<p>Connect to Kinetica using <code>PgConnectOptions</code>.</p>
<p>This gives you full control over connection options.</p>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::sqlx_support::connect_with_options;
use sqlx::postgres::PgConnectOptions;

let options = PgConnectOptions::new()
    .host("localhost")
    .port(5432)
    .username("admin")
    .password("password")
    .database("postgres");

let pool = connect_with_options(options, 10).await?;
```
