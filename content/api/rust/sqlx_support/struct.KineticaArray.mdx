<div className="docblock">
<p>Values for the Kinetica types SQLx’s own PostgreSQL types cannot read or write over Kinetica’s protocol, or cannot reliably: see their module. An array column’s value. Kinetica sends arrays numbered from 0, which SQLx’s own <code>Vec&lt;T&gt;</code> refuses; this reads them, in the binary form a query’s results come in and in the text form <code>sqlx::raw\_sql</code> gives, and writes them as the JSON text Kinetica takes. It also reads the JSON text Kinetica sends for an array a function computes, such as <code>ARRAY\_APPEND(col, 4)</code>.</p>
<p>Use <code>KineticaArray&lt;Option&lt;T&gt;&gt;</code> for an array that may hold nulls. The element types are those of Kinetica’s arrays: <code>i32</code> (<code>INTEGER\[\]</code>), <code>i64</code> (<code>BIGINT\[\]</code>), <code>u64</code> (<code>UNSIGNED BIGINT\[\]</code>), <code>f32</code> (<code>REAL\[\]</code>), <code>f64</code> (<code>DOUBLE\[\]</code>), <code>bool</code> (<code>BOOLEAN\[\]</code>) and <code>String</code> (<code>VARCHAR\[\]</code>).</p>
