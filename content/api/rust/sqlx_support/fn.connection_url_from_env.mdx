<p>Parse a Kinetica connection URL from environment variables.</p>
<p>Looks for:</p>
<ul>
<li><code>KINETICA\_SQLX\_URL</code> - Full connection URL</li>
<li>Or individual: <code>KINETICA\_HOST</code>, <code>KINETICA\_PORT</code>, <code>KINETICA\_USER</code>, <code>KINETICA\_PASSWORD</code></li>
</ul>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::sqlx_support::connection_url_from_env;

// Set KINETICA_SQLX_URL=postgres://admin:password@localhost:5432/postgres
// Or set KINETICA_HOST, KINETICA_USER, KINETICA_PASSWORD

let url = connection_url_from_env();
```
