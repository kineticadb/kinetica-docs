<div className="docblock">
<p>Trait that must be implemented by all types that can be inserted into Kinetica.</p>
<p>This trait is automatically implemented for all generated request types. Custom record types must implement this to work with <code>BulkInserter</code>.</p>
<p><strong>Note</strong>: Types implementing this trait must also implement <code>serde::Serialize</code> for Avro encoding to work.</p>
<h2 id="example-using-builder-api---recommended">Example (Using Builder API - Recommended)</h2>
<div>

```rust
use gpudb_api::{KineticaRecord, AvroSchemaBuilder, AvroType, TypePropertiesBuilder, avro_schema};
use std::collections::HashMap;

#[derive(serde::Serialize, Clone, Default)]
struct MyRecord {
    id: i32,
    name: String,
}

impl KineticaRecord for MyRecord {
    fn avro_schema(&self) -> &'static str {
        avro_schema!(
            AvroSchemaBuilder::new("MyRecord")
                .int_field("id")
                .string_field("name")
        )
    }

    fn type_properties() -> HashMap<String, Vec<String>> {
        TypePropertiesBuilder::new()
            .primary_key("id")
            .data("name")
            .build()
    }
}
```

</div>

<div className="docblock">
<p>Whether requests of this type are Snappy-compressed when the client has <a href="/content/api/rust/gpudb/struct.KineticaOptions#structfield.use_snappy" title="field gpudb_api::gpudb::KineticaOptions::use_snappy"><code>KineticaOptions::use\_snappy</code></a> enabled.</p>

The generator overrides this for <code>/insert/records</code> and <code>/update/records</code>; every other request type keeps the default.</p>
