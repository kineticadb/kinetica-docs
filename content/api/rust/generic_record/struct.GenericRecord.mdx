<div className="docblock">
<p>A generic record that can hold values for any Kinetica type.</p>
<p>It stores values in an array indexed by column position, and uses the associated <code>Type</code> for schema information.</p>
<h2 id="example">Example</h2>
<div>

```rust
let record_type = Type::from_table(&kinetica, "my_table").await?;
let type_arc = Arc::new(record_type);

let mut record = type_arc.new_record();

// Set values by index
record.set(0, 42)?;
record.set(1, "Alice")?;

// Set values by name; a name the type does not have is an error
record.set_by_name("score", 95.5)?;

// Get values
let id: i32 = record.get_int(0).unwrap();
let name: &str = record.get_string_by_name("name").unwrap();
```

</div>
<h2 id="dates-and-times">Dates and times</h2>
<p>A date, time or datetime column holds text in Kinetica’s formats: <code>yyyy-MM-dd</code>, <code>HH:mm:ss.SSS</code> and <code>yyyy-MM-dd HH:mm:ss.SSS</code>. A record reads no other formats; format the value with chrono first:</p>
<div>

```rust
use chrono::{DateTime, FixedOffset, NaiveDate, NaiveDateTime, NaiveTime};

// Text without an offset is kept as it is
let date = NaiveDate::parse_from_str("01/15/2024", "%m/%d/%Y").unwrap();
assert_eq!(date.format("%Y-%m-%d").to_string(), "2024-01-15");
let time = NaiveTime::parse_from_str("10:30:45.123999", "%H:%M:%S%.f").unwrap();
assert_eq!(time.format("%H:%M:%S%.3f").to_string(), "10:30:45.123");
let datetime = NaiveDateTime::parse_from_str("15.01.2024 10:30", "%d.%m.%Y %H:%M").unwrap();
assert_eq!(datetime.format("%Y-%m-%d %H:%M:%S%.3f").to_string(), "2024-01-15 10:30:00.000");
// A date alone, for a datetime column, is the start of the day
let midnight = date.and_time(NaiveTime::MIN);
assert_eq!(midnight.format("%Y-%m-%d %H:%M:%S%.3f").to_string(), "2024-01-15 00:00:00.000");

// Text with an offset is converted to the offset of the time zone given
// (a fixed offset, without daylight saving)
let india = FixedOffset::east_opt(5 * 3600 + 1800).unwrap();
let zoned = DateTime::parse_from_rfc3339("2024-01-15T23:30:00Z").unwrap().with_timezone(&india);
assert_eq!(zoned.format("%Y-%m-%d %H:%M:%S%.3f").to_string(), "2024-01-16 05:00:00.000");
assert_eq!(zoned.format("%Y-%m-%d").to_string(), "2024-01-16");
```

</div>
<p>Fractions of a second past the millisecond are dropped, not rounded. chrono refuses a day past the end of its month (<code>2023-02-30</code>) and the time <code>24:00</code>. Zone names (<code>America/New\_York</code>, <code>EST</code>) need a zone database, such as the <code>chrono-tz</code> crate. A fixed offset ignores daylight saving, so give the offset in effect if that is what is meant.</p>
</div>

<h3 className="code-header">impl <a className="trait" href="https://docs.rs/serde_core/1.0.228/serde_core/ser/trait.Serialize.html" title="trait serde_core::ser::Serialize">Serialize</a> for <a className="struct" href="/content/api/rust/generic_record/struct.GenericRecord" title="struct gpudb_api::generic_record::GenericRecord">GenericRecord</a></h3>
<div className="docblock">
<p>Encodes the record for its Avro schema, field by field in column order, each value converted for its column:</p>
</div>
</div>
</div>
<div className="docblock">
<ul>
<li>a number goes into an <code>int</code>, <code>long</code>, <code>float</code> or <code>double</code> column whatever its own type, converted as <code>as</code> converts it (truncated, or rounded to the nearest);</li>
<li>a string goes only into a <code>string</code> column, and bytes only into <code>bytes</code>;</li>
<li>a nullable column is an Avro union, which takes a value only of the column’s own type, unconverted, or null.</li>
</ul>
<p>A value the column cannot take fails the record with a message that begins with <code>ENCODE\_FAILURE\_PREFIX</code>.</p>
</div>
