<p>Generic Record Support for Dynamic Type Handling</p>
<p>This module provides <code>Type</code> and <code>GenericRecord</code> types for handling records without compile-time type information.</p>
<h2 id="overview">Overview</h2>
<p><code>GenericRecord</code> is for cases where you need to work with records dynamically at runtime, without defining a specific struct:</p>
<ul>
<li><strong><a href="/content/api/rust/generic_record/struct.Type" title="struct gpudb_api::generic_record::Type"><code>Type</code></a></strong> - Immutable collection of metadata about a Kinetica type (schema, columns)</li>
<li><strong><a href="/content/api/rust/generic_record/struct.GenericRecord" title="struct gpudb_api::generic_record::GenericRecord"><code>GenericRecord</code></a></strong> - A record instance that stores values by column index</li>
</ul>
<h2 id="when-to-use-genericrecord">When to Use GenericRecord</h2>
<p>Use <code>GenericRecord</code> when:</p>
<ul>
<li>Table schema is not known at compile time</li>
<li>You’re building generic data pipelines</li>
<li>You need to copy data between tables with different schemas</li>
<li>You’re reading data from CSV/JSON and inserting dynamically</li>
</ul>
<p>Use statically-typed records (implementing <code>KineticaRecord</code>) when:</p>
<ul>
<li>Schema is known at compile time</li>
<li>You want maximum type safety and performance</li>
<li>You’re building application-specific data models</li>
</ul>
<h2 id="example">Example</h2>
<div>

```rust
use gpudb_api::{BulkInserter, GenericRecord, Kinetica, Type};
use std::sync::Arc;

// Fetch type from existing table
let record_type = Arc::new(Type::from_table(&kinetica, "my_table").await?);

// Or create type programmatically
let record_type = Type::builder("my_record")
    .add_int_column("id").primary_key()
    .add_string_column("name")
    .add_double_column("score")
    .build_arc()?;

// Create records, which share their type through the Arc
let mut record = record_type.new_record();
record.set(0, 42)?;                   // by index
record.set_by_name("name", "Alice")?; // by name
record.set_by_name("score", 95.5)?;

// Use with BulkInserter (requires schema string since GenericRecord can't implement Default)
let inserter = BulkInserter::<GenericRecord>::with_schema(
    kinetica,
    "my_table".to_string(),
    10000,  // batch_size
    8,      // num_workers
    None,   // options
    record_type.schema_string(),
).await?;
inserter.insert(Arc::new(record))?;
inserter.flush().await?;
```
