</div>
</div>
<div className="docblock">
<p>Create a column with properties.</p>
<p>The column’s type is resolved from its base type and properties, so the properties decide: a string column with the <code>date</code> property is a date. A sub-type <code>column\_type</code> that they do not already make has its property added first (see <a href="/content/api/rust/generic_record/enum.ColumnType#method.property" title="method gpudb_api::generic_record::ColumnType::property"><code>ColumnType::property</code></a>). An array or vector type, which no single property makes, is kept as given.</p>
<p>This cannot fail, so an empty name or property is refused by <a href="/content/api/rust/generic_record/struct.Type#method.new" title="associated function gpudb_api::generic_record::Type::new"><code>Type::new</code></a> instead.</p>
</div>
