<p>Immutable collection of metadata about a Kinetica type.</p>
<p>It contains all the information needed to create and encode records of this type.</p>
<h2 id="creating-a-type">Creating a Type</h2>
<div>

```rust
// From existing table
let record_type = Type::from_table(&kinetica, "my_table").await?;

// Programmatically
let record_type = Type::builder("my_type")
    .add_column(Column::new("id", ColumnType::Integer))
    .add_column(Column::new("name", ColumnType::String))
    .build()?;
```
