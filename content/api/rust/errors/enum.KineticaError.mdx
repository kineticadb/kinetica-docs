<div className="details toggle top-doc">
<div className="docblock">
<p>The main error type for all Kinetica operations.</p>
<p>All API calls return <code>Result&lt;T, KineticaError&gt;</code> to handle various failure modes.</p>
<p>The variant tells what kind of failure it was: a request that failed on every cluster it could reach is a <a href="/content/api/rust/errors/enum.KineticaError#variant.Connection" title="variant gpudb_api::errors::KineticaError::Connection"><code>KineticaError::Connection</code></a>. The URL a request failed at is in its message.</p>
<h2 id="examples">Examples</h2>
<div>

```rust
use gpudb_api::KineticaError;

fn example() -> Result<(), KineticaError> {
    // Operations that might fail...
    Ok(())
}
```

<div className="docblock">
<p>An error reported in terms of the one that caused it.</p>
<p>Recovery paths use this to report what actually went wrong while keeping the underlying failure reachable through <a href="https://doc.rust-lang.org/1.98.1/core/error/trait.Error.html#method.source" title="method core::error::Error::source"><code>std::error::Error::source</code></a> — a retry’s own failure is usually a consequence of the original, and replacing it loses the only useful message.</p>
