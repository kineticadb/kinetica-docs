<p>Closes this object: drops the SQL #name temp tables it created, if any, and releases its HTTP connections. A session ID given by <a className="reference internal" href="/content/api/python/source/gpudb/session-id#gpudb.GPUdb.Options.session_id" title="gpudb.GPUdb.Options.session_id"><code className="xref py py-attr docutils literal notranslate"><span className="pre">GPUdb.Options.session\_id</span></code></a> is not dropped: the caller drops it with <a className="reference internal" href="/content/api/python/source/gpudb/drop-session#gpudb.GPUdb.drop_session" title="gpudb.GPUdb.drop_session"><code className="xref py py-meth docutils literal notranslate"><span className="pre">drop\_session()</span></code></a>.</p>
<p>An object that is never closed still has its temp tables dropped when it is deleted, on a best-effort basis; failing that, the server reclaims them on its own. Closing it is what makes the drop prompt.</p>
