<p>Manually repair a corrupted table. Returns information about affected tables.</p>
<p><strong>Parameters</strong></p>
<div className="blockquote">
<div>
<div className="dl">
<div className="dt">table\_names (<span className="em">list of str</span>) –</div>
<div className="dd">
<p>List of tables to query. An asterisk returns all tables. The user can provide a single element (which will be automatically promoted to a list internally) or a list.</p>
</div>
<div className="dt">table\_types (<span className="em">dict of str to str</span>) –</div>
<div className="dd">
<p>ID of the type per table.</p>
</div>
<div className="dt">options (<span className="em">dict of str to str</span>) –</div>
<div className="dd">
<p>Optional parameters. Allowed keys are:</p>
<ul>
<li>
<p><strong>repair\_policy</strong> – Corrective action to take. Allowed values are:</p>
<ul className="simple">
<li>
<p><strong>delete\_chunks</strong> – Deletes any corrupted chunks.</p>
</li>
<li>
<p><strong>shrink\_columns</strong> – Shrinks corrupted chunks to the shortest column.</p>
</li>
<li>
<p><strong>replay\_wal</strong> – Manually invokes write-ahead log (WAL) replay on the table.</p>
</li>
<li>
<p><strong>alter\_table</strong> – Reset columns modification after incomplete alter column.</p>
</li>
<li>
<p><strong>resync\_replicas</strong> – Repairs replicated tables whose record counts differ across the worker ranks and toms: the copy with the most records is kept, and every other copy is replaced with it. That copy may include records from a load that did not complete, or records that a delete did not remove. A table whose copies all have the same number of records is not repaired, even if their contents differ. Views cannot be named in input parameter <span className="em">table\_names</span>; a named table that is not replicated is reported in output parameter <span className="em">repair\_status</span>. An asterisk selects every replicated table. The repair runs only while no other requests are running. The repaired tables are listed in the <span className="em">repaired\_replicated\_tables</span> entry of the response output parameter <span className="em">info</span> map.</p>
</li>
</ul>
</li>
<li>
<p><strong>verify\_all</strong> – If <span className="em">false</span> only table chunk data already known to be corrupted will be repaired. Otherwise the database will perform a full table scan to check for correctness. Allowed values are:</p>
<ul className="simple">
<li>
<p>true</p>
</li>
<li>
<p>false</p>
</li>
</ul>
<p>The default value is ‘false’.</p>
</li>
</ul>
<p>The default value is an empty dict ( {"{"}{"}"} ).</p>
</div>
</div>
</div>
</div>
<p><strong>Returns</strong></p>
<div className="blockquote">
<div>
<p>A dict with the following entries–</p>
<div className="dl">
<div className="dt">table\_names (<span className="em">list of str</span>) –</div>
<div className="dd">
<p>List of repaired tables.</p>
</div>
<div className="dt">repair\_status (<span className="em">list of str</span>) –</div>
<div className="dd">
<p>List of repair status by table.</p>
</div>
<div className="dt">info (<span className="em">dict of str to str</span>) –</div>
<div className="dd">
<p>Additional information. Allowed keys are:</p>
<ul className="simple">
<li>
<p><strong>repaired\_replicated\_tables</strong> – If <span className="em">repair\_policy</span> is <span className="em">resync\_replicas</span>, comma-separated list of the replicated tables that were repaired.</p>
</li>
</ul>
<p>The default value is an empty dict ( {"{"}{"}"} ).</p>
</div>
</div>
</div>
</div>
