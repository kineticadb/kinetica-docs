<h3>filterByRange</h3>
<div className="member-signature"><span className="modifiers">public</span>&nbsp;<span className="return-type"><a href="/content/api/java/com/gpudb/protocol/FilterByRangeResponse" title="class in com.gpudb.protocol">FilterByRangeResponse</a></span>&nbsp;<span className="element-name">filterByRange</span><wbr /><span className="parameters">(<a href="/content/api/java/com/gpudb/protocol/FilterByRangeRequest" title="class in com.gpudb.protocol">FilterByRangeRequest</a>&nbsp;request)</span> throws <span className="exceptions"><a href="/content/api/java/com/gpudb/GPUdbException" title="class in com.gpudb">GPUdbException</a></span></div>
<div className="block">
Calculates which objects from a table have a column that is within the given bounds. An object from the table identified by <a href="/content/api/java/com/gpudb/protocol/FilterByRangeRequest#getTableName()"><code>tableName</code></a> is added to the view <a href="/content/api/java/com/gpudb/protocol/FilterByRangeRequest#getViewName()"><code>viewName</code></a> if its column is within \[<a href="/content/api/java/com/gpudb/protocol/FilterByRangeRequest#getLowerBound()"><code>lowerBound</code></a>, <a href="/content/api/java/com/gpudb/protocol/FilterByRangeRequest#getUpperBound()"><code>upperBound</code></a>\] (inclusive). The operation is synchronous. The response provides a count of the number of objects which passed the bound filter. Although this functionality can also be accomplished with the standard filter function, it is more efficient. 
<p> For track objects, the count reflects how many points fall within the given bounds (which may not include all the track points of any given track).</p>

An object from the table identified by <code>tableName</code> is added to the view <code>viewName</code> if its column is within \[<code> lowerBound</code>, <code>upperBound</code>\] (inclusive).
