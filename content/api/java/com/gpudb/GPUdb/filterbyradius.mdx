<h3>filterByRadius</h3>
<div className="member-signature"><span className="modifiers">public</span>&nbsp;<span className="return-type"><a href="/content/api/java/com/gpudb/protocol/FilterByRadiusResponse" title="class in com.gpudb.protocol">FilterByRadiusResponse</a></span>&nbsp;<span className="element-name">filterByRadius</span><wbr /><span className="parameters">(<a href="/content/api/java/com/gpudb/protocol/FilterByRadiusRequest" title="class in com.gpudb.protocol">FilterByRadiusRequest</a>&nbsp;request)</span> throws <span className="exceptions"><a href="/content/api/java/com/gpudb/GPUdbException" title="class in com.gpudb">GPUdbException</a></span></div>
<div className="block">
Calculates which objects from a table lie within a circle with the given radius and center point (i.e.&nbsp;circular NAI). The operation is synchronous, meaning that a response will not be returned until all the objects are fully available. The response payload provides the count of the resulting set. A new resultant set (view) which satisfies the input circular NAI restriction specification is also created if a <a href="/content/api/java/com/gpudb/protocol/FilterByRadiusRequest#getViewName()"><code>viewName</code></a> is passed in as part of the request. 
<p> For track data, all track points that lie within the circle plus one point on either side of the circle (if the track goes beyond the circle) will be included in the result.</p>
