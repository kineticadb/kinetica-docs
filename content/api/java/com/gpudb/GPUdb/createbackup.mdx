<div className="dl notes">
<div className="dt">Parameters:</div>
<div className="dd"><code>backupName</code> - Name for this backup. <div className="dd">
<code>backupType</code> - Type of snapshot to create. Supported values: 
<ul>
<li><a href="/content/api/java/com/gpudb/protocol/CreateBackupRequest.BackupType#DIFFERENTIAL"><code>DIFFERENTIAL</code></a>: Snapshot of changes in the database objects and data since the last full snapshot. </li>
<li><a href="/content/api/java/com/gpudb/protocol/CreateBackupRequest.BackupType#FULL"><code>FULL</code></a>: Snapshot of the given database objects and data. </li>
<li><a href="/content/api/java/com/gpudb/protocol/CreateBackupRequest.BackupType#INCREMENTAL"><code>INCREMENTAL</code></a>: Snapshot of changes in the database objects and data since the last snapshot of any kind. </li>
</ul>
</div>
<div className="dd">
<code>backupObjectsMap</code> - Map of objects to be captured in the backup; must be specified when creating a full snapshot and left unspecified when creating an incremental or differential snapshot. 
<ul>
<li><a href="/content/api/java/com/gpudb/protocol/CreateBackupRequest.BackupObjectsMap#ALL"><code>ALL</code></a>: All object types and data contained in the given <a href="/content/concepts/schemas/" target="_top">schema(s)</a>. </li>
<li><a href="/content/api/java/com/gpudb/protocol/CreateBackupRequest.BackupObjectsMap#CATALOG"><code>CATALOG</code></a>: Data Lake catalog that is external to the database. </li>
<li><a href="/content/api/java/com/gpudb/protocol/CreateBackupRequest.BackupObjectsMap#CONTEXT"><code>CONTEXT</code></a>: <a href="/content/sql-gpt/concepts/#sql-gpt-context" target="_top">Context(s)</a>. </li>
<li><a href="/content/api/java/com/gpudb/protocol/CreateBackupRequest.BackupObjectsMap#CREDENTIAL"><code>CREDENTIAL</code></a>: <a href="/content/concepts/credentials/" target="_top">Credential(s)</a>. </li>
<li><a href="/content/api/java/com/gpudb/protocol/CreateBackupRequest.BackupObjectsMap#DATASINK"><code>DATASINK</code></a>: <a href="/content/concepts/data_sinks/" target="_top">Data sink(s)</a>. </li>
<li><a href="/content/api/java/com/gpudb/protocol/CreateBackupRequest.BackupObjectsMap#DATASOURCE"><code>DATASOURCE</code></a>: <a href="/content/concepts/data_sources/" target="_top">Data source(s)</a>. </li>
<li><a href="/content/api/java/com/gpudb/protocol/CreateBackupRequest.BackupObjectsMap#DIRECTORY"><code>DIRECTORY</code></a>: KiFS <a href="/content/tools/kifs/" target="_top">File directory(ies)</a>. </li>

<li><a href="/content/api/java/com/gpudb/protocol/CreateBackupRequest.Options#FALSE"><code>FALSE</code></a> </li>
