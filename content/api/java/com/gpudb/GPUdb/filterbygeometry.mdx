<div className="dl notes">
<div className="dt">Parameters:</div>
<div className="dd"><code>tableName</code> - Name of the table on which the filter by geometry will be performed, in \[schema\_name.\]table\_name format, using standard <a href="/content/concepts/tables/#table-name-resolution" target="_top">name resolution rules</a>. <div className="dd"><code>viewName</code> - If provided, then this will be the name of the view containing the results, in \[schema\_name.\]view\_name format, using standard <a href="/content/concepts/tables/#table-name-resolution" target="_top">name resolution rules</a> and meeting <a href="/content/concepts/tables/#table-naming-criteria" target="_top">table naming criteria</a>. Must not be an already existing table or view. The default value is ''.</div>
<div className="dd"><code>columnName</code> - Name of the column to be used in the filter. Must be a geospatial geometry column.</div>
<div className="dd"><code>inputWkt</code> - A geometry in WKT format that will be used to filter the objects in <code>tableName</code>. The default value is ''.</div>
<div className="dd">
<code>operation</code> - The geometric filtering operation to perform. Supported values: 
<ul>
<li><a href="/content/api/java/com/gpudb/protocol/FilterByGeometryRequest.Operation#CONTAINS"><code>CONTAINS</code></a>: Matches records that contain the given WKT in <code>inputWkt</code>, i.e. the given WKT is within the bounds of a record's geometry. </li>
<li><a href="/content/api/java/com/gpudb/protocol/FilterByGeometryRequest.Operation#CROSSES"><code>CROSSES</code></a>: Matches records that cross the given WKT. </li>
<li><a href="/content/api/java/com/gpudb/protocol/FilterByGeometryRequest.Operation#DISJOINT"><code>DISJOINT</code></a>: Matches records that are disjoint from the given WKT. </li>
<li><a href="/content/api/java/com/gpudb/protocol/FilterByGeometryRequest.Operation#EQUALS"><code>EQUALS</code></a>: Matches records that are the same as the given WKT. </li>
<li><a href="/content/api/java/com/gpudb/protocol/FilterByGeometryRequest.Operation#INTERSECTS"><code>INTERSECTS</code></a>: Matches records that intersect the given WKT. </li>
<li><a href="/content/api/java/com/gpudb/protocol/FilterByGeometryRequest.Operation#OVERLAPS"><code>OVERLAPS</code></a>: Matches records that overlap the given WKT. </li>
<li><a href="/content/api/java/com/gpudb/protocol/FilterByGeometryRequest.Operation#TOUCHES"><code>TOUCHES</code></a>: Matches records that touch the given WKT. </li>
<li><a href="/content/api/java/com/gpudb/protocol/FilterByGeometryRequest.Operation#WITHIN"><code>WITHIN</code></a>: Matches records that are within the given WKT. </li>
</ul>
</div>
