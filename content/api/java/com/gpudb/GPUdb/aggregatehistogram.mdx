<h3>aggregateHistogram</h3>
<div className="member-signature"><span className="modifiers">public</span>&nbsp;<span className="return-type"><a href="/content/api/java/com/gpudb/protocol/AggregateHistogramResponse" title="class in com.gpudb.protocol">AggregateHistogramResponse</a></span>&nbsp;<span className="element-name">aggregateHistogram</span><wbr /><span className="parameters">(<a href="/content/api/java/com/gpudb/protocol/AggregateHistogramRequest" title="class in com.gpudb.protocol">AggregateHistogramRequest</a>&nbsp;request)</span> throws <span className="exceptions"><a href="/content/api/java/com/gpudb/GPUdbException" title="class in com.gpudb">GPUdbException</a></span></div>
<div className="block">
Performs a histogram calculation given a table, a column, and an interval function. The <a href="/content/api/java/com/gpudb/protocol/AggregateHistogramRequest#getInterval()"><code>interval</code></a> is used to produce bins of that size and the result, computed over the records falling within each bin, is returned. For each bin, the start value is inclusive, but the end value is exclusive--except for the very last bin for which the end value is also inclusive. The value returned for each bin is the number of records in it, except when a column name is provided as a <a href="/content/api/java/com/gpudb/protocol/AggregateHistogramRequest.Options#VALUE_COLUMN"><code>VALUE\_COLUMN</code></a>. In this latter case the sum of the values corresponding to the <a href="/content/api/java/com/gpudb/protocol/AggregateHistogramRequest.Options#VALUE_COLUMN"><code>VALUE\_COLUMN</code></a> is used as the result instead. The total number of bins requested cannot exceed 10,000. 
<p> NOTE: The Kinetica instance being accessed must be running a CUDA (GPU-based) build to service a request that specifies a <a href="/content/api/java/com/gpudb/protocol/AggregateHistogramRequest.Options#VALUE_COLUMN"><code>VALUE\_COLUMN</code></a>.</p>
