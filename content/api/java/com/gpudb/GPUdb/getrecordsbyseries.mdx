<div className="block">
Retrieves the complete series/track records from the given <code> worldTableName</code> based on the partial track information contained in the <code>tableName</code>. 
<p> This operation supports paging through the data via the <code>offset</code> and <code>limit</code> parameters. </p>
<p> In contrast to <a href="/content/api/java/com/gpudb/GPUdb/getrecords#getRecords(java.lang.Object,java.lang.String,long,long,java.util.Map)"><code>getRecords</code></a> this returns records grouped by series/track. So if <code> offset</code> is 0 and <code>limit</code> is 5 this operation would return the first 5 series/tracks in <code>tableName</code>. Each series/track will be returned sorted by their TIMESTAMP column.</p>
</div>
