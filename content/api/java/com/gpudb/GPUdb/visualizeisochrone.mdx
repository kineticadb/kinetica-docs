<div className="block">Generate an image containing isolines for travel results using an existing graph. Isolines represent curves of equal cost, with cost typically referring to the time or distance assigned as the weights of the underlying graph. See <a href="/content/graph_solver/network_graph_solver/" target="_top">Graphs and Solvers</a> for more information on graphs.</div>
<div className="dl notes">
<div className="dt">Parameters:</div>
<div className="dd"><code>graphName</code> - Name of the graph on which the isochrone is to be computed.</div>
<div className="dd"><code>sourceNode</code> - Starting vertex on the underlying graph from/to which the isochrones are created.</div>
<div className="dd"><code>maxSolutionRadius</code> - Extent of the search radius around <code> sourceNode</code>. Set to '-1.0' for unrestricted search radius. The default value is -1.0.</div>
<div className="dd"><code>weightsOnEdges</code> - Additional weights to apply to the edges of an existing graph. Weights must be specified using <a href="/content/graph_solver/network_graph_solver/#identifiers" target="_top">identifiers</a>; identifiers are grouped as <a href="/content/graph_solver/network_graph_solver/#id-combos" target="_top">combinations</a>. Identifiers can be used with existing column names, e.g., 'table.column AS WEIGHTS\_EDGE\_ID', or expressions, e.g., 'ST\_LENGTH(wkt) AS WEIGHTS\_VALUESPECIFIED'. Any provided weights will be added (in the case of 'WEIGHTS\_VALUESPECIFIED') to or multiplied with (in the case of 'WEIGHTS\_FACTORSPECIFIED') the existing weight(s). The default value is an empty <a href="https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html" title="class or interface in java.util" className="external-link"><code>List</code></a>.</div>
<div className="dd"><code>restrictions</code> - Additional restrictions to apply to the nodes/edges of an existing graph. Restrictions must be specified using <a href="/content/graph_solver/network_graph_solver/#identifiers" target="_top">identifiers</a>; identifiers are grouped as <a href="/content/graph_solver/network_graph_solver/#id-combos" target="_top">combinations</a>. Identifiers can be used with existing column names, e.g., 'table.column AS RESTRICTIONS\_EDGE\_ID', or expressions, e.g., 'column/2 AS RESTRICTIONS\_VALUECOMPARED'. If <a href="/content/api/java/com/gpudb/protocol/VisualizeIsochroneRequest.SolveOptions#REMOVE_PREVIOUS_RESTRICTIONS"><code>REMOVE\_PREVIOUS\_RESTRICTIONS</code></a> is set to <a href="/content/api/java/com/gpudb/protocol/VisualizeIsochroneRequest.SolveOptions#TRUE"><code>TRUE</code></a>, any provided restrictions will replace the existing restrictions. The default value is an empty <a href="https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html" title="class or interface in java.util" className="external-link"><code>List</code></a>.</div>
