<h3>dropSession</h3>
<div className="member-signature"><span className="modifiers">public</span>&nbsp;<span className="return-type"><a href="/content/api/java/com/gpudb/protocol/DropSessionResponse" title="class in com.gpudb.protocol">DropSessionResponse</a></span>&nbsp;<span className="element-name">dropSession</span><wbr /><span className="parameters">(<a href="/content/api/java/com/gpudb/protocol/DropSessionRequest" title="class in com.gpudb.protocol">DropSessionRequest</a>&nbsp;request)</span> throws <span className="exceptions"><a href="/content/api/java/com/gpudb/GPUdbException" title="class in com.gpudb">GPUdbException</a></span></div>
<div className="block">
Ends the client session named by the X-Kinetica-Session HTTP header of this request, dropping every session temp table (a table created in SQL as #name) that belongs to it. Objects outside the session that depend on those tables are invalidated, not dropped. 
<p> A client sends its session ID in the X-Kinetica-Session HTTP header to every endpoint (e.g., /execute/sql), and needs to call this endpoint only when a response's info map has carried session\_id\_used set to true. </p>
<p> Only the user that owns the session, or a system administrator, may drop it. Dropping an unknown session is a no-op.</p>
</div>
