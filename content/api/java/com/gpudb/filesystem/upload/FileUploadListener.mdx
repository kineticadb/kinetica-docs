<div className="section detail" id="onMultiPartUploadComplete(java.util.List)">
<h3>onMultiPartUploadComplete</h3>
<div className="member-signature"><span className="return-type">void</span>&nbsp;<span className="element-name">onMultiPartUploadComplete</span><wbr /><span className="parameters">(<a href="https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html" title="class or interface in java.util" className="external-link">List</a>&lt;<a href="/content/api/java/com/gpudb/filesystem/common/Result" title="class in com.gpudb.filesystem.common">Result</a>&gt;&nbsp;uploadResults)</span></div>
<div className="block">
This method is called when all the parts of a multi-part upload have been completed successfully. 
<p> The list contains a <a href="/content/api/java/com/gpudb/filesystem/common/Result" title="class in com.gpudb.filesystem.common"><code>Result</code></a> for every stage of the job, in the order they were executed: the initiating stage, one entry per uploaded part, and finally the completing stage. Only the completing stage reports the uploaded file through <a href="/content/api/java/com/gpudb/filesystem/common/Result#getFullFileNames()"><code>Result.getFullFileNames()</code></a>; for the other stages that list is empty. Use <a href="/content/api/java/com/gpudb/filesystem/common/Result#getUploadInfo()"><code>Result.getUploadInfo()</code></a> to tell the stages apart.</p>
</div>

<div className="dt">Parameters:</div>

</div>
</div>

<div className="section detail" id="onMultiPartUploadCancel(java.util.List)">
<h3>onMultiPartUploadCancel</h3>
<div className="member-signature"><span className="modifiers">default</span>&nbsp;<span className="return-type">void</span>&nbsp;<span className="element-name">onMultiPartUploadCancel</span><wbr /><span className="parameters">(<a href="https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html" title="class or interface in java.util" className="external-link">List</a>&lt;<a href="/content/api/java/com/gpudb/filesystem/common/Result" title="class in com.gpudb.filesystem.common">Result</a>&gt;&nbsp;uploadResults)</span></div>
<div className="block">
This method is called when a multi-part upload was aborted because an earlier stage of the job failed. It is never the result of an explicit request to cancel, as no such operation is exposed. 
<p> The list contains a <a href="/content/api/java/com/gpudb/filesystem/common/Result" title="class in com.gpudb.filesystem.common"><code>Result</code></a> for every stage that completed before the failure, followed by the cancelling stage; none of them report an uploaded file, since nothing was committed. This callback is purely informational — the failure is also reported to the caller of the upload method as a thrown <a href="/content/api/java/com/gpudb/GPUdbException" title="class in com.gpudb"><code>GPUdbException</code></a>, which remains the authoritative error channel.</p>
</div>
