<h2 className="groupheader">Detailed Description</h2>
<div className="textblock">
<p>A set of parameters for <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/showprocstatus#a63c727c0d7264750e61ef8e7c836ebb3">Kinetica.showProcStatus</a>. </p>
<p>Shows the statuses of running or completed proc instances. Results are grouped by run ID (as returned from <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/executeproc#aa60540ec2c062ebd91bab5e0191d9653">Kinetica.executeProc</a>) and data segment ID (each invocation of the proc command on a data segment is assigned a data segment ID).</p>
