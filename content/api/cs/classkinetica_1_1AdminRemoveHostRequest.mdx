<h2 className="groupheader">Detailed Description</h2>
<div className="textblock">
<p>A set of parameters for <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/adminremovehost#a93e3050c57e8c8509cc2d393dd513049">Kinetica.adminRemoveHost</a>. </p>
<p>Removes a host from an existing cluster. If the host to be removed has any ranks running on it, the ranks must be removed using <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/adminremoveranks#a57a58b6bbe780ba3e1085f8c9639bdd1">Kinetica.adminRemoveRanks</a> or manually switched over to a new host using <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/adminswitchover#ad6bf151abf662b20713a239122586b29">Kinetica.adminSwitchover</a> prior to host removal. If the host to be removed has the graph server or SQL planner running on it, these must be manually switched over to a new host using <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/adminswitchover#ad6bf151abf662b20713a239122586b29">Kinetica.adminSwitchover</a>. </p>
