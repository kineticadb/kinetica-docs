<h2 className="groupheader">Detailed Description</h2>
<div className="textblock">
<p>A set of parameters for <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/filterbybox#ae8f4a10b254066875da694eab13e4b80">Kinetica.filterByBox</a>. </p>
<p>Calculates how many objects within the given table lie in a rectangular box. The operation is synchronous, meaning that a response will not be returned until all the objects are fully available. The response payload provides the count of the resulting set. A new resultant set which satisfies the input NAI restriction specification is also created when a <a className="el" href="#ac59ee49c20b03523aa6dade2ec875725" title="If provided, then this will be the name of the view containing the results, in [schema_name.">FilterByBoxRequest.view\_name</a> is passed in as part of the input payload.</p>
