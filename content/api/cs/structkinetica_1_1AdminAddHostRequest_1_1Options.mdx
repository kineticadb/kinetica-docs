<p>The desired RAM limit for the host being added, i.e. </p>
<p>the sum of RAM usage for all processes on the host will not be able to exceed this value. </p>
<p>Supported units: K (thousand), KB (kilobytes), M (million), MB (megabytes), G (billion), GB (gigabytes); if no unit is provided, the value is assumed to be in bytes. For example, if <a className="el" href="#aa0ba50bdfb734d0b1d8fec679864e1a2">RAM\_LIMIT</a> is set to 10M, the resulting RAM limit is 10 million bytes. Set <a className="el" href="#aa0ba50bdfb734d0b1d8fec679864e1a2">RAM\_LIMIT</a> to -1 to have no RAM limit.</p>
