<p>Encoding to be applied to the output file data. </p>
<p>When using JSON serialization it is recommended to specify this as <a className="el" href="#ada9422bad27fab0b4f14a5b365a403cd">BASE64</a>. Supported values:</p>
<ul>
<li> <a className="el" href="#ada9422bad27fab0b4f14a5b365a403cd">BASE64</a>: Apply base64 encoding to the output file data. </li>
<li> <a className="el" href="#a92d3783d748d8fcd84856d1371aa4964">NONE</a>: Do not apply any encoding to the output file data. </li>
</ul>
<p>The default value is <a className="el" href="#a92d3783d748d8fcd84856d1371aa4964">NONE</a>.</p>
