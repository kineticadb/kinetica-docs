<h2 className="groupheader">Detailed Description</h2>
<div className="textblock">
<p>A set of parameters for <a className="el" href="">Kinetica.getRecordsBySeries</a>. </p>
<p>Retrieves the complete series/track records from the given <a className="el" href="#a45c752ddeaa5b846935629546d3f3ab9" title="Name of the table containing the complete series/track information to be returned for the tracks pres...">GetRecordsBySeriesRequest.world\_table\_name</a> based on the partial track information contained in the <a className="el" href="#ae0459053de3794d0e662bcc2bf35a535" title="Name of the table or view for which series/tracks will be fetched, in [schema_name.">GetRecordsBySeriesRequest.table\_name</a>.</p>
<p>This operation supports paging through the data via the <a className="el" href="#a6adb3c7f89d78d8be37abbe5554b86f1" title="A positive integer indicating the number of initial series/tracks to skip (useful for paging through ...">GetRecordsBySeriesRequest.offset</a> and <a className="el" href="#a7f9c24434495a69f4ef4d255cd896ac6" title="A positive integer indicating the maximum number of series/tracks to be returned.">GetRecordsBySeriesRequest.limit</a> parameters.</p>
<p>In contrast to <a className="el" href="">Kinetica.getRecords</a> this returns records grouped by series/track. So if <a className="el" href="#a6adb3c7f89d78d8be37abbe5554b86f1" title="A positive integer indicating the number of initial series/tracks to skip (useful for paging through ...">GetRecordsBySeriesRequest.offset</a> is 0 and <a className="el" href="#a7f9c24434495a69f4ef4d255cd896ac6" title="A positive integer indicating the maximum number of series/tracks to be returned.">GetRecordsBySeriesRequest.limit</a> is 5 this operation would return the first 5 series/tracks in <a className="el" href="#ae0459053de3794d0e662bcc2bf35a535" title="Name of the table or view for which series/tracks will be fetched, in [schema_name.">GetRecordsBySeriesRequest.table\_name</a>. Each series/track will be returned sorted by their TIMESTAMP column.</p>
