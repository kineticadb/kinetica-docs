<h2 className="groupheader">Detailed Description</h2>
<div className="textblock">
<p>A set of parameters for <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/createjob#ae37231de334eee413b2fdf5515890e53">Kinetica.createJob</a>. </p>
<p>Create a job which will run asynchronously. The response returns a job ID, which can be used to query the status and result of the job. The status and the result of the job upon completion can be requested by <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/getjob#afcc40cdc8d8e8e4e2a5a1059354623e6">Kinetica.getJob</a>.</p>
