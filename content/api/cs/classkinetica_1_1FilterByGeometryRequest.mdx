<h2 className="groupheader">Detailed Description</h2>
<div className="textblock">
<p>A set of parameters for <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/filterbygeometry#a45f9d2a07009ec70350f2c7e7be8b6da">Kinetica.filterByGeometry</a>. </p>
<p>Applies a geometry filter against a geospatial geometry column in a given table or view. <td>
The geometric filtering operation to perform. Supported values: 
<ul>
