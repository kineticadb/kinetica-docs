<h2 className="groupheader">Detailed Description</h2>
<div className="textblock">
<p>A set of parameters for <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/dropdatasink#a8e9edda06a969068cf03e6cb9979c3ac">Kinetica.dropDatasink</a>. </p>
<p>Drops an existing <a href="/content/concepts/data_sinks/" target="_top">data sink</a>.</p>
<p>By default, if any <a href="/content/concepts/table_monitors" target="_top">table monitors</a> use this sink as a destination, the request will be blocked unless option <a className="el" href="/content/api/cs/structkinetica_1_1DropDatasinkRequest_1_1Options#a527510426823469e3ccb1419aba98db8">CLEAR\_TABLE\_MONITORS</a> is <a className="el" href="/content/api/cs/structkinetica_1_1DropDatasinkRequest_1_1Options#a2ac83168106aa2cb6ab0c3ee938018c6">TRUE</a>.</p>
