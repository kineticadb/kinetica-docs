<div className="memdoc">
<p>Sets startup materialized view rebuild scheme. </p>
<p>Supported values:</p>
<ul>
<li> <a className="el" href="#a384d5fd2aa87a11236d966f0d2b6e467">ALWAYS</a>: Rebuild as many materialized views as possible before accepting requests. </li>
