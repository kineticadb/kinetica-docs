<p>Adds a table monitor to every table used in the creation of the graph; this table monitor will trigger the graph to update dynamically upon inserts to the source table(s). </p>
<p>Note that upon database restart, if <a className="el" href="#a91fd6e014bc6f24e024db7fa54803483">SAVE\_PERSIST</a> is also set to <a className="el" href="#af1fed1dcf13996e4702c40f0845f2e03">TRUE</a>, the graph will be fully reconstructed and the table monitors will be reattached. For more details on table monitors, see <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/createtablemonitor#aca74e08aa60b423b2d4dfa24fc9ec739">Kinetica.createTableMonitor</a>. <ul>
<li> <a className="el" href="#af1fed1dcf13996e4702c40f0845f2e03">TRUE</a> </li>
<li> <a className="el" href="#a35935722194ad06acd6b54236b7cc3d4">FALSE</a> </li>
</ul>
<p>The default value is <a className="el" href="#a35935722194ad06acd6b54236b7cc3d4">FALSE</a>.</p>
