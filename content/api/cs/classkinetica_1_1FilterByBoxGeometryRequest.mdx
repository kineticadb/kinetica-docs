<h2 className="groupheader">Detailed Description</h2>
<div className="textblock">
<p>A set of parameters for <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/filterbyboxgeometry#a426d85633932bcd12a42184a0f86c016">Kinetica.filterByBoxGeometry</a>. </p>
<p>Calculates which geospatial geometry objects from a table intersect a rectangular box. The operation is synchronous, meaning that a response will not be returned until all the objects are fully available. The response payload provides the count of the resulting set. A new resultant set which satisfies the input NAI restriction specification is also created when a <a className="el" href="#ac9e67a58bd7a2b0ef5ff4211e509619b" title="If provided, then this will be the name of the view containing the results, in [schema_name.">FilterByBoxGeometryRequest.view\_name</a> is passed in as part of the input payload.</p>
