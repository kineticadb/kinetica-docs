<p>Calculates which objects from a table have a column that is within the given bounds. </p>
<p>An object from the table identified by <a className="el" href="/content/api/cs/classkinetica_1_1FilterByRangeRequest#a276d97092e4631872054306284a4c0e9">table\_name</a> is added to the view <a className="el" href="/content/api/cs/classkinetica_1_1FilterByRangeRequest#a7a290c9e67114f18e7f830f2c20ab813">view\_name</a> if its column is within \[<a className="el" href="/content/api/cs/classkinetica_1_1FilterByRangeRequest#ac3f66f450b33944234cf15855b4e1d0b">lower\_bound</a>, <a className="el" href="/content/api/cs/classkinetica_1_1FilterByRangeRequest#a073f6425a8a1377617e1c1f73aeaaf8a">upper\_bound</a>\] (inclusive). The operation is synchronous. The response provides a count of the number of objects which passed the bound filter. Although this functionality can also be accomplished with the standard filter function, it is more efficient.</p>
<p>For track objects, the count reflects how many points fall within the given bounds (which may not include all the track points of any given track).</p>
