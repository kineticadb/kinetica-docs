<p>Calculates which geospatial geometry objects from a table intersect a named area of interest (NAI/polygon). </p>
<p>The operation is synchronous, meaning that a response will not be returned until all the matching objects are fully available. The response payload provides the count of the resulting set. A new resultant set (view) which satisfies the input NAI restriction specification is created with the name <a className="el" href="/content/api/cs/classkinetica_1_1FilterByAreaGeometryRequest#ae3593fed483156317e382ab499166982">view\_name</a> passed in as part of the input.</p>
