<div className="memdoc">
<p>Uploads one or more files to <a href="/content/tools/kifs/" target="_top">KiFS</a>. </p>
<p>There are two methods for uploading files: load files in their entirety, or load files in parts. The latter is recommended for files of approximately 60 MB or larger.</p>
<p>To upload files in their entirety, populate <span className="em">file\_names</span> with the file names to upload into on KiFS, and their respective byte content in <span className="em">file\_data</span> .</p>
<p>Multiple steps are involved when uploading in multiple parts. Only one file at a time can be uploaded in this manner. A user-provided UUID is utilized to tie all the upload steps together for a given file. To upload a file in multiple parts:</p>
<p>1. Provide the file name in <span className="em">file\_names</span> , the UUID in the <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aa7deca070961d9411808b20da75f6e72">MULTIPART\_UPLOAD\_UUID</a> key in <span className="em">options</span> , and a <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aebfe06ae81c1c18519ad14e5f2f3399c">MULTIPART\_OPERATION</a> value of <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#a88175c7ae4545611d3fc12abc36d9ad4">INIT</a>.</p>
<p>2. Upload one or more parts by providing the file name, the part data in <span className="em">file\_data</span> , the UUID, a <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aebfe06ae81c1c18519ad14e5f2f3399c">MULTIPART\_OPERATION</a> value of <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aecfe1b69ba6c3567b3467ba8d404cc88">UPLOAD\_PART</a>, and the part number in the <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aaec11fbee473009aa1db5a259453020a">MULTIPART\_UPLOAD\_PART\_NUMBER</a>. The part numbers must start at 1 and increase incrementally. Parts may not be uploaded out of order.</p>
<p>3. Complete the upload by providing the file name, the UUID, and a <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aebfe06ae81c1c18519ad14e5f2f3399c">MULTIPART\_OPERATION</a> value of <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aa0acfc9a23fe208447a0e1b5aa7df849">COMPLETE</a>.</p>
<p>Multipart uploads in progress may be canceled by providing the file name, the UUID, and a <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aebfe06ae81c1c18519ad14e5f2f3399c">MULTIPART\_OPERATION</a> value of <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#a02d273cd333b86c54cce52610938a8a5">CANCEL</a>. If an new upload is initialized with a different UUID for an existing upload in progress, the pre-existing upload is automatically canceled in favor of the new upload.</p>
<p>The multipart upload must be completed for the file to be usable in KiFS. Information about multipart uploads in progress is available in <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/showfiles#a93dfc6db9b1c849e502d17376ef74b7b">showFiles</a>.</p>
<p>File data may be pre-encoded using base64 encoding. This should be indicated using the <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#a68ccbdcc50d19d87c4fbea946006e330">FILE\_ENCODING</a> option, and is recommended when using JSON serialization.</p>
<p>Each file path must reside in a top-level KiFS directory, i.e. one of the directories listed in <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/showdirectories#aaa58a3b9936ce10ae690e2cd59c3ff94">showDirectories</a>. The user must have write permission on the directory. Nested directories are permitted in file name paths. Directories are delineated with the directory separator of '/'. For example, given the file path '/a/b/c/d.txt', 'a' must be a KiFS directory.</p>
<p>These characters are allowed in file name paths: letters, numbers, spaces, the path delimiter of '/', and the characters: '.' '-' ':' '\[' '\]' '(' ')' '#' '='.</p>

<div className="memdoc">
<p>Uploads one or more files to <a href="/content/tools/kifs/" target="_top">KiFS</a>. </p>
<p>(async) </p>
<p>There are two methods for uploading files: load files in their entirety, or load files in parts. The latter is recommended for files of approximately 60 MB or larger.</p>
<p>To upload files in their entirety, populate <a className="el" href="/content/api/cs/classkinetica_1_1UploadFilesRequest#a32804f91cd5afc1559152f243381aa14">file\_names</a> with the file names to upload into on KiFS, and their respective byte content in <a className="el" href="/content/api/cs/classkinetica_1_1UploadFilesRequest#a1bfe8b6a328028e6dcefddbd8c38a27d">file\_data</a>.</p>
<p>Multiple steps are involved when uploading in multiple parts. Only one file at a time can be uploaded in this manner. A user-provided UUID is utilized to tie all the upload steps together for a given file. To upload a file in multiple parts:</p>
<p>1. Provide the file name in <a className="el" href="/content/api/cs/classkinetica_1_1UploadFilesRequest#a32804f91cd5afc1559152f243381aa14">file\_names</a>, the UUID in the <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aa7deca070961d9411808b20da75f6e72">MULTIPART\_UPLOAD\_UUID</a> key in <a className="el" href="/content/api/cs/classkinetica_1_1UploadFilesRequest#a694b6a07eb6af4a6aa593de76fa9a90a">options</a>, and a <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aebfe06ae81c1c18519ad14e5f2f3399c">MULTIPART\_OPERATION</a> value of <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#a88175c7ae4545611d3fc12abc36d9ad4">INIT</a>.</p>
<p>2. Upload one or more parts by providing the file name, the part data in <a className="el" href="/content/api/cs/classkinetica_1_1UploadFilesRequest#a1bfe8b6a328028e6dcefddbd8c38a27d">file\_data</a>, the UUID, a <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aebfe06ae81c1c18519ad14e5f2f3399c">MULTIPART\_OPERATION</a> value of <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aecfe1b69ba6c3567b3467ba8d404cc88">UPLOAD\_PART</a>, and the part number in the <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aaec11fbee473009aa1db5a259453020a">MULTIPART\_UPLOAD\_PART\_NUMBER</a>. The part numbers must start at 1 and increase incrementally. Parts may not be uploaded out of order.</p>
<p>3. Complete the upload by providing the file name, the UUID, and a <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aebfe06ae81c1c18519ad14e5f2f3399c">MULTIPART\_OPERATION</a> value of <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aa0acfc9a23fe208447a0e1b5aa7df849">COMPLETE</a>.</p>
<p>Multipart uploads in progress may be canceled by providing the file name, the UUID, and a <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#aebfe06ae81c1c18519ad14e5f2f3399c">MULTIPART\_OPERATION</a> value of <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#a02d273cd333b86c54cce52610938a8a5">CANCEL</a>. If an new upload is initialized with a different UUID for an existing upload in progress, the pre-existing upload is automatically canceled in favor of the new upload.</p>
<p>The multipart upload must be completed for the file to be usable in KiFS. Information about multipart uploads in progress is available in <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/showfiles#a93dfc6db9b1c849e502d17376ef74b7b">showFiles</a>.</p>
<p>File data may be pre-encoded using base64 encoding. This should be indicated using the <a className="el" href="/content/api/cs/structkinetica_1_1UploadFilesRequest_1_1Options#a68ccbdcc50d19d87c4fbea946006e330">FILE\_ENCODING</a> option, and is recommended when using JSON serialization.</p>
<p>Each file path must reside in a top-level KiFS directory, i.e. one of the directories listed in <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/showdirectories#aaa58a3b9936ce10ae690e2cd59c3ff94">showDirectories</a>. The user must have write permission on the directory. Nested directories are permitted in file name paths. Directories are delineated with the directory separator of '/'. For example, given the file path '/a/b/c/d.txt', 'a' must be a KiFS directory.</p>
<p>These characters are allowed in file name paths: letters, numbers, spaces, the path delimiter of '/', and the characters: '.' '-' ':' '\[' '\]' '(' ')' '#' '='.</p>
