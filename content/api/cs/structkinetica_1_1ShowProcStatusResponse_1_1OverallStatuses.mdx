<h2 className="groupheader">Detailed Description</h2>
<div className="textblock">
<p>A set of string constants for the parameter <a className="el" href="/content/api/cs/classkinetica_1_1ShowProcStatusResponse#ab84b1244d5aab2175a413141604c40ec" title="Overall statuses for the returned run IDs.">ShowProcStatusResponse.overall\_statuses</a>. </p>
