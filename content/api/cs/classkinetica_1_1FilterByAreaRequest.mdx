<h2 className="groupheader">Detailed Description</h2>
<div className="textblock">
<p>A set of parameters for <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/filterbyarea#a700c5cf8bafb7b1213d19fe20613e829">Kinetica.filterByArea</a>. </p>
<p>Calculates which objects from a table are within a named area of interest (NAI/polygon). The operation is synchronous, meaning that a response will not be returned until all the matching objects are fully available. The response payload provides the count of the resulting set. A new resultant set (view) which satisfies the input NAI restriction specification is created with the name <a className="el" href="#a609aa2175e1b8f233582768f0f79b73a" title="If provided, then this will be the name of the view containing the results, in [schema_name.">FilterByAreaRequest.view\_name</a> passed in as part of the input. </p>
