<h2 className="groupheader">Detailed Description</h2>
<div className="textblock">
<p>A set of parameters for <a className="el" href="/content/api/cs/classkinetica_1_1Kinetica/filterbyradiusgeometry#a4c4b14d1ca8b440b124ccf4c29b40dbe">Kinetica.filterByRadiusGeometry</a>. </p>
<p>Calculates which geospatial geometry objects from a table intersect a circle with the given radius and center point (i.e. circular NAI). The operation is synchronous, meaning that a response will not be returned until all the objects are fully available. The response payload provides the count of the resulting set. A new resultant set (view) which satisfies the input circular NAI restriction specification is also created if a <a className="el" href="#adb9ff9e60057060245f87477128286d9" title="If provided, then this will be the name of the view containing the results, in [schema_name.">FilterByRadiusGeometryRequest.view\_name</a> is passed in as part of the request.</p>
