<p>Drops the SQL #name temp tables this object created, if any. </p>
<p>A session ID given by <a className="el" href="/content/api/cpp/classgpudb_1_1GPUdb_1_1Options#a227d223b9d8e11256d8c10154bec1bb6" title="Set the session ID for SQL #name temp tables, so that several GPUdb objects can share one session's t...">Options::setSessionId()</a> is not dropped: the caller drops it with <a className="el" href="/content/api/cpp/classgpudb_1_1GPUdb/dropsession#a87e3605b58acf4ec17c20a6d687e06a2" title="Ends the client session named by the X-Kinetica-Session HTTP header of this request,...">dropSession()</a>. The destructor does the same, with a short timeout and no failover; closing first is what makes the drop reliable.</p>
