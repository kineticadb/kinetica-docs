<li>
<a className="el" href="/content/api/cpp/namespacegpudb#a855eb532c369e687541a8b142dff1e82">drop\_backup\_no\_error\_if\_not\_exists</a>: Whether or not to suppress the error if the specified backup does not exist. Supported values:
