</tr>
<tr>

<td className="paramname">options</td>
<td>
Optional parameters. 
<ul>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#a11243780573269b0188f43086fefd487">alter\_wal\_max\_segment\_size</a>: Maximum size of an individual segment file. </li>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#a2cc00dc1d5af908a8cb471d1672a047b">alter\_wal\_segment\_count</a>: Approximate number of segment files to split the WAL across. Must be at least two. </li>
<li>
<a className="el" href="/content/api/cpp/namespacegpudb#ae521bb194a9ce38e75609142cd93becf">alter\_wal\_sync\_policy</a>: Maximum size of an individual segment file. Supported values: 
<ul>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#a91d162ed444e2e9085c605c28c877e00">alter\_wal\_none</a>: Disables the WAL. </li>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#ad2fe01c6f5978e3e7236facab116f4a2">alter\_wal\_background</a>: WAL entries are periodically written instead of immediately after each operation. </li>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#ae10a93be3787862b80aab1897fb52e33">alter\_wal\_flush</a>: Protects entries in the event of a database crash. </li>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#aae23b82ae4ff72a7ea1a7086fa15a02b">alter\_wal\_fsync</a>: Protects entries in the event of an OS crash. </li>
</ul>
</li>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#ac171e13c8202fc9465715d3b417db8f0">alter\_wal\_flush\_frequency</a>: Specifies how frequently WAL entries are written with background sync. This is a global setting and can only be used with the system {"{"}options.table\_names{"}"} specifier '\*'. </li>
<li>
<a className="el" href="/content/api/cpp/namespacegpudb#afda614e8703a8cbfcbd7341c53356a80">alter\_wal\_checksum</a>: If <a className="el" href="/content/api/cpp/namespacegpudb#a05b6ab935abe46b7ad7f3d3be3bee137">true</a> each entry will be checked against a protective checksum. Supported values: 
<ul>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#a05b6ab935abe46b7ad7f3d3be3bee137">alter\_wal\_true</a> </li>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#afd2618a1b1b25668ee515a4f44133c9f">alter\_wal\_false</a> </li>
</ul>
 The default value is <a className="el" href="/content/api/cpp/namespacegpudb#a05b6ab935abe46b7ad7f3d3be3bee137">alter\_wal\_true</a>. 
</li>
<li>
<a className="el" href="/content/api/cpp/namespacegpudb#a3bf4a86f684e5f72efca3f49eb6606c7">alter\_wal\_override\_non\_default</a>: If <a className="el" href="/content/api/cpp/namespacegpudb#a05b6ab935abe46b7ad7f3d3be3bee137">true</a> tables with unique WAL settings will be overridden when applying a system level change. Supported values: 
<ul>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#a05b6ab935abe46b7ad7f3d3be3bee137">alter\_wal\_true</a> </li>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#afd2618a1b1b25668ee515a4f44133c9f">alter\_wal\_false</a> </li>
</ul>
 The default value is <a className="el" href="/content/api/cpp/namespacegpudb#afd2618a1b1b25668ee515a4f44133c9f">alter\_wal\_false</a>. 
</li>
<li>
<a className="el" href="/content/api/cpp/namespacegpudb#ae1945c992a9ac4f5a9e6d7182ad084f5">alter\_wal\_restore\_system\_settings</a>: If <a className="el" href="/content/api/cpp/namespacegpudb#a05b6ab935abe46b7ad7f3d3be3bee137">true</a> tables with unique WAL settings will be reverted to the current global settings. Cannot be used in conjunction with any other option. Supported values: 
<ul>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#a05b6ab935abe46b7ad7f3d3be3bee137">alter\_wal\_true</a> </li>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#afd2618a1b1b25668ee515a4f44133c9f">alter\_wal\_false</a> </li>
</ul>
 The default value is <a className="el" href="/content/api/cpp/namespacegpudb#afd2618a1b1b25668ee515a4f44133c9f">alter\_wal\_false</a>. 
</li>
<li>
<a className="el" href="/content/api/cpp/namespacegpudb#af6747739be3b5833037159b5e848e54e">alter\_wal\_persist</a>: If <a className="el" href="/content/api/cpp/namespacegpudb#a05b6ab935abe46b7ad7f3d3be3bee137">true</a> and a system-level change was requested, the system configuration will be written to disk upon successful application of this request. This will commit the changes from this request and any additional in-memory modifications. Supported values: 
<ul>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#a05b6ab935abe46b7ad7f3d3be3bee137">alter\_wal\_true</a> </li>
<li> <a className="el" href="/content/api/cpp/namespacegpudb#afd2618a1b1b25668ee515a4f44133c9f">alter\_wal\_false</a> </li>
</ul>
 The default value is <a className="el" href="/content/api/cpp/namespacegpudb#a05b6ab935abe46b7ad7f3d3be3bee137">alter\_wal\_true</a>.

</ul>
 The default value is an empty map.
