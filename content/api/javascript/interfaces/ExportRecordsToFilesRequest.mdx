<div className="tsd-comment tsd-typography">
<p>Path to data export target. If <code>filepath</code> has a file extension, it is read as the name of a file. If <code>filepath</code> is a directory, then the source table name with a random UUID appended will be used as the name of each exported file, all written to that directory. If filepath is a filename, then all exported files will have a random UUID appended to the given name. In either case, the target directory specified or implied must exist. The names of all exported files are returned in the response.</p>
