<p>Forgets the cached type of one table, or of every table.</p>
<p>A client using binary encoding looks a table's type up on its first insert into that table and reuses it for later ones. A failed insert drops the table's entry by itself. Call this after altering a table's columns, so the next insert is not encoded in the old layout.</p>
