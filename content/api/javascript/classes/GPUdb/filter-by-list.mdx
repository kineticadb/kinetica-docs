<div className="tsd-description">
<div className="tsd-comment tsd-typography">
<p>Calculates which records from a table have values in the given list for the corresponding column. The operation is synchronous, meaning that a response will not be returned until all the objects are fully available. The response payload provides the count of the resulting set. A new resultant set (view) which satisfies the input filter specification is also created if a <code>view\_name</code> is passed in as part of the request.</p>
<p>For example, if a type definition has the columns 'x' and 'y', then a filter by list query with the column map {"{"}&quot;x&quot;:\[&quot;10.1&quot;, &quot;2.3&quot;\], &quot;y&quot;:\[&quot;0.0&quot;, &quot;-31.5&quot;, &quot;42.0&quot;\]{"}"} will return the count of all data points whose x and y values match both in the respective x- and y-lists, e.g., &quot;x = 10.1 and y = 0.0&quot;, &quot;x = 2.3 and y = -31.5&quot;, etc. However, a record with &quot;x = 10.1 and y = -31.5&quot; or &quot;x = 2.3 and y = 0.0&quot; would not be returned because the values in the given lists do not correspond.</p>
</div>
