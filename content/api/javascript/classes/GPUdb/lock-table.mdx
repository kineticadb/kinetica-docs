<div className="tsd-description">
<div className="tsd-comment tsd-typography">
<p>Manages global access to a table's data. By default a table has a <code>lock\_type</code> of read\_write, indicating all operations are permitted. A user may request a read\_only or a write\_only lock, after which only read or write operations, respectively, are permitted on the table until the lock is removed. When <code>lock\_type</code> is no\_access then no operations are permitted on the table. The lock status can be queried by setting <code>lock\_type</code> to status.</p>
</div>
