<div className="tsd-description">
<div className="tsd-comment tsd-typography">
<p>Rebalance the data in the cluster so that all nodes contain an equal number of records approximately and/or rebalance the shards to be equally distributed (as much as possible) across all the ranks.</p>
<p>The database must be offline for this operation, see <code>admin\_offline</code></p>
<ul>
<li>If <code>admin\_rebalance</code> is invoked after a change is made to the cluster, e.g., a host was added or removed, sharded data will be evenly redistributed across the cluster by number of shards per rank while unsharded data will be redistributed across the cluster by data size per rank</li>
<li>If <code>admin\_rebalance</code> is invoked at some point when unsharded data (a.k.a. randomly-sharded) in the cluster is unevenly distributed over time, sharded data will not move while unsharded data will be redistributed across the cluster by data size per rank</li>
</ul>
<p>NOTE: Replicated data will not move as a result of this call</p>
<p>This endpoint's processing time depends on the amount of data in the system, thus the API call may time out if run directly. It is recommended to run this endpoint asynchronously via <code>create\_job</code>.</p>
</div>
