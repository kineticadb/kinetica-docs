<div className="tsd-description">
<div className="tsd-comment tsd-typography">
<p>Retrieves records from a collection. The operation can optionally return the record IDs which can be used in certain queries such as <code>delete\_records</code>.</p>
<p>This operation supports paging through the data via the <code>offset</code> and <code>limit</code> parameters.</p>
<p>Note that when using the Java API, it is not possible to retrieve records from join views using this operation.</p>
