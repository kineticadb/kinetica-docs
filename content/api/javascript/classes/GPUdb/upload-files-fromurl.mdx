<p>Uploads one or more files to KiFS.</p>
<p>Each file path must reside in a top-level KiFS directory, i.e. one of the directories listed in <code>show\_directories</code>. The user must have write permission on the directory. Nested directories are permitted in file name paths. Directories are delineated with the directory separator of '/'. For example, given the file path '/a/b/c/d.txt', 'a' must be a KiFS directory.</p>
<p>These characters are allowed in file name paths: letters, numbers, spaces, the path delimiter of '/', and the characters: '.' '-' ':' '\[' '\]' '(' ')' '#' '='.</p>
